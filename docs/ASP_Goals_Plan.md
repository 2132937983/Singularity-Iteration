# Advanced Solar Panels (高级太阳能板) 目标实施计划

## 项目目标

基于 ASP 源代码作为参考，**独立实现**一套高级太阳能板系统，还原其核心功能和玩法体验。

---

## 核心目标

### 🎯 目标 1: 多级太阳能发电系统

实现 4 个等级的太阳能发电机，形成清晰的技术进阶路线：

| 等级 | 名称 | 白天发电 | 夜晚发电 | 存储容量 | 输出等级 |
|------|------|----------|----------|----------|----------|
| 1 | 高级太阳能板 | 8 EU/t | 1 EU/t | 32,000 EU | LV (1) |
| 2 | 混合太阳能板 | 64 EU/t | 8 EU/t | 100,000 EU | MV (2) |
| 3 | 终极混合太阳能板 | 512 EU/t | 64 EU/t | 1,000,000 EU | HV (3) |
| 4 | 量子太阳能板 | 4,096 EU/t | 2,048 EU/t | 10,000,000 EU | EV (4) |

**关键特性**:
- [ ] 白天/夜晚差异化发电
- [ ] 天气影响（雨天/雷雨天发电降低）
- [ ] 天空检测（需要直接看到天空）
- [ ] 能量存储和输出
- [ ] 自动给相邻机器/导线供电

---

### 🎯 目标 2: 太阳能头盔装备

实现 3 个等级的可穿戴太阳能装备：

| 等级 | 名称 | 发电能力 | 充电范围 | 护甲值 |
|------|------|----------|----------|--------|
| 1 | 高级太阳能头盔 | 同高级太阳能板 | 身上所有装备 | 钻石级 |
| 2 | 混合太阳能头盔 | 同混合太阳能板 | 身上所有装备 | 钻石级 |
| 3 | 终极太阳能头盔 | 同终极太阳能板 | 身上所有装备 | 钻石级 |

**关键特性**:
- [ ] 穿戴时持续发电
- [ ] 自动给玩家装备栏物品充电
- [ ] 提供护甲保护
- [ ] 与太阳能板相同的日夜/天气逻辑

---

### 🎯 目标 3: 分子重组仪 (Molecular Transformer)

实现一个高级加工机器，用于生产太阳能板所需的高级材料：

**核心功能**:
- [ ] 消耗大量 EU 进行物品转换
- [ ] 支持多种转换配方
- [ ] 有工作进度显示
- [ ] 可升级（速度/能效）

**关键配方**:
- [ ] 铁锭 → 铱锭 (高耗能)
- [ ] 钻石 → 强化铱铁板
- [ ] 青金石 → 辐射铀
- [ ] 玻璃 → 辐射玻璃板
- [ ] 铀锭 → 阳光化合物碎片

---

### 🎯 目标 4: 材料合成体系

建立完整的材料金字塔，支撑太阳能板的技术进阶：

**基础材料** (可通过挖矿/基础加工获得):
- [ ] 铱锭 - 稀有金属，用于高级机械
- [ ] 铀锭 - 核材料，用于辐射相关合成

**加工材料** (需要通过分子重组仪):
- [ ] 阳光化合物碎片 → 阳光化合物 → 富集阳光化合物
- [ ] 阳光合金 → 富集阳光合金
- [ ] 铱铁板 → 强化铱铁板
- [ ] 辐射铀 → 辐射玻璃板 → 辐射强化板

**核心组件**:
- [ ] 分子重组核心 - 分子重组仪的关键组件
- [ ] 量子核心 - 量子级设备的核心

---

### 🎯 目标 5: 合成配方设计

设计合理的科技树配方，确保进阶感：

**高级太阳能板**:
```
[辐射玻璃板] [阳光化合物] [辐射玻璃板]
[高级电路]   [基础太阳能板] [高级电路]
[铱铁板]     [铱铁板]       [铱铁板]
```

**混合太阳能板**:
```
[富集阳光化合物] [分子重组核心] [富集阳光化合物]
[精英电路]       [高级太阳能板] [精英电路]
[强化铱铁板]     [强化铱铁板]   [强化铱铁板]
```

**终极/量子太阳能板**: 类似的递进式设计

---

### 🎯 目标 6: 视觉效果

**太阳能板**:
- [ ] 不同等级有不同的纹理（颜色/材质区分）
- [ ] 工作时可以有轻微的发光效果
- [ ] 根据发电状态改变纹理（白天/夜晚）

**分子重组仪**:

- [ ] 能量流动画
- [ ] 核心旋转效果

**GUI**:
- [ ] 太阳能板显示当前发电状态
- [ ] 能量存储进度条
- [ ] 分子重组仪显示工作进度

## 技术实现目标

### 系统架构
```
com.singularity_iteration.mio_icif.addons.asp/
├── ASPAddon.java                 # 主类/注册中心
├── ASPConfig.java                # 配置
├── blocks/
│   └── ASPBlocks.java            # 方块定义
├── items/
│   └── ASPItems.java             # 物品定义
├── tiles/
│   ├── SolarPanelTile.java       # 太阳能板实体
│   ├── MolecularTransformerTile.java
│   └── QuantumGeneratorTile.java
├── gui/
│   ├── SolarPanelScreen.java
│   └── MolecularTransformerScreen.java
├── recipes/
│   └── MTRecipes.java            # 分子重组配方
└── network/
    └── ASPPackets.java           # 网络同步
```

### 关键机制实现

**1. 天空检测系统**:
- [ ] 检测上方是否有方块遮挡
- [ ] 检测当前是白天还是夜晚
- [ ] 检测天气状况
- [ ] 缓存检测结果（避免每 tick 重复计算）

**2. 能量管理系统**:
- [ ] 内部能量存储
- [ ] 向电网输出能量
- [ ] 给相邻机器充电
- [ ] 太阳能头盔给玩家装备充电

**3. 配方系统**:
- [ ] 自定义配方类型（分子重组）
- [ ] 配方 JSON 数据驱动
- [ ] JEI 兼容性支持
