```
基础材料
├── 铁锭 → [分子重组] → 铱锭
│   └── 铱锭 + 铁板 → 铱铁板
│       └── 铱铁板 + 钻石 → [分子重组] → 强化铱铁板
│
├── 铜锭 → [分子重组] → 铀锭
│   └── 铀锭 + 沙子 → [分子重组] → 阳光化合物碎片
│       └── 9x碎片 → 阳光化合物
│           └── 阳光化合物 + 铱锭 → [分子重组] → 富集阳光化合物
│               └── 富集阳光化合物 + 铱铁板 → 阳光合金
│                   └── 阳光合金 + 强化铱铁板 → [分子重组] → 富集阳光合金
│
└── 青金石 + 铀锭 → [分子重组] → 辐射铀
    └── 辐射铀 + 玻璃 → [分子重组] → 辐射玻璃板
        └── 辐射玻璃板 + 强化铱铁板 → 辐射强化板

机器核心
├── 高级电路 + 铱锭 + 钻石 → 分子重组核心
└── 精英电路 + 铱锭 + 量子之星 → 量子核心
```
