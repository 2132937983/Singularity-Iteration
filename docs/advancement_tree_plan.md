## 1. 现状的问题

- 现有 18 个进度几乎都挂在 `root → hammer_time → industrial_age` 这一条线下面，只有一个页签。
- 顺序和合成依赖对不上。例如 `refined_steel`（钢）挂在火力发电机下面，但钢只能用高炉炼。
- 新清单里，电炉排在锻造锤、剪刀之前。但实际依赖链是：锻造锤（铁板）→ 板材切割剪刀（要一块铁板）→ 导线 → 绝缘导线（要橡胶）→ 电路板 → 电炉。

## 2. 原则

1. **父子关系只用于「合成或获取上的前置」**。一个进度的父进度，必须是做出它之前大概率已经完成的步骤（以配方为准）。
2. **分 4 个页签**，每个页签内部分叉，不再只有一条线。
3. **现有 18 个进度保留 ID**，玩家已经拿到的不会丢。只改父进度，部分改标题（见第 5 节）。
4. 表格里的类型照搬：普通 = `task`，目标 = `goal`，挑战 = `challenge`；经验奖励写进 `rewards.experience`；隐藏 = `hidden: true`。

## 3. 四个页签

图例：`[目标]`、`[挑战 N]`（N = 经验）、`[隐藏]`；`★` = 需要写代码触发，其余用原版条件就能完成。

原版条件就能完成的：电锯屠夫、像 Boss 一样（`player_killed_entity` 加手持物品或伤害来源判断）、科技中的魔法（物品带省电魔咒）、薛定谔（`tick` 加装备判断）、我是一个粉刷匠（`item_used_on_block`）、其余「获得某物品」。
