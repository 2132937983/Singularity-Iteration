# 美术批次 SB1：三把联动拔刀（拔刀剑 Resharped 的 OBJ 模型与贴图）

先读 [`../README.md`](../README.md) 第 4 节（分支、推送、报告的规矩）。这一批由 **Codex** 来做。它不画 16×16 图标，交付的是拔刀剑（SlashBlade Resharped 2.2.1，NeoForge 1.21.1）读取的 **OBJ 模型、贴图和蓄力流光贴图**，每把刀一套。

本说明的格式照搬神秘时代联动拔刀的美术需求（那是另一个仓库，打不开也没关系，要用的规矩都写在本文第 2 到 5 节里）。

## 0. 这一批是什么

奇点迭代给拔刀剑做三把联动名刀，靠升级拿到：**纳米刃 → 量子刃 → 奇点刃**。

| 文件夹名 `<刀>` | 名字 | 一句话 | 对应奇点迭代的什么 |
|---|---|---|---|
| `nano` | 纳米刃 | 碳纳米管和石墨烯叠层的刀身，压电高频振动刃口，纳米机器人自修复 | 纳米战甲（碳纤维黑）、纳米剑 |
| `quantum` | 量子刃 | 叠加态的刀：一把刀同时在几个位置，出刀时坍缩到被标记的目标上 | 量子战甲（陶瓷白，用在刀装上）、量子剑 |
| `singularity` | 奇点刃 | 刀镡里约束着一颗微型奇点，靠 EU 维持约束，刀身是被引力压实的暗物质刃 | 分子重组仪、核聚变，奇点迭代的终局 |

总的造型要求（用户定的）：

1. **它们是刀，不是剑。** 三把都是日本刀的骨架：单刃、有弯度、刀身薄、刀镡紧凑。拔刀剑所有的挥刀、居合、收刀动作都是按这副骨架做的（第 3.0 节）。三把刀的差别用刀种来分：纳米刃是**打刀**，量子刃是**太刀**，奇点刃是**大太刀**。
2. **刀鞘和刀身都要有进攻性**，但只放在不破坏骨架的地方（第 3.0 节末尾的表）：刀尖的形状、刀背一侧的棱角、不对称的刀镡、鞘尾的尖刺或爪、鞘上的装甲分段、发光的刃线。
3. **不要**：直的等宽刀身、加厚的刀身、十字形护手或横向伸出的长翼、刀背上竖起的鳍或锯齿、双刃。这些会让刀读起来像大剑或幻想剑（见第 7 节纳米刃第一、二版的验收）。

**特效全部由代码做**（第 3.4 节）：纳米的驻波和残影、量子的概率云和坍缩、奇点的引力透镜、吸积盘和霍金辐射爆发，都不进模型。模型上只做“这些特效从哪里来”的实体部件：压电陶瓷片、双缝刀镡、约束环。

## 2. OBJ 对象（部件）全表

拔刀剑按**对象名**找部件，名字必须完全一致（小写、下划线）。下表是拔刀剑 2.2.1 渲染器实际读取的全部对象。**全部都要做。**

### 2.1 主体对象

| 对象名 | 是什么 | 游戏里什么时候画 |
|---|---|---|
| `blade` | 完整刀身，含刀镡、刀柄 | 手持、挥刀；刀架上；掉在地上的刀 |
| `blade_damaged` | 断刀：只剩根部一截 | 耐久耗尽、刀“断了”时，代替 `blade` |
| `blade_fragment` | 断下来的那截刀尖 | 碎片落地 |
| `sheath` | 刀鞘 | 收刀佩在腰间；刀架上；掉在地上的刀 |
| `effect` | 蓄力流光层：包在刀鞘外面的一层壳 | 拔刀技（SA）蓄满力时，叠在腰间刀鞘上（第 2.3 节） |
| `item_blade` | 物品栏模型：刀和鞘斜放的 3D 构图 | 物品栏、快捷栏、JEI、展示框、掉在地上的远景 |
| `item_damaged` | 断刀的物品栏模型 | 刀断了时的物品栏 |
| `item_bladens` | 无鞘的物品栏模型：只有刀 | 刀与鞘分离的展示；要做齐，免得显示成默认刀 |

### 2.2 自发光对象

任意主体对象名加 `_luminous` 后缀，拔刀剑会在它上面**叠画一层自发光**（黑暗中全亮，加色混合）。每把刀按第 6 节决定哪里发光，但**有发光的地方，所有状态都要有对应的发光对象**，不然断刀、物品栏、地上的刀会突然不亮：

| 对象名 | 叠在谁上面 |
|---|---|
| `blade_luminous` | `blade` |
| `blade_damaged_luminous` | `blade_damaged` |
| `blade_fragment_luminous` | `blade_fragment` |
| `sheath_luminous` | `sheath` |
| `item_blade_luminous` | `item_blade` |
| `item_damaged_luminous` | `item_damaged` |
| `item_bladens_luminous` | `item_bladens` |

做法：把要发光的面复制出来，沿法线向外偏移约 0.1 单位，单独成一个对象。它和本体用同一张贴图、同一套 UV 规则；贴图里发光区域以外的像素全透明。

- 加色混合下暗色几乎不加亮：发光对象采样到的贴图像素要**明亮**（亮度 150 以上）。
- 细长的发光线（刃线、接缝）在贴图上**至少 2 像素宽**，或让 UV 对准像素中心。不然游戏里会显示成虚线。
- `effect` 没有发光对象（`effect_luminous` 不会被画）。

### 2.3 蓄力流光层 `effect`

- SA 蓄满力时，`effect` 叠画在腰间刀鞘上，用的不是 `texture.png`，而是一张随时间滚动的流光贴图。奇点迭代会把它换成每把刀自己的 `charge.png`。
- `effect` 是**略大于刀鞘的一层外壳**：沿法线把鞘向外放大 1～1.5 单位，**不能和 `sheath` 重合**（重合会闪烁）。只保留鞘的大轮廓，不要刀镡和浮雕，**最多 60 个顶点**。
- `effect` 的 UV：沿鞘的长度方向展开成一条连续长带，流光顺着鞘流。这张贴图会平铺，所以 UV 可以超出 0～1。
- `charge.png`：64×64，四边无缝平铺，像素画风格，透明底，只用全透明和全不透明的像素。图案和颜色按第 6 节。

### 2.4 断刀与碎片

- `blade_damaged` 和 `blade_fragment` 拼起来正好是完整的 `blade`，断口对得上。
- 碎片要能单独看：两面都有贴图，断口有截面。断口画出各自的材质：纳米是层叠的石墨烯片；量子是镜面钢的截面（亮银，带一条暗的心铁线）；奇点是暗刃崩开后露出的发光内芯。

### 2.5 摆放参照

单位与模板相同。外框数据从拔刀剑 2.2.1 jar 的默认刀量出，并且和模板对过。新刀可以比默认刀长 15% 以内，但 `item_*` 三个物品栏对象**不要超出**表中外框，否则在物品栏里会被裁掉：

| 对象 | 默认刀的外框（x / y / z） | 说明 |
|---|---|---|
| `blade` | −291～42 / −27～18 / −10～10 | 刀尖朝 −X，原点在握位，刀柄末端 x ≈ 41.74 |
| `blade_damaged` | −110～42 / −11～18 / −10～10 | 只到刀身约三分之一 |
| `blade_fragment` | −291～−110 / −27～6 / −0.6～0.6 | 很薄的一片 |
| `sheath` | −297～−35 / −31～11 / −5.6～5.6 | |
| `effect` | 比 `sheath` 每边大 1～1.5 | |
| `item_blade` | −87～71 / −71～80 / −4～30 | 物品栏构图 |
| `item_damaged` | −71～71 / −83～81 / −4～28 | |
| `item_bladens` | 与 `item_blade` 同框 | 只是没有鞘 |

拔刀剑 jar 里的原版 OBJ 可以打开看对象怎么分、怎么摆（**只看，不复制**，第 4 节）：`model/blade.obj`（默认刀）、`model/named/yamato.obj`（鞘带饰件）、`model/named/yasha/yasha_true.obj`（有 `sheath_luminous`、`item_blade_luminous` 的例子）。

### 2.6 物品栏模型在游戏里怎么画

拔刀剑的物品栏不是 16×16 平面图标，而是每帧由它的渲染器把 `item_*` 当 3D 模型画出来，带光照和倾斜视角。

| 场合 | 变换 | 说明 |
|---|---|---|
| 物品栏、快捷栏、JEI | 旋转 x 15°、y −25°、z −5°，平移 (2, 3, 0)，缩放 0.65；再由渲染器缩放 0.008 | 正交投影、GUI 光照。格子在屏幕上是 16 × 界面缩放 像素（32～64 像素） |
| 耐久条 | `item_*` 后面叠一块 ±70.7 见方的耐久底板（z 0～5） | 物品栏模型的主体要在底板前面（z 大于 5 的一侧） |
| 展示框 | 缩放 0.0095，绕 y 转 180° | 背面朝外，`item_*` 的背面也要有贴图 |
| 掉在地上 | 缩放 0.005，上移 0.15 | 同一个 `item_*` 对象 |
| 刀架上 | 画 `blade` 和 `sheath`，不用 `item_*` | |

所以：

1. 构图：刀和鞘交叉斜放（参照默认刀的 `item_blade`），在 gui 变换下正好填满格子、不出框。`item_bladens` 去掉鞘、构图不变；`item_damaged` 是断刀加鞘。
2. 要有真实厚度（默认刀 z 从 −4 到 30），不是一张平片。
3. 用同一张 `texture.png`，可以为物品栏单独画一块更饱满的区域。
4. `item_*_luminous` 在格子里同样全亮：在这里放“一眼认出是哪把刀”的点（纳米的橙色刃线、量子银刀身上的青色刃纹和双缝镡、奇点的品红约束环）。

## 3. 建模规范

### 3.0 拔刀骨架（硬约束）

**拔刀剑怎么握刀。** 拔刀剑的刀不挂在原版的手上。它另有一副 MMD 骨架（`bladeholder.pmd`），用自己的 `.vmd` 动作驱动：`blade` 画在骨骼 `hardpointA` 上，那里就是手；`sheath` 画在 `hardpointB` 上，那里是腰。模型 1 个单位是 1/128 方块。由此得出：

- **原点就是手握的位置。** 刀柄从刀镡后面（x ≈ −35）一直到 x = 41.74，原点在刀柄中段，是双手握的位置。
- **所有名刀共用同一套动作。** 动作是按“单刃、刃口朝 +Y、刀身向刃口一侧拱起、刀尖往下落”的刀做的。模型改不了动作，只能顺着它。刃口朝反了，挥刀时就是刀背在前；刀身不弯，刀尖的轨迹就不对。
- **刀和鞘是两个分开的挂点。** 居合时刀从鞘口抽出，鞘留在腰间。所以刀鞘必须和刀身一样弯，鞘口抵住刀镡，粗细只比刀身外扩一圈，否则佩在腰间会穿进身体。

**骨架的数值。** 模板（也就是拔刀剑默认刀和大和的刀身）都按这一套做；`check_sb1.py` 会在刀身 10% 到 90% 处切 9 个横截面检查：

| 项目 | 要求 | 模板的值 |
|---|---|---|
| 刃口 | 在 **+Y** 一侧：横截面在 +Y 收薄成刃，−Y 是较厚的刀背 | +Y 一侧收到 z ≈ 0 |
| 弯度 | 刀身中线从 10% 处到 90% 处下降多少按第 6 节各刀的范围；中段比两端连线高出 1.5 以上（向刃口一侧拱起）；弯沿全长分布，后三分之一的下降不超过前三分之一的 3.5 倍（不能把弯挤在刀尖，像镰刀） | 下降约 21，拱起约 4，后/前约 2.8 倍 |
| 刀身宽 | 7～13，向刀尖略收 | 约 9.5 |
| 刀身厚 | 最厚处不超过 ±1.2；超过 ±0.9 就开始显得笨重 | ±0.57 |
| 刀镡（x −60～−30） | y 方向外径 ≤ 34，z 方向 ≤ 24；是一块盘或板，不是横向伸出的翼 | 29 × 20 |
| 刀柄（x 0～41.74） | y ≤ 14，z ≤ 9；表面画缠绳或防滑纹，看得出是手握的地方 | 11 × 7 |
| 刀鞘 | 每个横截面都包住刀身；鞘口在 x −42～−30（抵住刀镡）；比刀身高出不超过约 12 | 鞘口 x −35，比刀身高约 6 |
| 长度 | 按第 6 节的刀种 | 握柄末端到刀尖 332.7 |

最省事的做法：在模板 `.blend` 里先沿模板刀身的中线画一条曲线，新刀身沿这条曲线弯（Blender 的 Curve 修改器），刀鞘用同一条曲线。

**进攻性放在哪里。**

| 可以做 | 不要做 |
|---|---|
| 刀尖：切先（折角刀尖）、钩尖、斜折 | 加宽、加厚刀身，或做成等宽直板 |
| 刀背一侧的棱角、鎬筋（刀身侧面的纵棱），不超出刀身宽度 | 刀背上竖起的鳍、锯齿、尖刺 |
| 不对称的刀镡：朝刀尖方向斜出的短爪，收在上表的外径以内 | 十字形护手、向上下伸出的长翼 |
| 鞘尾（鞘的末端）做成尖刺、爪或钳 | 双刃、斧刃、刀身上开洞 |
| 鞘上的装甲分段、散热缝、线圈箍 | 比刀身粗一倍以上的鞘 |
| 发光的刃线、刃纹、接缝 | |

### 3.1 坐标、尺寸、朝向

1. **不要改模板的原点、朝向和缩放。** 刀身沿 −X 伸出，原点在刀镡附近（握位）。挥刀以原点为轴，原点偏了刀会离手。
2. 刀身长度可以在模板基础上增减 ±15%，刀柄长度和握持位置不变。各刀的长度见第 6 节。
3. 鞘要装得下刀：`sheath` 的长度和弧度跟着 `blade` 改（第 3.0 节）。
4. `blade_damaged`、`blade_fragment` 沿用 `blade` 的弯度和刃口朝向；`item_*` 里的刀和鞘也是同一副骨架，只是摆成交叉构图。

### 3.2 面数

1. 全部对象合计 ≤ **3000** 个顶点；物品栏三个对象合计 ≤ **1200**；`effect` ≤ **60**。
2. 造型靠体块，细节靠贴图。纹理、刻线、接缝画在贴图上。
3. 不做小于 1 单位的独立小零件。

### 3.3 贴图

1. 每把刀一张 PNG，尺寸为 2 的幂，建议 **128×256**，最大 256×512。
2. 所有 UV 落在 0～1 之内（`effect` 除外）。模板刀身的 UV 有超出 1 的情况，重做时展开到 0～1 以内。
3. 像素密度大体一致：刀身、刀柄、鞘上一个贴图像素看起来差不多大。
4. 像素只用完全透明或完全不透明（alpha 只有 0 和 255）。
5. 风格是像素画，不用照片贴图或手绘渐变。奇点迭代自己的物品图是参照：纳米剑 `textures/item/3d/item_tool_nanosaber.png`、量子剑 `textures/item/3d/item_tool_quantum_sword.png`、量子与纳米的套装物品图 `textures/item/armor/`，以及模块美术规范 [`../style-suit-modules.md`](../style-suit-modules.md) 的量子陶瓷白和纳米碳纤维黑。
6. **色相偏移：** 阴影偏冷、高光偏暖（或按材质反过来），不要只改明度。
7. **禁止：** 随机噪点、色带和贴边堆叠、同心圆枕头阴影、无视结构的单边平涂、不规整的斜线锯齿、无意义的抖动。纳米碳纤维的规则 45° 斜纹不算噪点。
8. 刃口用一条连续的亮色像素表达，不要渐变。

### 3.4 特效不画在模型里

拔刀的光、剑气、残影、概率云、透镜、吸积盘、粒子都由代码做。模型里不放静态的光柱、火焰、粒子片、残影片、光晕圆盘。约束环、双缝镡这类**实体部件**可以做，它们是刀的零件，不是特效。

### 3.5 导出

拔刀剑的 OBJ 读取器很挑剔：

1. Blender：文件 → 导出 → Wavefront (.obj)，勾选 UV 坐标、法线、三角化面。
2. **每个面只能是三角形或四边形。** 有五边以上的面，读取器直接报错，刀会显示成默认模型。
3. **每个面都要有 UV**（`f 1//1` 这种没有 UV 的写法会让贴图错乱）。
4. **对象名只用英文字母、数字和下划线。**
5. 导出后重新导入，确认 `blade` 的外框和模板一致（x 约 −291～42，y 约 −27～18；长度按第 6 节可以变，刀柄末端不变）。
6. `.mtl` 不交付，拔刀剑不读它。
7. 也可以用 Blockbench 建模后导出 OBJ，规则相同，但起点必须对齐模板的原点和尺寸，所以推荐直接在模板 `.blend` 上做。

- **奇点迭代自己的贴图**（第 3.3 节第 5 条列的那些）可以取色、照着纹样重画，让三把刀一看就是奇点迭代的东西。
- **拔刀剑的素材**是 ARR：只看比例、做工和画风，不复制几何体，不取像素。

## 6. 三把刀的设计

下面的造型方向是建议，可以改，改了在报告里写理由；但第 3.0 节的骨架不能改。颜色是主色板，可以在同一色相上加减一两个过渡色。**发光部位**一栏就是要做 `_luminous` 的地方。

三把刀从轮廓上就要分得出来，靠的是刀种，不是加宽加厚：

| 刀 | 刀种 | 长度（相对模板） | 弯度 | 一眼认出它的地方 |
|---|---|---|---|---|
| 纳米刃 | 打刀 | 1.00～1.05 | 同模板（中线下降 18～25） | 切先刀尖、橙色刃线、尖刺鞘尾 |
| 量子刃 | 太刀（浅弯） | 1.03～1.07 | 三把里最浅，沿全长均匀（中线下降 14～18） | 银色镜面刀身、青色干涉刃纹、双缝刀镡 |
| 奇点刃 | 大太刀 | 1.10～1.15 | 弯而长（中线下降 21～30），刀尖带一点回钩 | 约束环刀镡、品红裂缝刃线、三爪鞘尾 |

### 6.1 纳米刃 `nano`（先交）

**原理：** 刀身是碳纳米管束和石墨烯片一层层压出来的黑色叠层，刃口里嵌着一排压电陶瓷片，通电后以超声频率振动（代码会画驻波和残影），切割时刃口会发热发橙。刀坏了不会彻底消失：纳米机器人在刀鞘里把它补回来（代码做修复的特效）。

**刀身（打刀）**

- 长度：模板的 1.00～1.05 倍。弯度、宽度、厚度照第 3.0 节，刀身宽约 9～10，厚 ±0.6～0.8。
- 刀尖用切先（tanto 式的折角刀尖）：刃线（+Y 一侧）在刀尖前有一个明显的折点，折点前一段更陡地收向刀背。这是它的“进攻角”。
- 刀背（−Y 一侧）中段做一条鎬筋式的棱线，靠刀根三分之一处刻 3 道斜的散热刻线（贴图，或不超出刀背的浅槽）。不要竖起的鳍。
- 刃口沿全长一条压电振动带：贴图上是刃线内侧一排等距的浅色小方块（压电片），刃线本身是发光的橙色，2 像素宽。
- 刀镡：扁八角或切角方形的板，外径在第 3.0 节以内；朝刀尖一侧的两个角斜切成短爪（向 −X 斜出 3～5 单位）。不做向上下伸出的翼。
- 刀柄：碳纤维黑，缠一条深灰的防滑带（菱形缠法画在贴图上），柄头是一个斜切的尖头。

**刀鞘**

- 碳纤维黑的装甲鞘，沿刀身的弯度分 3 到 4 段护板，段与段之间有斜向的散热缝。
- 鞘口一圈收紧的金属箍，与刀镡贴合。
- 鞘尾收成尖刺，顺着刀身的弯度往下、往后延伸 10～15 单位，带一个折角。
- 鞘背中线一条细的压电导轨（贴图），收刀时代码让它发橙。

**颜色**

| 用途 | 颜色 |
|---|---|
| 碳纤维斜纹（两色交替，45°） | `#24282D` / `#1C1F23` |
| 倒角高光 / 暗部 | `#4A5058` / `#15171A` |
| 描边、深缝 | `#0E1013` |
| 压电陶瓷片 | `#C9CED4`，暗部 `#8E959E` |
| 振动刃线（发光） | `#FF7A1F`，最亮的芯 `#FFC46B` |
| 散热缝、导轨（发光） | `#FF5A14` |
| 金属箍 | `#6F7680`，高光 `#A9B0B9` |

**发光部位：** 刃线（全长，2 像素宽）；鞘的散热缝和背部导轨（`sheath_luminous`）；物品栏里刃线和鞘缝要看得见。

**断刀：** 断在切先折点之前。断口画出层层叠叠的石墨烯片（3 到 4 条横纹），刃线在断口处断开，不发光。

**charge.png：** 六边形石墨烯蜂窝格（线宽 1 像素），橙色 `#FF7A1F`，每隔几格一个亮的 `#FFC46B` 节点；无缝平铺，滚动起来像热量顺着晶格流过。

**杀伤细节（第三轮加入）**

| 细节 | 道理 | 做法 |
|---|---|---|
| 压电片按驻波节点排：等距排列，越近刀尖间距越密 | 压电片要放在驻波的节点上；刀尖频率更高，切得更细 | 贴图；B2 的驻波特效对齐这些节点 |
| 刃根微齿：刀镡前约 25 单位，刃口一排 1 像素的锯齿 | 锯齿段能咬住纤维和装甲缝；居合起手拖切时最先接触这一段 | 贴图，或不超出刃宽的极浅几何 |
| 切先破甲帽：折点前的刀尖是一块白色陶瓷硬化帽（`#C9CED4`） | 切先本来就是为刺穿护甲设计的，硬化层不卷刃 | 贴图，可加 0.1 单位的薄层 |
| 回火色带：刃线内侧 2～3 条离散色带（稻草黄 `#D9B45A`、紫 `#7A5A9E`、蓝 `#4A6FA8`），越往刀尖越靠里 | 钢受热会出回火色，看得出刃口一直在发热 | 贴图（离散色带，不是渐变） |
| 鞘口修复梳齿：鞘口内侧一圈细齿 | 每次收刀，纳米梳刮掉血污、补平刃口 | 贴图；收刀时代码触发修复粒子 |
| 栗形做成充电口：鞘侧挂绳的小钮做成带橙色指示灯的接口 | 武装库给刀自动充电、修复，就从这里接入 | 小几何加贴图，指示灯发光（`sheath_luminous`） |

### 6.2 量子刃 `quantum`

**原理：** 刀身处在叠加态，同时“在”好几个位置；出刀时它坍缩到战甲标记过的目标上（代码画概率云、干涉条纹和坍缩）。实体上，刀镡是一块双缝板，相位就从两条缝里发出来；刀身是镜面研磨的钢，刃纹就是叠加态的干涉条纹。

**方向（用户定的，第三轮）：镜面刃 + 干涉刃纹 + 双缝刀镡 + 白陶瓷刀装。** 量子的概念放进日本刀最经典的地方：刃纹。它是三把里最冷、最精确、最优雅的一把，进攻性靠锐利的切先和干脆的棱线，不靠夸张的弯和发光管。三把刀的刀身颜色因此分成黑（纳米）、银（量子）、紫黑（奇点）。

**刀身（浅弯的太刀）**

- 长度：模板的 1.03～1.07 倍。
- **弯度浅而均匀**：中线从 10% 到 90% 下降 14～18（模板 21），弯沿全长平均分布，刀尖段不能突然下甩（第 3.0 节的“刀尖集中”检查）。宽约 9～10，厚 ±0.6～0.8。
- **材质是冷银色的镜面钢**，不是白陶瓷：鎬筋（刀身侧面的纵棱）把刀身分成上下两个面，靠刃口一侧的平地亮，靠刀背一侧的鎬地暗一档，色相冷暖错开（见下面的颜色表），像抛光的钢映着天空。
- **刃纹就是干涉条纹**：刃线内侧一条宽 4～6 像素的刃纹带，由青色亮带和暗银带交替组成，边界画成刃纹那样的波形（互の目或小乱刃的起伏）。条纹间距从刀根到刀尖逐渐收窄，像越来越接近确定态。亮带是发光的，暗带不发光。
- **刃线**：一条亮白加青的连续刃线（2 像素宽），发光。
- **不要**贯穿全长的发光樋，也不要刃线外侧的第二道线。只在刀根三分之一开一条短的棒樋（减重、增加刚性），樋底是暗银色，不发光。
- 刀尖：小而锐的切先，横手（刀尖和刀身的分界线）画成一条干脆的亮线。
- 刀镡：见下面的“双缝镡”。
- 刀柄：白陶瓷底，石墨蓝的菱形缠绳（柄巻，画在贴图上），中段左右各一颗小的六边形目贯（柄上的装饰钉），柄头是一颗小的菱形发射器。

**双缝镡**

- 一块薄的切角方形或木瓜形板（厚 3～4 单位），外径在第 3.0 节以内，白陶瓷边框加石墨蓝的板面。
- 板面上竖开两条平行的窄缝（沿 Y 方向，各宽约 1.5 单位，相隔约 3 单位，缝的位置在刀身上下两侧都看得到），缝里是发光的青色。这是双缝干涉，量子最经典的符号。
- 朝刀尖一侧的两角可以斜切，但不再做叉爪和方形卡子。

**刀鞘（白陶瓷刀装）**

- 白陶瓷鞘，沿刀身的浅弯分 4 段，接缝细（1 像素暗线），接缝里不发光。
- 鞘口一圈石墨蓝的金属箍，与双缝镡贴合；鞘口往下 30～40 单位有一小段干涉刻纹（一组竖线，间距逐渐变化），这一段的刻纹发光。
- 鞘侧一个栗形（挂绳的小钮），石墨蓝。
- 鞘尾是收敛的矛头尖（比现在短，10～12 单位），尖端一圈细的青色发射环。
- 整体要比刀身安静：亮的地方只有鞘口刻纹和鞘尾发射环。

**颜色**

| 用途 | 颜色 |
|---|---|
| 镜面钢：平地亮面 / 中间调 | `#E6ECF2` / `#C2CCD6` |
| 镜面钢：鎬地暗面 / 最暗 | `#8FA0B2` / `#5E6B7A` |
| 横手、鎬筋高光（偏暖） | `#FFF8EE` |
| 干涉刃纹亮带、刃线、双缝、发射环（发光） | `#4DE6FF`，最亮的芯 `#C8FAFF` |
| 干涉刃纹暗带 | `#6F8193` |
| 白陶瓷刀装：主色 / 中间调 / 暗部 | `#EDEDE8` / `#D6D7D2` / `#B4B6B3` |
| 石墨蓝（镡面、柄巻、鞘口箍、栗形） | `#2B3440` / `#5A6472` |
| 干涉的第二色（发光，极少量，只在刀尖观测点旁） | `#9B7CFF` |

**发光部位：** 刃线；干涉刃纹的亮带；双缝；刀尖观测点；鞘口干涉刻纹和鞘尾发射环（`sheath_luminous`）。物品栏里的辨识点是银色刀身上的青色刃纹和双缝镡。

**杀伤细节（第三轮加入）**

| 细节 | 道理 | 做法 |
|---|---|---|
| 切先是“观测点”：刀尖最前端一个单独的亮青色像素帽，旁边点一个紫色像素 | 坍缩斩从这里坍缩：测量发生在刀尖 | 贴图，`blade_luminous` 覆盖；B3 的坍缩特效从刀尖起始 |
| 干涉条纹越往刀尖越密 | 越接近确定态，刀尖切得越准 | 贴图 |
| 双缝镡就是相位发射器 | 拔刀时两条缝亮起，概率云从这里展开 | 贴图发光；B3 的概率云从刀镡发出 |
| 刀根的短棒樋 | 减重、增加刚性，让刀尖更快 | 浅几何或贴图，不发光 |

**断刀：** 断在刀身中段。断口是镜面钢的截面（亮银，带一条暗的心铁线），刃纹在断口处断开；断口处的刃纹不发光（叠加态塌了）。

**charge.png：** 两组倾斜方向相反的等距细线叠出来的干涉（莫尔）条纹，青 `#4DE6FF` 为主，交叉处点 `#C8FAFF`，偶尔一点紫 `#9B7CFF`；无缝平铺。

### 6.3 奇点刃 `singularity`

**原理：** 刀镡里关着一颗微型奇点，靠持续消耗 EU 的磁约束环维持；刀身是被它的引力压实的暗色物质刃，几乎不反光。击杀会给奇点“喂”质量；SA“事件视界”时约束短暂放开（代码画引力透镜、吸积盘和品红的霍金辐射爆发）。

**刀身（大太刀）**

- 长度：模板的 1.10～1.15 倍，最长的一把。弯度照模板或略深，刀尖带一点回钩（刀尖最后 15～20 单位再向刃口一侧勾一点）。宽可以取第 3.0 节的上限（约 11～12），厚仍然不超过 ±1。它长，但不是宽板。
- 刀身表面近乎纯黑的暗面，只在鎬筋（刀身侧面的纵棱）上留极少的冷色高光（像黑曜石，但更暗）。
- 刃线是一条品红的发光线，中间夹 1 像素白芯。刃线在靠刀镡的三分之一段做成断续的“裂缝”（像刀身里的光要漏出来），每段至少 2 像素宽。
- 刀镡：一个厚的约束环（扁圆环，截面带棱角，至少 8 段），环上 3 到 4 个线圈块；环中心是一颗暗色的球（奇点的外壳，实体，不是光晕）。环的外径在第 3.0 节以内，环的轴线沿 X（刀身穿过环心）。朝刀尖一侧可以伸出两根短爪，也收在外径以内。
- 刀柄：深灰金属，缠紫黑色带，柄头是一个小的第二约束环。

**刀鞘**

- 约束鞘：沿鞘分布 4 到 5 道磁线圈箍（箍只比鞘身高出 1～2 单位），箍之间的鞘身是暗色装甲，接缝透出品红。
- 鞘口一圈加厚的线圈环，与刀镡的约束环对接。
- 鞘尾是三根向后收拢的爪（像夹住什么东西的钳子），爪尖朝后。
- 鞘跟着加长的刀身弯，包住回钩的刀尖。

**颜色**

| 用途 | 颜色 |
|---|---|
| 暗刃主色 / 棱线冷高光 | `#0A0612` / `#3A3550` |
| 装甲暗部 / 中间调 | `#14101C` / `#2A2433` |
| 线圈箍金属 | `#4B4458`，高光 `#8C84A0` |
| 刃线、接缝、约束环光（发光） | `#FF2BD6`，白芯 `#FFE6FA` |
| 吸积热色（发光，少量，只在约束环内侧） | `#FF8A3D` |
| 奇点外壳 | `#050308`，一圈 1 像素 `#5B2A6E` 的边缘光 |

**发光部位：** 刃线和根部的裂缝；约束环内侧和线圈块的接缝；鞘的接缝和鞘口线圈环（`sheath_luminous`）。奇点外壳本身**不发光**（它是黑的，透镜特效由代码画在它周围）。物品栏里的辨识点是品红刃线和约束环。

**断刀：** 断在裂缝段的前端。断口画出崩开的暗刃，里面露出发光的品红内芯（这把刀断口反而亮），碎片上的刃线也保持发光。

**charge.png：** 向内旋的螺旋臂（2 到 3 条，像素阶梯画法），品红 `#FF2BD6`，内沿点 `#FF8A3D`；做成能沿鞘方向滚动的无缝平铺（螺旋臂在边界处接上）。
