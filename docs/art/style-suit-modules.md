# 套装模块美术规范

用户已定的方向（2026-11-24）：**量子模块是陶瓷白底配合图标，纳米模块是碳纤维黑底。** 两套和各自的套装对得上：量子套装物品图是浅灰白，纳米套装是深灰黑。

一句话：**每个模块是一块能插进套装的硬件，外形说明它属于哪套，图标说明它做什么，一个小指示灯说明它的功能色。**

## 1. 读法（为什么这样画）

物品栏里一眼要分出三件事，按这个优先级：

1. **哪一套**：靠底色和外形轮廓。白色方块 = 量子；黑色八角 = 纳米；黑白对角拼接 = 共用。
2. **什么功能**：靠中间的图标。图标要在 16×16 的原尺寸下认得出，宁可简单。
3. **哪一级**：Mk.II 有统一的金色标记（第 5 节），不靠换整体颜色。

## 2. 量子：陶瓷白

外形：**圆角方块**，主体约 14×14，四周留 1 像素透明边；四个角各切掉 1 像素做圆角。

| 用途 | 颜色 |
| --- | --- |
| 外描边 | `#1B1E24` |
| 釉面高光（左上边缘一线、左上角 2–3 像素亮点） | `#FFFFFF` |
| 陶瓷主色（大面） | `#EDEDE8` |
| 陶瓷中间调（靠右下的面） | `#D6D7D2` |
| 陶瓷暗部（右下倒角一线） | `#B4B6B3` |
| 接缝 / 面板分割线（可选，1 像素） | `#9A9DA2` |
| 图标线条 | `#2B3440`（深石墨蓝） |
| 图标的次要部分（可选） | `#5A6472` |

画法：

- 釉面感只靠两处：左上一线高光和左上角一个小亮点。不要大面积渐变。
- **图标用深色线条画在白底上**，线宽 1 像素为主，最多 2 像素。不要把整个图标涂成彩色。
- **功能色只用在一个指示灯上**：右下角一块 2×1 或 2×2 的小灯（批次清单给出每个模块的颜色），灯的左上加 1 像素更亮的高光（功能色往白调 40%）。
- 可以在底边画一排 1 像素的金属接点（像插卡的金手指），颜色 `#C9A55A` / `#8E7438`，这样一看就是“插进槽里的硬件”。是否画由你判断，但同一套要统一。

## 3. 纳米：碳纤维黑

外形：**八角形**（正方形四角各切掉 3 像素的斜角），主体约 14×14，四周留 1 像素透明边。轮廓和量子的方块明显不同。

| 用途 | 颜色 |
| --- | --- |
| 外描边 | `#0E1013` |
| 碳纤维斜纹（两色交替） | `#24282D` / `#1C1F23` |
| 边缘倒角高光（左上） | `#4A5058` |
| 边缘暗部（右下） | `#15171A` |
| 图标 | 该模块的功能色（批次清单） |
| 图标的辉光边（可选，图标外 1 像素） | 功能色与底色的中间色 |

画法：

- **碳纤维纹**：2×2 为一格的规则斜纹（编织图案），两种深灰交替，对比很低，远看是一块哑光黑。这是规则图案，不算噪点；不要做成随机颗粒。
- 图标要画在纹理之上并留 1 像素干净边，避免和斜纹糊在一起；必要时在图标下面垫一块纯底色 `#1C1F23`。
- **图标直接用功能色**，可以有一层更亮的中心（功能色往白调 40%），像发光的荧光线。黑底上彩色图标是这一套的特点，和量子“白底深色线条”正好相反。
- 不画金属接点（纳米是软的、贴身的）。

## 4. 共用模块：黑白对角拼接（用户已确认，2026-11-24）

共用模块（两套都能装）用**左上白、右下黑**的对角拼接：

- 外形用量子的圆角方块（它们是硬件卡）；
- 从左下到右上的 45° 对角线把底分成两半：左上半是量子陶瓷白（第 2 节颜色），右下半是纳米碳纤维黑（第 3 节颜色），交界处 1 像素描边色 `#1B1E24`；
- 图标跨在两半上，用**功能色**画，在白半边加 1 像素深色描边（`#2B3440`）保证看得清；
- 指示灯不画（图标已经是功能色）。


## 5. Mk.II 标记（两套通用）

Mk.II 和 Mk.I 用**同一个图标、同一个底**，只加一个统一的标记：

- **右上角两个金色小点**（每个 1×1，中间隔 1 像素，横排），颜色 `#F2C14E`，下面各垫 1 像素暗金 `#8E6A1F`；
- 再加一条 1 像素的金色镶边：量子在顶边，纳米在八角形的左上斜边，共用在顶边；
- 不换底色、不换图标颜色。

Mk.I 不画这些金色元素。整套里**只有 Mk.II 用金色**（量子的金属接点除外，它们是暗金，位置在底边，不会混）。

## 6. 其他配件

| 物品 | 归属与画法 |
| --- | --- |
| 框架核心（重力子壁垒、高级推进、太阳能阵列 I/II/III） | 量子的配件。**圆形**陶瓷外壳（直径约 13–14），中间嵌一颗功能色的晶核（直径 5–7，带 1 像素高光）。阵列 I/II/III 用同一个底，晶核旁边用 1、2、3 个深色刻点区分等级，**不用**金色 Mk.II 标记 |
| 量子扩展槽 | 量子陶瓷方块，中间画一个空的插槽（深色凹口）和一个小“+” |
| 活体纳米内衬 | 纳米碳纤维，但外形是**软的圆角布片**（四角圆、边缘有 1 像素缝线），上面一条功能色的“活体电路”曲线（绿 `#5DFFB0`） |
| 纳米晶格致密剂 | 纳米的耗材：一支碳纤维黑的小罐 / 安瓿，罐身一条功能色的窗（青 `#64FFDA`），罐口浅灰金属盖 |

## 7. 检查

`python3 tools/art/check_modules.py` 会检查：文件齐全、16×16、RGBA、alpha 只有 0 和 255、没有纯黑像素、每张图用色不超过 16 种、四周 1 像素边框全透明。
