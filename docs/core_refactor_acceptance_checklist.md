## 6. 本轮改动专项（务必验证）

这些项目涉及重构后的行为变化；其中一部分已有服务端自动化，仍需补齐实际放置、界面与完整机器链路的验收：

- [ ] **流体抽取不再回落输入罐**（炼油机、热源机、灌装机、斯特林动能机、蒸汽动能机）：用管道从机器侧面抽取，确认只能抽到产物流体，原料罐不被抽走。
- [ ] **蒸汽动能机的蒸馏水罐可灌入**：往它灌蒸馏水/水，行为符合预期（IC2 的 `SteamKineticGenerator` 亦允许）。
- [ ] **多方块结构**（GESU、大型制造机、流体反应堆）：能成形、能工作、破坏后能拆除；`onFormed`/`onBroken` 相关表现（日志、结构失效）正常。
- [ ] **UU 链路**：扫描一个物品 → 存入记忆晶体 → 复制机复制，全流程可用；报价数值与旧版一致。
- [ ] **构建器声明的流体罐**（附属路径）：罐数、容量、填充/抽取正确；未声明罐的机器不暴露流体能力。
- [ ] **储罐垂直成组**：两罐堆叠后容量翻倍，填充跨罐分布，抽取返回全部流体。

**预期/异常**：按上述描述工作；异常为原料被抽走、产物罐被灌入、结构不成形、数值偏差。
