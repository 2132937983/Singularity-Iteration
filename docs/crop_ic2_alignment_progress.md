# 杂交农业 IC2 对齐实施记录

日期：2026-09-29。基准：仓库内 IC2 Experimental `2.8.221-ex112` 源码，目标平台 NeoForge 1.21.1。初始问题见 [农业审计](crop_ic2_alignment_audit.md)。

## 存档与附属兼容

- 保留已有作物、种袋、方块和机器注册 ID；没有删除旧升级作物架或富集种子。
- 新 NBT 写入 `CropCycleVersion=1`。旧档内采用 IC2 周期的作物首次加载时，只清零旧单位的阶段进度；品种、已达阶段、G/G/R、扫描等级和补给储量继续保留。新格式再次加载保留进度。
- 作物架现在要求下方为耕地。原来直接种在矿物块上的布局需改成“作物架 → 耕地 → 根系范围内的矿物”，邻居更新会移除不合法布局。
- 管理器保留原有槽位和旧水箱数据。超过新 2000 mB 上限的旧储水不直接丢弃，消耗到新上限以下才能重新灌入。机器扫描游标新增持久化字段。
- `PlantType` 旧 tick 和默认生长单位不变；新增 `Ic2PlantType` 明确选择 IC2 周期。公开 API 只增加默认方法与语义别名，避免静默改变既有附属作物。
- `ICropSeedItem` 增加身份、G/G/R 和扫描读写默认方法，附属可覆盖自己的存储格式；分析仪菜单和界面均通过接口读取。[ForeignCropSeed](../src/addonExample/java/example/sicore/ForeignCropSeed.java) 是不依赖 common 的示例。

## 验证

执行命令：

```powershell
python tools/crop-audit/compare_catalog.py
.\gradlew.bat build runAddonGameTestServer --offline --console=plain --max-workers=2
git diff --check
```

**验证结果：构建、核心架构边界及示例编译通过；87 项必需 GameTest 全部通过（新增农业 15 项、既有 72 项）；`git diff --check` 无错误。** 最终构建及服务端结果见 `build/crop-final-validation.log`。农业专项 [CropAlignmentGameTests](../src/addonExample/java/example/sicore/CropAlignmentGameTests.java) 包含 15 项测试，覆盖：

1. 真实作物架交互、杂交状态、补给及四个花卉的种植成本。
2. Weed-EX 耗尽前后的邻株侵占。
3. 256 tick 周期与资源消耗。
4. 深层根系、空气截断和特殊 tick 后的阶段推进。
5. 环境不足死亡和高抗性存活。
6. 四亲本参与与单邻居扩散。
7. 20000 次高斯收成抽样、零产出和种袋属性保存。
8. 注册表与特殊阶段行为。
9. 旧进度迁移及新存档往返。
10. 管理器逐点扫描、三项补给和实际耗电。
11. Weed-EX 模拟排液无副作用、64 次总计 3200 mB 守恒。
12. 分析仪逐级收费、输出阻塞和附属自定义种子数据。
13. 收割机最优阶段、按掉落项计费和产物守恒。
14. 毒花、食人花和除草铲实际行为。
15. 作物架拆除不会被更新回调恢复。

## 适配边界与实机验收

- 1.21.1 的生物群系和 RNG 与 1.12.2 不同。环境类别通过现代标签适配，概率规则按原版复原，不承诺相同世界种子产生相同随机结果。
- 钛/铀、富集种子和升级作物架为项目扩展。旧升级架的 1.5/1.25 倍率 getter 没有接入 IC2 周期，不宣称存在原版加速效果。
- 油莓的第三方石油联动不在本轮实现范围；未引入不存在的石油模组依赖。
- 服务端 GameTest 不代替客户端目视验收：新机器面板、槽位点击、流体材质和作物模型仍需在实际客户端检查；也未加载用户的生产存档进行验证。
