# 加工机器界面规范（工况面板）

0.1.11.110 起，加工机器都用这套界面。0.1.11.118 按玩家反馈改版：框改回原版容器风格，左边恢复熔炉式的「输入 → 箭头 → 输出」和电量闪电，示意图改为像素画。读数和图表的内容不变。

实现：`common/client/screen/ProcessInstrumentScreen`（共用基类）、`VanillaFrame`（原版风格的框、槽位、凹窗、箭头和闪电）和 `common/client/suit/PixelCanvas`（像素画布）。各机器只画自己的示意图，再提供读数行。

## 尺寸与分区

- 界面 176 × 240（0.1.11.180 起是原版容器的宽度；0.1.11.120–0.1.11.179 是 248 × 240，更早是 204 高）。整块是原版容器的浅灰底（`#C6C6C6`），外缘黑色圆角描边，左上白、右下深灰的凸边。

## 像素示意图

- 示意图在 `drawFigure` 里照常用 `FcsDraw` 的图元（线、四边形、圆、圆弧、扇形）和 `FcsDraw.fill` 画，坐标仍以示意图中心为原点、半径约 40。基类在调用前打开一块 `PixelCanvas`，这些图元都被光栅化到整 GUI 像素上（1 格 = 1 像素，和槽位里的物品图标一样粗细），并按 0.75 缩放进凹窗。
- 每个图元是一个「部件」。有内部的部件，在压住后面东西的地方，左上边加亮、右下边压暗，像像素画那样有体积感；细线和小点不加边。
- 半透明的填充（发光）按透明度混合，不算部件。
- 示意图里不要直接调用 `g.fill`，也不要贴流体或物品贴图：画布在示意图画完以后才画出来，会盖住它们。要贴图的放到 `drawOverFigure` 里画（0.1.11.141 起）。

## 从容布局（0.1.11.141 起，逐台迁移）

按「高级感」评审改的布局：从容（元素少、焦点集中）、秩序（信息分级，越重要越大）、克制（描边刚好够用）。0.1.11.141 先用在装罐机，0.1.11.143 起所有加工机器默认使用（`calm()` 默认返回 true，旧布局留在开关后面）。

- **原版描边**：外框、物品槽和示意图窗（0.1.11.142 起示意图窗改回原版凹边、槽灰底，和打粉机一样；0.1.11.141 的平底窗像个洞）。读数区不再有窗，文字直接写在面板上。
- **示意图部件不加亮暗边**（`PixelCanvas.flat()`），部件只用两档浅灰：框 `#C9CED0`、内腔 `#E6E9E7`；工作中的管道用钢色，不工作的用 `#ADB3B5`。
- **空槽画虚影**（0.1.11.142，`ghost`）：该放的物品盖一层 70% 的槽灰，随模式变化；鼠标停在空槽上提示放什么。当前模式不用的槽用 `slotShown` 连槽框一起隐藏（槽里有东西时照常显示）。机器重写 `slotGhost` 和 `slotHint` 给出各槽的虚影和提示；电池槽 (10, 56) 由基类处理。
- **需要贴图的东西画在画布之后**：`drawOverFigure` 在像素画布输出后调用，坐标用 `figPx(中心, 偏移)` 换算到屏幕。流体用 `VanillaFrame.fluid` 平铺 still 材质并着色（装罐机的两个储罐）。
- **三级文字**，全部原版字体：
  1. 主信息（`headline()`）：2 倍原版字，(8, 100)，正文深色。
  2. 右侧同一行（y 104）：运行时是进度百分比，停机时是原因（故障红色，等待灰色）。`headlineBar()` 有值时，条形画在两者之间，7 像素高，和字的大写行对齐。
  3. 读数行：y 122 起，每行 12，最多 3 行；第一行正文色 `#404040`，其余淡灰 `#80868A`。没有内容的行不写（例如空着、也不在本模式工作的储罐）。
  4. 主读数不截断：主读数（2 倍宽）加右侧文字放不进一行时，右侧文字下移成第一行（保持它的颜色），读数顺延，第三行以后不画。
- **按钮**改成示意图窗右上角的 11 × 11 小图标（现有 `ICON_CYCLE` 切换模式、`ICON_SWAP` 交换、`ICON_XP` 收集经验、`ICON_FLAME` 保温、`ICON_LOCK` 锁定转速；开关类按钮开着时画成按下）（`iconButton`，图标是 7 × 7 的像素画，不用字体里的箭头字符，它们大小不一），名字和说明放进鼠标提示。
- **标题**在左边 (8, 6)，不画状态灯，也不画左上角的升级提示「i」（空升级槽的鼠标提示说的是同一件事）。

## 对齐（0.1.11.141）

- 进度箭头 x 32：左边输入槽外缘到 27、右边输出槽外缘从 60 起，箭头两侧各空 5 像素。

0.1.11.121 起，发电机的读数行也写在示意图窗下面的原版灰底读数窗里（`ReadoutPanel`），原版字体，按「·」分段自动换行；底部储量条用 `VanillaFrame.labelledBar`（熔炉式白条）。界面高 244，物品栏在 (44, 162)，快捷栏 y 220。

0.1.11.144 起发电机也用从容布局：读数不再套窗，文字从示意图窗左边缘起直接写在面板上；第一条正文色，后面的淡灰色，状态色保留；标题靠左，没有状态灯和升级提示（`calmChrome()`）。示意图窗和图表窗保持凹边纸白底。

0.1.11.181 起发电机也是 176 宽的合并布局（见下面"发电机的合并布局"）。

0.1.11.145 起：

- **主读数**：发电机在 `drawWindow` 里调用 `ReadoutPanel.headline(主读数, 状态, 状态色)`。主读数是输出（EU/t、KU/t、HU/t 或 mB/t），2 倍原版字；状态写在同一行右边，放不下时下移成第一行。下面最多四行，第一条正文色，其余淡灰。

## 合并布局（0.1.11.175 装罐机先行，0.1.11.176 起全部加工机器，0.1.11.178 起每台画自己的机器）

原来示意图凹窗占了面板右边三分之二，画的却是个简单的示意图；真正要操作的槽位挤在左上角一小块。合并布局把两者合在一起：机器直接画在面板上，槽位就在机器图里该在的位置。

- 基类开关 `merged()`：打开后不画示意图凹窗和左边的熔炉区，改由 `drawMerged(g, x, y, dt)` 在槽框之前把整台机器画在面板上半部（0.1.11.180 起 x 8–168，原来 x 8–240；y 17–95）。下面的大读数、读数行和物品栏不变。
- 闪电、箭头、图标按钮的位置和悬停区由子类提供：`boltX/boltY`、`arrowX/arrowY`、`iconButtonX/iconButtonY`；示意图的悬停提示改为 `mergedTooltip(rx, ry)`，按部件返回（如储罐的流体和存量）。
- 槽位坐标改在菜单类里（例如 `CannerElcMenu.MATERIAL_X` 等常量），界面按同一组常量画机器。
- 像素部件用 `MachineArt`：`steel`（凸起钢件，左上亮、右下暗）、`tank`（钢壳 + 凹玻璃仓 + 流体贴图 + 高光 + 刻度）、`pipeH/pipeV`（4 像素管道，工作时内部是水，运转时有亮点流动）。1 个美术像素 = 1 个 GUI 像素。
- 电池槽离开了熔炉区的固定位置，基类按坐标认电池槽的方法认不到它，合并界面要自己在 `slotGhost`/`slotHint` 里给电池槽的虚影和提示。

装罐机：左右两端是整高的输入、输出储罐；中间顶上是料斗（材料槽，电池模式下关闭），下面是灌装头，喷嘴下是罐子槽和底座；箭头指向右边的输出槽；最左边是闪电和电池槽；模式、对调两个图标按钮竖排在最右边（0.1.11.180 起面板变窄，右储罐靠右边缘，按钮改为横排在料斗右边）。当前模式用到的管道里是水：「储罐→单元」和混合是左罐到灌装头，「单元→储罐」和混合是灌装头到右罐。

0.1.11.176 起所有加工机器都用合并布局（`merged()` 默认打开）。0.1.11.176 的其余 13 台只是模板：输入列、钢壳凹窗里的旧示意图、输出列三段并排，并没有融合。0.1.11.178 起每台机器都像装罐机一样画自己的机器，槽位嵌在机器结构里（坐标见 `common/menu/MergedSlots` 的嵌套类，每种机器图一个）：

- **原则**：输入槽放在机器接料的地方（料斗里、压机模台上、炉膛炉床上、工作台进料端）；运动部件画在机器本体上原地运动；输出槽放在出料口的托盘或料架里，前面是进度箭头；电池在左下角，闪电紧贴其上，铜芯电缆从电池接到电机、泵或加热控制器。
- **实现**：基类 `drawMerged` 在面板上半部（x 4–172，y 15–99）开一块 1:1 的平涂像素画布（`PixelCanvas`，坐标用面板坐标），调用子类的 `drawMachine(g, dt)`，再画闪电和箭头；槽框随后画在机器图上面。`MachineArt` 的部件都经 `FcsDraw.fill` 绘制，所以在画布里和圆盘、转动的叶片等按顺序叠放：`iron`（深色铁件）、`sunk`（凹进去的部件）、`hopper`（料斗：槽外一圈钢领 + 收窄的喉部）、`tray`（输出托盘：两侧挡板 + 底）、`rack`（三格输出料架）、`cable`（电缆）、`motor`（带散热片的电机）、`gauge`（不用流体贴图的液位柱）。流体贴图不能进画布，装罐机的储罐仍直接画在屏幕上。
- 悬停：`machineBody()` 给出机器本体的矩形，鼠标在上面显示原理提示（鼠标在槽位上时只显示槽位自己的提示，0.1.11.179）；储液柱等部件在 `mergedTooltip` 里单独给提示。感应炉两路各有一个箭头，`overArrow` 都认。
- 图标按钮竖排在面板右上角（x 153，y 19 起每 13 像素一个，编号大的在上）；装罐机的两个按钮横排在料斗右边 (106, 19)、(119, 19)。
- 0.1.11.180 起面板宽 176（原版容器宽度）：机器图都在 x 8–168 之内，输出托盘和料架靠右边缘，右上角留给图标按钮。

## 规则

1. **原版风格的框。**面板、槽位、凹窗、条形和按钮都按上面的颜色画凸边和凹边，文字用原版字体，不缩小。
2. **示意图要动，并且是像素画。**画机器真实的工作部件，并且和机器状态同步：转速、是否运转、热量等。不用帧动画贴图。
3. **示意图要画对机器。**打粉机是锤式破碎机：俯视圆形腔体，转子上四个锤头，外圈是筛板。旋风打粉机是风扫磨：外圈磨环和三个磨辊，中间是分级叶轮。其他机器各按自己的原理画。
4. **输入、输出和电要一眼看清。**左边熔炉区固定：输入在左上，电池在左下，闪电显示储电，箭头显示进度并指向输出。
5. **读数列固定顺序**：第一行是主读数（大字：转速、温度或「运转中」），然后依次是材料与本次能耗、功率与工时、机器特有的读数，最后是状态。状态用颜色区分：运行为绿色，等待为次要文字色，缺电、输出已满等停机原因为红色。
6. **停机原因要写出来**：运行、等待输入、没有配方、输出已满、缺电、被红石关闭等。服务器算好状态码，经菜单数据同步过来。
7. **数值都由服务器经菜单数据同步**，界面不读客户端的方块实体。菜单数据是 16 位，超过 32,767 的数要拆成两项或用千分比。
8. **按钮**：原版式凸起按钮，竖排在读数行右边（`buttonCount()` 告诉基类留出按钮列）。悬停时变亮，开着时凹下去、白字。
9. **提示**：鼠标悬停在示意图、读数和按钮上时，用一两句话说明原理和数值的含义。
10. 文字走语言文件 `gui.mio_icif.process.*`，中、英、日、俄四种语言同时更新。

## 发电机的合并布局（0.1.11.181）

以前改过界面的其余机器也合并并收窄到 176：`MimicScreen` 的全部子类（蒸汽链、斯特林、动能、水力、地热、地磁、焚化、经验、RTG、量子发电机）、柴油机（`EngineScreen`）、太阳能板、热能、风力、风力动能发电机，以及分子重组仪、粒子聚合机和泵。核反应堆和聚变堆保持原样。

- **区域**：机器画在面板上 x 8–168，Mimic 系列和柴油机 y 15–77（像素画布，1:1 平涂），读数从 y 80 起高 62，底栏 y 145，物品栏 (8, 162)。热能发电机的图高到 y 110（圆盘记录纸半径 40），分子重组仪 (8, 122)，粒子聚合机和泵是 176 × 240、物品栏 (8, 160)。
- **槽位**：坐标在各自菜单类里（如 `CondenserMenu.VENT_X`、`GeoGeneratorMenu.CONTAINER_X`、`RTGeneratorMenu.PELLET_X`、`EngineMenu.BATTERY_X`、`SolarPanelMenu.slotX`），界面按同一组常量画机器。容器槽：空的在灌装头（`MachineArt.filler`）上方，满的在下方；发电机的电池在输出电缆（`MachineArt.euCable`，有电时黄色电流跑动）尽头。
- **部件**：`MachineArt` 新增 `pipe/pipeDown`（任意介质颜色）、`level`、`shaft`、`flywheel`、`generator`、`coupling`（KU 输出）、`euCable`、`turbine`、`thermometer` 与 `mark`、`flames`、`filler`、`temperature`。斯特林机本体是 `StirlingScreen.engine`，RTG 铅容器是 `RtgScreen.container`。
- **图表**留在纸上（`ChartView`、风玫瑰、圆盘记录仪、日照记录等），缩窄后放在机器旁边；图表旁重复的数字去掉。机器图里不写和大读数重复的数值。
- **提示**：`MimicScreen.overMachine` 在鼠标位于槽位上时返回 false（槽位只显示自己的提示）；读数行放不下时（`ReadoutPanel.end` 返回完整内容），鼠标停在读数区显示全部。
- **锅炉**的压力和给水是机器图里的调节器 [−] 数值 [+]：一次 1，Shift 10，Ctrl 100，两者 1,000，或滚轮。
