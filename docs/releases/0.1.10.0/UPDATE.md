# 0.1.10.0 更新说明：量子套装模块系统 Q1（量子行动基础）

基于 0.1.9.2（`pr-0.1.9.2-20261014`）。按已批准的提案 v1（`quantum_proposal.md`，全部采用推荐方案）实现第 1 阶段 Q1：相干度资源与退相干、V/B 行动键整合、5 种主动行动、扩展槽、FCS HUD 与特效。构建环境为 Gradle 8.10.2、JDK 21、NeoForge 21.1.218，离线构建。

## 1. 相干度（Coherence）

* 量子行动的资源，0..上限（100；每个相干电容器 +50）。显示为准星周围的相干度环。
* 最后一次行动 30 tick（1.5 秒）后自动回复，每秒 8 点（相干电容器 +25%）；每点从套装共享能量池支付 2 500 EU。持续型行动运行中与退相干期间不回复。
* 只有在穿戴的量子部件上装有行动单元或相干电容器时才回复（量子核心“在线”）。
* **退相干**：行动或持续消耗使相干度降到 0 时，核心退相干 80 tick（4 秒）：拒绝一切行动，运行中的力场消失，HUD 出现故障效果（色差、撕裂、噪点，可在客户端关闭为温和提示），传感器刷新减半。
* 相干度保存在玩家附件 `mio_icif:quantum_core`（死亡后保留）。退相干、运行中的行动与跃迁充能不保存；玩家下线、死亡或换维度时，所有运行中的行动结束并撤销对世界的改动（力场释放投射物，时间扭曲收回属性修饰符，慢动作恢复）。

## 2. 行动键

* 量子行动与纳米爆发共用 **V / B** 两个键与同一套分配（奇点管理面板）：选中量子部件后，新的“量子核心”分区显示单元槽、相干度与两个键行，点击键行循环选择（自动 / 各可用行动 / 无）。
* 可用列表 = 纳米部件上的爆发单元 + 量子部件上的行动单元（混合套装两者都可选；资源各自独立：纳米用储备/热量，量子用相干度）。
* 默认自动分配按优先顺序取前两个：量子跃迁、相位偏移、力场展开、时间扭曲、纠缠齐射，然后是附属行动。
* 服务器入口统一：`NanoBursts.request` 发现键上是量子行动单元时交给 `QuantumActions.request`。客户端对量子键先做本地判断（退相干、相干度不足、冷却），服务器再次检查。

## 3. 五种行动（服务器配置 `QuantumSuit` 可调）

| 行动 | 来源单元 | 相干度 | 冷却 | 效果 |
|---|---|---|---|---|
| 量子跃迁 | 相位跃迁驱动器（护腿/靴子，新） | 25 | 每次充能 50 tick | 瞬移到视线所指位置，12 格（Mk.II 20 格、2 次充能）；跃迁后 10 tick 免摔落 |
| 相位偏移 | 相位调制器（胸甲，新） | 35 | 160 tick | 20 tick（Mk.II 30 tick）内生物、投射物、爆炸伤害穿透；投射物穿身而过；不受击退；不能攻击、射箭、挖掘；Mk.II 结束时 4 格冲击波（4 伤害 + 击退） |
| 力场展开（开关） | 量子偏转器 Mk.II | 启动 15，之后每秒 10 | 落下后 120 tick | 半径 4 格的力场罩：敌方飞行中的投射物停在空中（落下时恢复重力掉落），火球等自推进弹在罩上爆散；敌对生物被推出 |

规则细节：

* **量子跃迁不穿墙**：眼睛高度的视线、脚部、腰部、眼部三条到落点的线都必须畅通，落点需容得下身体（尝试最多 1.8 格的抬升），落点不能有岩浆或火，区块已加载且在世界边界内；找不到落点时拒绝（HUD 显示 NO PATH），不消耗相干度。传送使用 `/tp` 相同路径（服务器移动并通知客户端）。
* **相位偏移**：只免除生物与投射物造成的伤害以及爆炸；岩浆、火焰、溺水、饥饿、摔落、虚空与 `/kill` 照常生效。
* **力场**：再次按键收起。只拦截飞行中的投射物（插在地上的箭不受影响）；穿戴者自己、盟友、自己的僚机与宠物的投射物不受影响。
* **时间扭曲**：游戏对所有人只有一个时钟，因此为局部减速。可选的“单人真实慢动作”（`realSlowMotion`，默认关闭）：仅在单人且无其他玩家在线时把服务器 tick 速率降为 `realSlowMotionTickRate`（默认 8），结束、下线、服务器停止时恢复。
* 对玩家的效果仅在服务器开启 PvP 且对应开关打开时生效（默认开启）：`phaseShockHitsPlayers`、`fieldAffectsPlayers`、`dilationSlowsPlayers`、`volleyHitsPlayers`。
* 每个行动与相干电容器都有开关（`actions` 分区）；关闭后单元保持安装，Mk.I 偏转器与预测器保留原有被动效果。

## 4. 新物品与改动

* 新单元：相位跃迁驱动器、相位调制器、相干电容器（护腿/靴子，被动：上限 +50、回复 +25%）、量子纠缠中继器。
* 新 Mk.II：量子偏转器 Mk.II（每点伤害 3 000 EU，原 4 000；增加力场行动）、行为预测器 Mk.II（增加时间扭曲；路径与攻击预告不变）、相位跃迁驱动器 Mk.II、相位调制器 Mk.II。配方沿用纳米 Mk.II 模式（中子板 + 生体电路 + 主题材料）。
* **量子扩展槽**：放入通用套装改装台单元槽与量子部件一起，部件 +1 单元槽（头盔 5、胸甲 4、护腿 3、靴子 3），每件 1 个，永久。存于新数据组件 `mio_icif:suit_bays`；没有该组件的部件保持原槽数。改装台显示紫色扩展槽格并在放入扩展槽时预览；已扩展时状态为“已装有扩展槽”。
* 新单元配方：量子级（铱板、精英电路、兰波顿晶体或主题原版材料：末影之眼与回响碎片、幻翼膜、能量水晶、追溯指针、潜影壳）。
* 单元提示框显示行动名、相干度消耗与冷却；Mk.I 偏转器/预测器显示“Mk.II 解锁行动”。

## 5. HUD 与特效（华丽至上）

* **量子核心 HUD**（新 GUI 层 `quantum_hud`）：36 段相干度环（青→紫渐变），两层反向旋转的干涉虚线环，回复时边缘彗星光点，V/B 消耗刻度；退相干时红色闪烁、“DECOHERENT”与恢复进度条，整个环随机横向跳动。无纳米核心时显示 V/B 行动芯片（共用纳米芯片的冷却扫掠、就绪呼吸、拒绝红叉与原因），跃迁 Mk.II 的充能菱形与回充条；相位偏移、力场、时间扭曲的计时条。
* 全屏提示：跃迁白闪与放射光线；相位偏移时紫/青干涉条纹从边缘渗入与“OUT OF PHASE”；时间扭曲的紫色暗角、由中心扩散的慢波纹与旋转指针；退相干故障（撕裂带、色差边、噪点块）。
* **FCS 面罩启动序列**：HUD 开启时（戴上头盔、HUD 键、首个 HUD 单元）视野从一条横线展开（CRT 开机）、扫描线下扫、准星校准环收拢、左侧启动日志逐字打出，伴随启动音；退相干时整个 FCS HUD 抖动并出现红/青色差框。
* **世界特效**（共用纳米效果管线：场景折射、全息网格、加法光）：
  * 量子跃迁：出发点身体坍缩成紫色光点，路径上 4 个全息残影，透镜扭曲光迹，落点先内爆再向地面扩散冲击环，透镜星芒。
  * 相位偏移：身体化为在洋红与青色间拍频的全息体并折射背景，扫描环沿身体上行，双螺旋干涉线，洋红残影；Mk.II 结束时紫色冲击波与电弧。
  * 力场：晶格穹顶从穿戴者长出，边缘按菲涅尔规律折射背景并增亮，六角波纹流动；每个被拦下的投射物在穹顶上激起涟漪并悬停在停滞环中；落下时闪烁消散。
  * 时间扭曲：随穿戴者移动的透镜气泡，地面钟盘（60 刻度、两根慢速指针），力场内投射物的紫色长拖尾，被减速敌人脚下的时间锁环，缓慢漂浮的光点。
  * 纠缠齐射：穿戴者到各僚机的双螺旋纠缠线，枪口蓄能，每架僚机 3 枚沿贝塞尔曲线弯曲飞行、同时命中的光弹，目标上收缩的倒计时环（金→红），命中闪光、冲击环与星芒。
  * 退相干：身体上爬动的红色静电电弧。
* 12 个合成音效（`tools/sfx_1100.py`）：跃迁、相位开/关、力场开/关/拦截、时间扭曲开/关（磁带减速/加速）、齐射指令/命中、退相干、面罩启动。
* 客户端选项（`quantum_suit` 分区）：`quantum_hud`、`visor_boot`、`quantum_fx_intensity`（0.25..1.5）、`decoherence_glitch`；`reduced_flashes` 同样减弱闪光。

## 6. 公共 API（只增不改）

* 新类型：`SuitActionSpec`（相干度消耗、冷却、是否持续、每秒消耗）、`SuitActionBehavior`（`fire`、可选 `sustain`、`end`）、`SuitQuantumActions`（注册与查询附属量子行动）、`SuitQuantumCore`（相干度、上限、退相干的只读视图）。
* 附属单元仍用 `SuitModuleRegistry` 注册；再用 `SuitQuantumActions.register(unitId, spec, behavior)` 增加行动。未注册行动的单元行为不变。
* 示例：`ExampleSonarUnit` 增加“深度声呐”行动（15 相干度、10 秒冷却）。
* 已有公共类型与签名均未改变（javap 比较 0.1.9.2 与 0.1.10.0 的 api 与 core 两个 jar：327 个类，0 个成员丢失）。

## 8. 修复：指南页的 HTML 注释（0.1.9.1 起）

* 0.1.9.1 的指南生成工具在 9 个页面（机器索引、武装库、感应炉 × 中英日）插入了 `<!-- 0.1.9.1 -->` 标记。GuideME 按 MDX 解析，禁用了 HTML（`htmlFlow`/`htmlText`），`<!--` 会被当作 JSX 标签并报错（“to create a comment in MDX, use `{/* text */}`”），这些页面在 0.1.9.1 与 0.1.9.2 中无法打开。已在 GuideME 21.1.17 的 `MdxSyntax` 中确认。
* 修复：删除所有标记注释；`tools/guide_191.py` 与新工具改为按标题内容判断是否已插入；`check_191.py` 改为检查标题并报告任何 HTML 注释（对 0.1.9.2 运行时正确报出 9 个页面）；新检查 `check_1100.py` 把 `<!` 视为错误。
