# 0.1.10.1 更新说明：量子套装模块系统 Q2（纠缠与协同）

基于 0.1.10.0（`pr-0.1.10.0-20261014`）。按已批准的提案 v1（`quantum_proposal.md`）实现第 2 阶段 Q2：纠缠链接、9 种单元间协同、3 种时机连击、演算带宽系统、量子演算核心、其余量子 Mk.II、六角单元护盾，以及相关 UI 与特效。构建环境为 Gradle 8.10.2、JDK 21、NeoForge 21.1.218，离线构建。

## 1. 纠缠链接

* **链接中枢**是穿戴中的量子胸甲：链接以单元键列表保存在胸甲的新数据组件 `mio_icif:suit_links` 上（缺省 = 无链接，与 0.1.10.0 相同）。
* 容量：2 条；量子演算核心启用时 3 条。不穿量子胸甲时任何协同都不起作用。
* 一对单元都必须安装在**穿戴中的量子部件**上（纳米部件上的共用单元不计）；两个单元都开启并有供电时协同才生效。
* 更换单元后链接保留在胸甲上，单元装回即恢复；超出容量的链接保留但不生效（矩阵中显示 OVER CAP）；指向已移除模组单元的链接保留但不起作用，也不占容量（新增链接时清理）。
* 服务器校验每次切换：无中枢、单元不全、容量已满、未知协同分别以结果码回复客户端（`quantum_link_result`），客户端显示原因并播放拒绝音。

## 2. 纠缠矩阵（链接编辑界面）

* 打开方式：奇点管理面板 → 选中量子胸甲 → “量子核心”分区新增的 **链接** 行（显示已用链接/容量与 QB 负载，点击打开）。没有放在改装台，是因为只有面板能同时看到所有穿戴部件。
* 左侧：穿戴量子部件上的单元作为节点排成圆环（物品图标 + 单元颜色的菱形框，生效时呼吸）。可链接的一对为淡虚线；已链接但单元未生效为实线；生效中的协同为脉动的双螺旋光线（协同颜色 + 白色副链）。
* 右侧：全部协同（内置 9 种 + 附属注册的协同）及状态：LINKED / READY / OFFLINE / OVER CAP / MISSING；点击行切换链接，悬停显示名称、说明、所需单元与上一次的拒绝原因。
* **拖动连线**：把一个节点拖到另一个节点上，拖动中光线跟随鼠标；悬停在有协同的一对上时显示协同预览（名称、效果、“松开以链接/解除”），松开即切换；没有协同的一对显示提示并播放拒绝音。
* 底部：链接数/容量（或“无链接中枢”）、QB 负载/预算与负载条（超出时变红）。

## 3. 九种协同（服务器配置 `QuantumSuit` → `synergies` 每种一个开关）

| 协同 | 单元 | 效果 |
|---|---|---|
| 预测诱导 PGD | 智能弹道诱导 + 行为预测器 | 诱导弹按预测位置拦截：生物沿寻路路径节点按当前地速预测，三次迭代求解拦截点；转向 +4°/tick（Mk.I 14→18，Mk.II 20→24）；锁定 +2（Mk.I 6→8，Mk.II 10→12） |
| 威胁透视 TSI | 生物扫描仪 + 威胁传感器 | 正在追猎你的生物发出红色轮廓（穿墙），并以圆环倒数其攻击到达时间 |
| 地脉全息 OHL | 战术全息地图 + 地震矿物扫描仪 | 扫描到的矿石以 3D 体素显示在全息地图与战术地图中（战术地图切片时隐藏切片以上的矿石） |
| 弹道同步 BSY | 弹道计算机 + 智能弹道诱导 | 锁定时间 −30%；向每个锁定目标绘制下一发诱导弹的琥珀色点状弹道 |
| 爆心预报 BFC | 爆炸预警计时器 + 行为预测器 | 即将爆炸的 TNT/苦力怕显示 3D 线框爆炸球与“EVADE”撤离箭头 |
| 共振偏转 RDF | 量子偏转器 + 力场共振解体 | 偏转器挡下伤害的 25% 蓄积为共振，达到 8 时爆发：以蓄积量对 4 格内敌对生物造成伤害并击退 |
| 残像诱饵 DCY | 相位跃迁驱动器 + 行为预测器 | 跃迁在出发点留下诱饵 40 tick：24 格内原本追猎你的敌对生物失去目标、走向诱饵，期间不能重新以你为目标 |

* 数值（`synergyTuning` 分区）：`resonanceShare` 0.25、`resonanceThreshold` 8、`resonanceRadius` 4、`decoyTicks` 40、`phaseCounterMaxDamage` 20、`quantumTunnelWindowTicks` 20、`frozenVolleyDamageFactor` 1.5。

## 4. 三种时机连击（无需链接）

* **量子隧穿**：量子跃迁后 20 tick 内的相位偏移只消耗一半相干度（每次跃迁一次）。
* **冻结齐射**：在自己的时间扭曲中下达纠缠齐射：被减速的生物（最多 8 个）加入目标，无需 12 tick 充能、立即同时命中，伤害 ×1.5。
* **静止弹幕**：用按键收起力场时，力场中停住的投射物以捕获时的速度飞回射手（射手不在时原路反向），归属改为穿戴者。因断电或退相干而落下的力场不触发。
* 触发时：HUD 横幅（QUANTUM TUNNEL / FROZEN VOLLEY / STATIC BARRAGE）、专属音效与世界特效（隧穿：紫色三重收缩旋涡环；冻结齐射：金色“时停”球面闪光与钟面刻度；静止弹幕：蓝色爆发环与放射火花，回飞弹体带蓝色光迹）。

## 5. 演算带宽（QB）

* 量子部件上每个生效的单元占用套装计算机；同一单元装在两个部件上只计一次；量子 Mk.II 多占 1 QB。
  * 3 QB：生物扫描仪、行为预测器、全息地图、矿物扫描仪、相位调制器、纠缠中继器
  * 2 QB：智能诱导、威胁传感器、相位跃迁驱动器
  * 1 QB：弹道计算机、爆炸预警、电网遥测、偏转器、力场共振
  * 0 QB：其他单元；附属单元除非用 `SuitBandwidth.register` 注册，否则为 0
* 预算 20 QB，量子演算核心启用时 28 QB。
* **既有配置不受影响（已穷举证明）**：`check_1101.py` 读取 0.1.9.2 的单元表与基础槽数 4/3/2/2，枚举全部 22 176 种合法量子配置，最重为 20 QB（头盔 ESP+预测器+全息地图+诱导 11，胸甲 威胁+爆炸预警+偏转器 4，护腿/靴子 矿物扫描+遥测+共振 5），等于预算；并确认 0.1.9.2 中这些计费单元都没有 Mk.II。
* 0.1.10.0 起新增的行动单元、扩展槽与 Mk.II 可以超出预算（信息：0.1.10.0 条件下理论最重 33 QB）。这是提案的设计：超出时**演算饱和**——传感器刷新减半（客户端）、相干度回复速度减半（服务器），不会关闭任何功能。
* HUD：准星上方 12 段 QB 表，饱和时变红并显示 SATURATED；纠缠矩阵与面板行同样显示。

## 6. 新物品与 Mk.II

* **量子演算核心**（胸甲/护腿，6 EU/t，量子专用）：预算 +8 QB，链接 +1。配方：铱板、比较器、精英电路、兰波顿晶体、能量水晶。
* 其余量子 Mk.II（配方沿用纳米 Mk.II 模式：中子板 + 生体电路 + 主题材料 + Mk.I 单元，均为 −20% 耗电）：
  * 地震矿物扫描仪 Mk.II（望远镜）：半径 24（原 16）；面板新增“矿石筛选”行，在“全部”与游戏已知的各 `c:ores/*` 标签间切换（客户端显示筛选；切换后重新带脉冲扫描）。同时修复：回波波前与矿石显示按实际扫描半径计算（此前固定为 16+2，Mk.II 的远处矿石不会显示）。
  * 电网遥测传感器 Mk.II（侦测器）：沿视线读取 36 格内的方块（Mk.I 仅触及范围）。
  * 生物扫描仪 Mk.II（幽匿感测体）：48 格（原 32），目标卡显示精确生命值与护甲值。
  * 弹道计算机 Mk.II（弩）：多重射击弩额外显示左右 10° 两发的弹道。
  * 智能弹道诱导 Mk.II（指南针）：锁定 10（原 6），转向 20°/tick（原 14）。
  * 力场共振解体 Mk.II（钟）：半径 3.75（原 2.5），每 tick 最多 9 个方块（原 6）。
  * 全息地图 Mk.II 按提案随 Q3 的 3D 全息台推出。
* 单元提示框新增：演算带宽（QB）、演算核心加成、该单元参与的协同及搭档单元。

## 7. HUD 与特效（华丽至上）

* **六角单元护盾**（偏转器受击）：频率 4 的测地球面 162 个六角单元，从着弹点扩散的波前逐个点亮并柔和填充；颜色随套装电量：青色、低于 50% 琥珀、低于 25% 红；低于 50% 时越来越多单元破裂（缺边、锯齿裂纹、闪烁）；原光子屏障的棱镜色边保留为外层淡壳。受击包 `ShieldHit` 末尾追加电量字段。
* 链接光线：每个生效的协同在穿戴者身上以其颜色绕身体从一个部件到另一个部件的光线（第三人称与其他玩家可见）。
* 准星旁的协同芯片（三字母代码、协同颜色、缓慢扫光）；连击横幅（斜光条滑入、1.5 秒淡出）。
* 共振爆发：地面驻波环、紫色光柱、连向每个被击中生物的电弧；相位反击冲击波偏红加粗。
* 残像诱饵：脉动地环与 V 形标记、从诱饵连向被吸引生物的红色牵引线、闪烁的全息残影，结束时消散粒子。
* 舰队数据链：僚机看到的每个生物头顶青色菱形，被标记的目标有旋转双环。
* 弹道同步：琥珀色点状诱导弹道；威胁透视：红色穿墙轮廓与倒数环；爆心预报：线框爆炸球与撤离箭头；地脉全息：全息地图/战术地图矿石体素。
* 4 个合成音效（`tools/sfx_1101.py`）：链接建立（两音滑入同度）、链接断开（同度分裂）、连击（上行琶音 + 和弦）、共振爆发（非谐泛音金属钟声 + 低频冲击）。

## 8. 公共 API（只增不改）

* 新类型 `SuitSynergies`：`register(id, unitA, unitB)`、`get`、`all`、`active(player, id)`；附属协同出现在纠缠矩阵中，效果由附属实现。
* 新类型 `SuitBandwidth`：`register(unitId, cost)`（0..16）、`cost`、`load`、`budget`。
* 已有公共类型与签名均未改变（javap 比较 0.1.10.0 与 0.1.10.1 的 api 与 core 两个 jar：334 个类，0 个成员丢失；新增 6 个类，含内部类）。API 指南新增 3.6 节；两个新类加入三语注释清单（`all` 模式）。
