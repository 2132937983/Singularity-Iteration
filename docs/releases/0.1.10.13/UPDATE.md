# 0.1.10.13 更新说明：GitHub issue #18（爆炸破坏机器时崩溃）与僚机持物手部抖动

基于 0.1.10.12（`pr-0.1.10.12-20261019`）。共 2 项。构建环境为 Gradle 8.10.2、JDK 21、NeoForge 21.1.218，离线构建。

## 1. GitHub issue #18：爆炸破坏模式扫描仪时服务器崩溃

### 现象

* 使用 Explosion Overhaul 模组时，TNT 在模式扫描仪旁爆炸，服务器在掉落计算中抛出 `NullPointerException`（`MachineSalvage.compute` 第 68 行：`result` 为 null），方块未被破坏。
* 同样的问题会出现在所有带 `mio_icif:machine` 标签、未用扳手破坏的机器上。

### 原因

* 非扳手破坏的机器按其合成配方决定掉落（0.1.8.0 起：外壳等级）。为此 `MachineSalvage` 会读取服务器上**所有模组**的配方结果。
* 按约定 `Recipe#getResultItem` 不应返回 null，但某些模组的配方会返回 null。原代码只捕获了异常，没有处理 null，于是在 `result.isEmpty()` 处崩溃。

### 修复

* 新增 `common.util.RecipeResults.of(recipe, registries)`：null 与异常都视为“没有可用结果”（空物品）。
* `MachineSalvage`：配方结果通过 `RecipeResults` 读取；配方的材料列表为 null 或材料测试抛出异常时跳过该配方；计算整体失败时掉落机器本身并记录警告（不再让掉落导致世界崩溃，下次破坏时重新计算）。
* 同类风险一并处理：电炉与感应炉读取所有模组的原版熔炼配方，结果同样通过 `RecipeResults` 读取，空结果时不加工、不消耗材料。

## 2. 僚机持纳米剑、量子剑等物品时手部抖动

### 原因（0.1.10.11 只修正了拔刀剑：拔刀剑使用独立的静止架势）

1. **挥击期间姿势切换**：除拔刀剑外，手臂平时使用飞行姿势，但在整个挥击期间（`attackTime > 0`）被原版姿势整体替换，因此每次攻击的开始与结束两只手臂都会瞬间跳变。
2. **空中的行走摆臂**：原版姿势包含按移动速度计算的行走摆臂。僚机飞行（打了就跑的冲刺、追随主人）时手臂以约 9 tick 的周期摆动；位置数据包每 2 tick 到达一次，速度不均匀，摆动更明显。
3. **枪械每发都挥手**：射击武器每发调用一次挥手，射速 2～4 tick 时手臂几乎一直处于 1 与 2 的状态，并且挥手会在进行到一半时重新开始（原版规则），手臂被拉回。
4. 原版挥击的身体扭转曲线 `sin(sqrt(a)·2π)` 在挥击开始时斜率无穷大，手臂在百分之一 tick 内转动约 0.16 rad。

纳米剑的 HF 同步颤动（0.1.8.5）只作用于玩家第一人称（`LocalPlayer`），与僚机无关。

### 修复

* 新类 `common.armory.WingmanPose`（纯计算，不依赖客户端类，可离线检验）：
  * 目标姿势只由按 tick 平滑的状态计算：飞行系数、着陆、战斗（锁定目标）、持物种类（空手、持物、远程、拔刀剑）、头部角度。不再使用行走摆臂。
  * 持物：近战武器与工具平时前伸（原版持物姿势），战斗中举到防御架势；远程武器在战斗中双手瞄准（随头部俯仰与偏转，并补偿飞行前倾）。
  * 失效保护：目标姿势按游戏时间做低通平滑（时间常数 1.6 tick，最大 0.45 rad/tick），任何状态变化（换物品、开始战斗、着陆）都不会让手臂跳变；非有限值保持上一姿势；角度限制在 ±π。
  * 挥击、后坐、拔刀剑斩击作为叠加量加在平滑后的姿势上，三者在开始与结束时都为零。挥击沿用原版的砍击曲线，身体扭转改为斜率有限的同形曲线。
* `WingmanRenderer`：所有持物都使用上述姿势；原版 `setupAnim` 以零行走量与零攻击进度调用（只保留头部等），手臂由 `WingmanPose` 设置；保留原版的轻微待机摆动。左手僚机得到镜像姿势（瞄准方向不镜像）。
* `WingmanEntity`：
  * 正在进行的挥手不再被重新开始（服务器与客户端都适用）。
  * 射击（枪械与量子套装的纠缠齐射）不再挥手；客户端用射击计数驱动后坐：射击后保持 8 tick，连续射击时为稳定的架势，不会每发抖动。
  * 远程判定与姿势共用 `WingmanPose.ranged`（战斗逻辑、姿势、特效三处一致）。

### 验证（离线测试 `Harness1113`，62 项全部通过）

用与实体相同的按 tick 平滑状态模拟客户端，对比 0.1.10.12 与 0.1.10.13 的手臂姿势。跳变：每 tick 96 帧时相邻帧差超过 0.08 rad 的次数（连续运动不会出现）；抖动：60 fps 下、挥击与后坐之外、不含待机摆动时，10 tick 内再次反向的次数（每 100 tick，即 1 Hz 以上的振荡）。

| 场景 | 0.1.10.12 跳变 / 抖动 | 0.1.10.13 跳变 / 抖动 |
|---|---|---|
| 纳米剑打了就跑（每 15 tick 一击） | 24 / 3.0 | 0 / 0 |
| 量子剑（每 13 tick 一击） | 28 / 3.0 | 0 / 0 |
| 连射枪械（每 2 tick 一发） | 70 / 2.0 | 0 / 0 |
| 慢速发射器（每 30 tick 一发） | 12 / 4.0 | 0 / 0 |
| 追随主人（数据包不均匀） | 0 / 33.0 | 0 / 0 |
| 进入与离开战斗（近战） | 8 / 25.6 | 0 / 0 |
| 进入与离开战斗（枪械瞄准） | 21 / 20.0 | 0 / 0 |
| 着陆与起飞（持工具） | 0 / 13.8 | 0 / 0 |
| 切换物品（空手、工具、枪械、拔刀剑） | — | 0 / 0 |
| 左手僚机的纳米剑 | — | 0 / 0 |

* 挥击时机：每 4 tick 一击、持续 40 tick 时，0.1.10.12 有 9 次挥击中途重新开始，0.1.10.13 为 0。
* 姿势函数：首帧、同一帧多次绘制、切换物品的平滑与速度上限、非有限输入、挥击／斩击／后坐在两端为零、左手镜像、40,500 组输入的有界性。

* 本模组注册的 473 个物品与 237 个方块物品：远程 9 个（电动步枪、高级电动步枪、战术激光步枪、电浆枪、超光速粒子干扰器、纳米弓、火箭发射器、等离子发射器、采矿镭射），其余为持物；与源码中的 `isRanged()` 一致。
