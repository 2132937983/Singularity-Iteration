# 0.1.10.2 更新说明：量子套装模块系统 Q3（量子纠缠指挥）

基于 0.1.10.1（`pr-0.1.10.1-20261014`）。按已批准的提案 v1（`quantum_proposal.md`）实现第 3 阶段（最终阶段）Q3：指挥轮盘（G）、僚机单独模式与定点/集中/齐射指令、数据链、量子回收、3D 全息台（全息地图 Mk.II）以及推进特效（热浪、激波钻石、着陆尘环）。构建环境为 Gradle 8.10.2、JDK 21、NeoForge 21.1.218，离线构建。

## 1. 指挥链路与指挥轮盘

* **条件**：穿戴的量子部件上装有已启用的量子纠缠中继器。没有时所有命令被拒绝并提示原因（穿戴量子部件时）。
* **按键 G**：按住打开轮盘，鼠标移到扇区后松开执行；也可点击；中心为取消；快速轻按时轮盘保持打开等待点击。
  * **与工具切换键共用 G**：`key.mio_icif.tool_toggle` 的默认键原本就是 G。两者按情境分工：手持可切换电动工具时 G 仍切换工具；否则打开指挥轮盘。两者使用同一个自定义冲突情境 `SharedGKeyContext`，在按键设置界面不会互相标红，但与其他游戏内按键冲突时照常标红；可分别重新绑定。
* **目标捕获**：轮盘打开瞬间记录准星所指的地点与生物（最远 256 格；看天空时为前方 48 格的空中点）。
* **选择**：轮盘上方的标签选择全部或单架僚机（滚轮切换），全息台与编队 HUD 共用此选择。
* **十个扇区**：移动、待机、区域压制、集中攻击、齐射（与行动键相同的纠缠齐射）、归队、模式（扇形子菜单：四种战术模式、跟随全队、返回军械库）、数据链开关、全息台、量子回收。不可用的扇区变灰（例如没有准星目标时的集中攻击、冷却中的量子回收）。
* **外观**：双层反向旋转干涉环、依次展开的扇区、悬停扇区外移并发光、每种命令的线条图标、中央读数（选择对象、命令、目标与距离）；打开/选择音效。

## 2. 命令（服务器端 `WingmanCommands`）

| 命令 | 行为 |
|---|---|
| 移动 MOVE | 飞往地点（途中不交战），到达后在地点上方小圆上散开并守卫：攻击待机半径（默认 10 格）内的敌对生物。 |
| 待机 HOLD | 每架僚机在当前位置待命，攻击靠近的敌人。 |
| 区域压制 SUPPRESS | 在区域上空 5 格的圆环上巡航，清除压制半径（默认 14 格）内的所有敌对生物。 |
| 集中攻击 FOCUS | 攻击指定生物直到其倒下或超出集中攻击范围（距僚机默认 128 格），然后归队。不能指定玩家、僚机或盟友。 |
| 归队 FORM UP | 结束命令，回到编队与战术模式。 |
| 模式 / 跟随全队 | 对单架僚机设定的模式为“单独模式”：全队模式（面板或轮盘对全部）不再改变它，直到“跟随全队”。对全部设定即为全队模式（记录在玩家附件中）。 |
| 返回 RETURN | 普通返航（飞回军械库）。 |

* **范围**：同一维度内不限距离。执行定点命令的僚机不再受 28 格主人牵引与 64 格追赶传送约束，而是守卫命令地点。
* **未加载区块**：其中的僚机无法移动；编队列表显示 UNLOADED，只有量子回收能到达。
* **战术评分**：定点命令时“与主人的距离”项改为以命令地点计算（守点而非追随远处的主人）；舰队数据链的准星标记作为强呼叫加入评分（与 Q2 的优先目标规则一致）。
* **保存**：僚机新增存档键 `Individual`、`Order`、`OrderX/Y/Z`（集中攻击不保存）；旧存档没有这些键，读取为“无命令、全队模式”。
* **反馈**：命令时从你的胸口到每架受令僚机延伸干涉双螺旋光线，地点闪出地面光环与光柱，并播放应答通讯音；动作栏显示命令与架数。
* **安全**：命令负载限速（8 次突发，每 4 tick 恢复 1 次）；服务器首先检查指挥链路，校验地点（有限数值、世界高度与世界边界内）、集中攻击目标与所有权。

## 3. 数据链

* 指挥轮盘的开关（默认开启，保存于新玩家附件 `mio_icif:wingman_command`）。开启时，僚机看到的敌对生物（每架周围 24 格）通过既有的数据链负载每 10 tick 发送给你。
* 显示位置：HUD 全息地图（青绿色接触点）、战术地图（带圆环）、3D 全息台（带圆环）。
* 与舰队数据链协同的分工：协同额外提供世界中的菱形标记，并把准星所指的生物设为僚机首要目标；没有协同时只在地图类显示中标记。

## 4. 量子回收

* 让你的所有僚机立即折返军械库：任何维度、已加载或未加载均可。消耗 30 相干度，冷却 600 tick（均可在服务器配置 `QuantumSuit` → `command` 中调整；可关闭对未加载僚机的回收）。
* **未加载僚机名册**：僚机随区块卸载时记入世界存档的 `mio_icif_wingman_roster`（主世界 data 目录），重新加载或永久离开时移除。量子回收为其区块添加 300 tick 的加载票据，实体出现时立即送回；超时未出现则提示“未响应”并移除该记录。
* 特效：光柱向内坍缩、扫描环上下扫过、白色光迹射向天空、透镜星芒与上升粒子；量子回收音效。

## 5. 编队 HUD 与命令标记

* **编队面板**（左侧）：每架僚机的模式（`*` 为单独模式）、命令与到命令地点的距离、生命条、与你的距离；未加载/其他维度单独标注；标题栏显示数据链与量子回收冷却。
* **屏幕边缘标记**：视野外的僚机在屏幕边缘显示指向箭头与距离；视野内显示小括号。
* **世界标记**（仅你可见）：待机点（三层下指 V 形、旋转地面环与待机半径虚线圆）、区域压制（大红圈与雷达扫描线）、集中攻击目标（旋转红色括号与菱形，僚机牵引线），前往远处地点的僚机显示流动虚线。
* 客户端选项：`squad_hud`、`order_markers`。

## 6. 3D 全息台（全息地图 Mk.II）

* 新物品 **战术3D全息地图 Mk.II**（配方：Mk.II 模式 + 地图）。打开方式：按住战术地图键 N 0.4 秒（轻按仍打开战术地图），或轮盘的全息台扇区。
* 在你面前 1.25 格、腰部高度投射 1.5 格见方的地形全息：采样半径 24/48/96 格（滚轮），每边 49 格（客户端选项 `holo_table_cells`，25..65），每 2 秒重新采样；与世界同向（北为北），可拖动旋转。
* 外观：地形柱从中心向外升起（收起时反向折叠）、方块颜色向青色偏移的加法光、对角干涉条纹、横扫扫描线、投影框角括号与北向缺口、从胸口到四角的投影光束。
* 标记：你（白色菱形与朝向线）、僚机（青色，七段数字编号，命令连线与地点）、敌对生物（红色立柱；数据链中的带青绿圆环）、其他玩家（琥珀色）、地脉全息协同下的扫描矿石。
* 操作：左键地形 = 移动；右键 = 区域压制；左键生物 = 集中攻击；H = 待机；F = 归队；0..9 = 选择；Esc/N/G = 收起。

## 7. 推进特效（客户端选项 `flight.thruster_fx`）

* **热浪**：特殊机动飞行时双手双脚推进器火焰、僚机靴部推进器与助推喷流的位置每帧记录，在纳米特效的折射通道中沿火焰并越过焰尖绘制热浪扭曲，推力越大越宽越强。
* **激波钻石**：全推力（油门 0.72 以上）时尾焰变长，焰中出现四个闪烁的马赫节点；僚机助推喷流中出现三个。
* **着陆尘环**：从特殊机动飞行着地时，地面方块颗粒与云团向外扩散，伴随热浪圆环、柔光圆环与低沉的着陆声；强度随下降速度变化。其他玩家同样可见。
* 既有的音爆云、蒸汽锥与尾迹保持不变。

* 新物品：战术3D全息地图 Mk.II（演算带宽 +1 QB，与其他量子 Mk.II 相同）。
