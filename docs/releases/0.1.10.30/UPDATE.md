# 0.1.10.30 更新说明：武装库与量子套装视觉改进·第 1 弹——套装发光、真正的全息投影、量子套装配色、屏障菲涅耳、Iris 自动降级

基于 0.1.10.29。按已批准的视觉改进方案（`work-vfx/SI_armory_suit_vfx_audit_ja.md`）实施计划 A：S-1、S-2、S-3、A-2、A-5（简化版）、S-7、P-1、P-4，以及 S-9 中的一人称护手发光。新规则先作为纯类和离线测试 `verify-si1130`（`Harness1130`，22 项）与 0.1.10.29 比较，只采用测得有改进的部分；未采用的见第 8 节。

## 1. 套装发光（S-1，`SuitGlowLayer`、`SuitGlowRules`）

- 0.1.10.29 之前，纳米与量子套装只由原版盔甲层绘制，随环境光变暗：夜里是一团暗影，能量状态完全不体现在套装上。
- 新的渲染层在盔甲之后，用 `RenderType.eyes`（原版着色器，全亮、加色混合；光影包将其视为自发光并加泛光）绘制每个部件的发光蒙版：
  - 颜色：配色的发光色，无配色时为套装自身的灯光色（量子 `3CB4FF`、纳米 `46E070`）；电量低于一半向琥珀色过渡，四分之一时为琥珀色，再往下向红色过渡；没电时不亮。
  - 强度：3.2 秒的呼吸（0.8～1.0）；电量低于四分之一时 1.1 秒一次的双拍心跳；受击期间闪烁；推力（特殊机动油门、喷气飞行）时最多亮 35%。
  - 能量带：每 3.6 秒一条亮带从头顶流到脚下（按顶点高度计算，无自定义着色器）。
  - 启动扫过（A-5 简化版）：有电的部件启用时（穿上、由武装库穿戴、从空电充电），光从胸口核心以每秒 40 像素扩散，0.9 秒覆盖全身；进入视野时已穿着的不触发。
- 只绘制盖住发光像素的面（`GlowMasks`，每次资源重载计算一次）：整套量子套装 1,218 面中 302 面（24.8%），每套每帧约 1,200 个顶点。
- 加到玩家、盔甲架、僚机和全息展示的人台；一人称手臂同样发光（S-9 的护手部分）。客户端选项 `suit_glow`、`suit_glow_strength`（0.25～1.5），装备控制台外观页也可切换。

## 2. 发光蒙版（S-2，`tools/glow_masks_1130.py`）

- 新文件 `textures/models/armor/quantum_*_glow.png`：保留全部原有灯光像素（`_accent`），并在盔甲外侧面上沿箱式 UV 面的边生成电路线：内缩 1 像素的边线、从边进入板面的 L 形走线与端点节点、大板上的两条平行走线。
- 规则：朝上或朝下的面（|ny| > 0.7）、小于 3×3 像素的面、实心像素不足 90% 的面（抖动纹理的板）不画线；线只画在该面内和基础纹理的不透明像素上；图案由面的尺寸、朝向和肢体种类的哈希决定，左右镜像的面图案相同。结果确定（同样输入同样输出）。
- 基础、镀层与强调纹理（Blockbench 模型的原图）不变：电路线只以光的形式存在，没电时看不见。
- 发光像素：头盔 568 → 745，胸甲 68 → 452，护腿 52 → 167，靴子 32 → 78，合计 720 → 1,442（×2.0）。
- 离线预览 `tools/glow_preview_1130.py`（白天、夜间无发光、夜间发光三种外观）。

## 3. 量子套装配色（S-3）

- 量子套装四件可设置配色（装备控制台→外观页→配色），与纳米套装相同：装甲色（`_plating`）与发光色（`_accent`）。强化量子胸甲与重型量子胸甲自 0.1.9.0 起是量子胸甲＋框架核心（旧物品会立即转换），因此同样适用。
- 量子材质改为两层（`quantum`、`quantum_accent`），穿戴纹理按配色选择原图或 `_plating`，第 2 层无配色时跳过；物品图标、一人称手臂、武装库飞行部件原本就按两层绘制，现在三处一致。
- 框架核心外装：有配色时发光部分（重力环灯、推进喷口、太阳核心）改用灰度副本（`tools/attachment_lum_1130.py`，`*_lum.png`）乘以发光色；金属板和太阳能板保留原材质。没有配色时与之前相同。

## 4. 真正的全息投影（A-2）

- 0.1.10.29 的“全息”是把盔甲用原来的渲染类型染成青色并全亮，不透明。
- 现在投影的装备画两次：半透明全亮的青色本体（`entityTranslucentEmissive`，使用装备自身的纹理）与加色的全息网格（纳米全息网格纹理，4 倍细，`HOLOGRID_FINE`）。纹理通过访问转换器从任意渲染类型读取（`RenderTypeTextures`），所以原版盔甲、套装和其他模组的盔甲都适用；附魔光效不画。
- 扫描带每 3.3 秒向上扫过；偶尔有 2～3 条水平切片横移 3 tick；投影装备变化时，新装备沿扫描线从脚下在 1.2 秒内构建出来（首次进入视野时不播放）。

## 5. 屏障菲涅耳（S-7）

- 光子屏障的棱镜边与六角格护盾：直视处变暗（0.55），掠视的边缘最亮（最高 1.3），像气泡；离线：正对相机的格 0.55，侧面 1.13，顶部 1.03（相机 6 格远）。
- 命中点附近的格在命中后的最初 18% 时间内整格闪亮。

## 6. Iris 自动降级（P-1，`IrisCompat`）

- 通过反射读取 Iris 的公开 API（`IrisApi.isShaderPackInUse`，每秒至多一次；未安装 Iris 时不做任何事）。使用光影包时，纳米的屏幕拷贝折射（光学迷彩、冲刺与 EMP 冲击波、推进器热浪）自动改用全息网格与加色光的后备效果，不再需要玩家手动关闭；首次时记录一次日志。
- 新增的发光全部使用原版着色器的渲染类型（`eyes`、`entityTranslucentEmissive`、能量旋涡），不新增自定义核心着色器（P-2 方针）。

## 7. 减少每帧分配（P-4）

- `FxDraw`（环、圆盘、锥、星、光束、线）：改用 double 计算与按分段数缓存的正余弦表，顶点与 0.1.10.29 完全一致（2,000 次随机调用，最大差 0）。离线（7 轮交替的中位数）：五种图元每次调用合计 11,520 → 64 字节；环（48 段）4.7 → 1.9 微秒，圆盘 2.0 → 0.9，锥 1.4 → 0.7。时间随运行波动（例如下面分段的旧代码两次运行测得 1,845 与 1,221 纳秒），分配量基本稳定（1,800 与 1,816 字节）；本节数字取自随附的 `verify-si1130/harness.txt`。
- 六角格护盾：格角方向预先计算（与旧公式完全一致），每帧 213,840 → 320 字节、115 → 56 微秒。
- 武装库飞行装甲部件的分段：每帧重建的分段表改为常量，分段的面按几何数组缓存；每段（328 面）1,816 → 0 字节、1,221 → 19 纳秒。

## 8. 未采用的部分、与方案的差异

- **偏导护盾的六角补丁（`ShieldFieldRenderer`）未改写**：用 double 改写后测得 0.1.10.29 的代码每次只分配约 80 字节（JIT 已消除其向量），没有可改进的余地，因此保持原代码。最初的单次测量受 JIT 状态影响很大（同一代码两次测得 40,442 与 8,168 字节），改用预热后 7 轮交替取中位数后才得出此结论。
- **发光蒙版只生成量子套装**：纳米套装沿用原有 `_accent` 发光（灯光与面罩），没有生成电路线。
- **框架核心外装的金属板不随装甲色改变**：太阳能板等保留材质，只有发光部分随发光色。
- **A-5 为简化版**：只有发光从胸口扩散的启动扫过；面罩点亮、放射状脉动等在计划 C（S-6、S-8）中实施。
