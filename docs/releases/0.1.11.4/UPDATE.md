# 0.1.11.4 更新说明与游戏内测试清单

基于 0.1.11.3。逐项说明见 `CHANGELOG.md` 的 0.1.11.4 一节。

| 项目 | 改动 |
|---|---|
| 物品缓冲机 | 两个升级槽都作用于全部 48 格，抽进来的物品可以弹出 |
| 量子 / 纳米套装防化 | 完整量子套、装有工作中的毒素过滤单元的完整纳米套，在核爆区和放射性方块旁不再被施加辐射与虚弱（上游 issue #31） |
| 液冷核电 | 删除发电模式反应堆的液冷（往反应堆注入冷却液降温）；旧存档中的冷却液丢失 |
| 导线原料 | 低压锡、中压铁、高压铜、超高压金；超高压只能用金属成型机制作 |

没有新增配置。反应堆总输出上限（issue #33 第 1 点）本版未改。导线贴图暂未更换。

## 游戏内测试清单

1. **物品缓冲机**：升级槽 1 放抽取升级，升级槽 2 放弹出升级，一侧接装满物品的箱子、另一侧接空箱子（用带方向的升级避免来回搬运）。物品经缓冲机从满箱流入空箱。
2. **量子套防化**：穿完整、有电的量子套进入核爆辐射区或靠近放射性方块，不出现辐射与虚弱效果。
3. **纳米套防化**：完整纳米套装上并开启毒素过滤单元，同样不出现辐射与虚弱；关掉单元后恢复为按几率挡掉辐射。
4. **反应堆**：发电模式反应堆界面右侧不再有冷却液计量条，管道和桶不能往里注冷却液；旧存档中有液冷的反应堆加载后照常运行（冷却液没了，注意温度）。
5. **导线**：JEI 中中压导线由铁制成、高压导线由铜制成、超高压导线由金制成；切割刀 + 铁板合成 3 根中压导线。

未在游戏客户端中检查（以上清单尚未执行）。
