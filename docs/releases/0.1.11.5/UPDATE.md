# 0.1.11.5 更新说明与游戏内测试清单：被动式套装 HUD 与全息图改修

基于 0.1.11.4。纯客户端改动。逐项说明见 `CHANGELOG.md` 的 0.1.11.5 一节。

| 项目 | 改动 |
|---|---|
| 被动式 HUD | 平时只有左下状态行；情况出现时视野上方弹出消息，最多 2 条，按优先级 |
| 详细视图 | 按住左 Alt：左侧文字面板（电量、机动、模块、电网、最近消息），右侧大号全息图 |
| 电网遥测、弹道 | 看向电网节点时弹出文字卡片；弹道解为文字卡片 |
| 飞行 HUD | 去掉俯仰梯与刻度带，改为文字读数；悬停静止 3 秒折叠；新增坠地与推进电量消息 |
| 量子 / 纳米核心 HUD | 空闲时完全隐藏 |
| 全息图 | 高差、形状、遮挡、距离标注、盒边箭头；中性地形、剖开头顶、危险上色；距离环；平时隐藏、有敌对或声呐结果时弹出；详细视图可缩放、调俯角 |

新增按键：“套装详细视图（按住）”，默认左 Alt，可在按键设置中修改。

## 游戏内测试清单

1. **平时**：穿量子套、装满模块走在空地上，屏幕上只有准星、视野边角框和左下“面罩正常”。
2. **威胁**：引来一只僵尸。上方出现“! 威胁 右前 · 1 个敌对 · 8 米”，右上角弹出小号全息图；僵尸死后约 4 秒全息图收起，消息 1.5 秒后消失。
3. **详细视图**：按住左 Alt，左侧出现文字面板、右侧大号全息图；滚轮缩放，Shift+滚轮改俯角；松开恢复。
4. **全息图**：进洞穴或盖了顶的房间，全息图剖开顶部，能看到房间内部；岩浆为橙色、悬崖边描红；高处的怪竖线为实线，坑里的为虚线。
5. **电网**：看向线缆或机器，准星左下弹出电网卡片；移开视线即消失。
6. **飞行**：特殊机动起飞，准星两侧显示速度和高度，底部一行显示模式和推力；悬停不动 3 秒后只剩底部一行；朝地面俯冲出现“坠地”警告。
7. **量子 / 纳米**：不使用技能时准星周围的相干度 / 储备环隐藏；使用技能时亮起。
8. **多语言**：切换到中文、日文、俄文，消息、面板、全息图文字都已翻译。

未在玩家实际游戏中检查（以上清单尚未执行）。
