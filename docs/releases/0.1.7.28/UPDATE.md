# 奇点迭代 0.1.7.27–0.1.7.28 更新记录

## 0.1.7.28

### 高级采矿机

- 修复过滤器（黑／白名单幽灵槽）保存错误：`ItemStack#save(provider, tag)` 返回新标签而不修改传入的标签，旧代码丢弃返回值，只写入了 `{Slot:n}`。结果：每次区块重载／重启服务器后过滤器全部清空（采矿不再过滤），客户端在每个方块实体更新包（运行灯切换、修改过滤器、切换白名单／精准采集、扫描仪变化）后图标消失，直到重新打开界面。
- 客户端更新包补充自动输出模式与当前深度；界面在客户端方块实体被替换时重新获取实例；`stillValid` 不再恒为真（机器被拆除或玩家远离时关闭界面）。
- 拆除机器时，尚未输出的已采掘物品会掉落，不再消失（普通与高级采矿机）。

### 扳手拆除保留全部设置（全机器）

- 扳手拆除 SI 机器时，物品写入完整方块实体数据（能量、升级与物品栏、模式、过滤器、红石模式、升级方向、变压器模式等），重新放置后完整恢复；以前只保存能量。
- 物品栏随机器物品一起保存，不再散落；超过 256 KiB 时只保存设置、物品照常掉落。
- 剥离与位置／时间绑定的运行状态：采矿位置与层、多方块核心坐标、区块加载器票据、计时器、传输中账本、远程关闭开关等。
- 由方块状态显示的设置在放置后同步（金属成型机、高级金属成型机的模式；后者以前从不更新方块状态）。
- 储物箱掉落改用可选战利品参数，避免无方块实体时抛出异常；已装物品的储物箱不能再放入储物箱（防止无限嵌套导致数据过大）。
- 删除储电箱右键时的调试日志刷屏。
- 新增 `Round28GameTests`：过滤器存读档与客户端更新、高级采矿机扳手拆除与恢复（过滤器、模式、扫描仪、升级、能量）、金属成型机模式与方块状态、MFSU 能量与红石模式、变压器模式、储物箱嵌套。

## 0.1.7.27

### 电网探测（电压检测器 / 能源管理终端）

- 重写 `NetworkWalker` 拓扑探测：变压器与储电箱（BatBox～MFSU、GESU）统一视为"缓冲节点"。`SEGMENT` 范围止于缓冲节点；`SYSTEM` 范围双向穿过变压器与储电箱，并按电压段划分子网。
- 修复「变压器 ⇄ 超导合金导线 ⇄ 变压器」中间导线上的检测器／终端读不到另一侧用电器的问题；修复「变压器 ⇄ 导线 ⇄ 储电箱 ⇄ 导线 ⇄ 用电器／发电机」在变压器与储电箱之间检测时两侧均读不到的问题（旧版储电箱从不展开，且已登记的缓冲节点在第二个导线段中被跳过）。
- 电压检测器（GUI、HUD）始终以 `SYSTEM` 范围统计全系统节点构成，电压／电流／流量取所测导线段（检测点所在电压段）的实测值。
- 能源管理终端新放置时默认 GLOBAL（全系统）；旧存档保留原设定。
- 探测结果按 (维度, 原点, 范围) 缓存，并以新增的拓扑时钟 `TopologyClock` 失效：方块实体方块放置／拆除／替换、导线端口或颜色变化时递增，另有 200 tick 上限。大型工厂中终端、检测器与 HUD 不再每次重新遍历全部导线。

### 单位

- 统一为 `EU/t`：导线额定值显示为「额定 LuV · 最大 32.8k EU/t」，并在检测器界面悬停说明为单个数据包每 tick 的上限。移除全部 `EU/p`。

### 外观风格

- 默认风格改为经典 IC2（随模组本体提供）：朴素方块机器；机器物品直接使用方块模型，物品栏与放置后的方块始终一致。
- 原精致／DSP 风格改为内置资源包「实验性风格」(`resourcepacks/si_experimental`)：精致机器模型、状态灯、输出插座／转轴／导热端口，以及配套的 DSP 物品图标——方块与物品一起切换。
- 装备特性管理「外观」页签：默认 (Default / 默认风格) 与 实验性 (Experimental / 实验性风格)。旧的 `si_classic` 资源包移除。
- 由 `tools/build_appearance_packs.py` 生成新布局。

### 修复与清理

- 恢复 0.1.7.26.1 中 `en_us.json` / `zh_cn.json` 丢失的 263 条翻译键（激光塔升级、区域扫描器、终端、检测器等界面文本）；删除 8 个空的 `_adv_*.json` 临时文件。
- 删除未注册的重复 `common/mixin/AdvancementTabMiophaMixin.java`（实际生效的是 `mixin/client` 版本）。
- 补齐缺失资源：物品输出管道父模型、`block_glass_cable_1` 贴图、合金门物品贴图引用。
- 移除已封存的纳米／量子 3D 装甲生成工具。
- 性能／内存：`MachineStatusTracker` 在维度卸载与服务器停止时释放 `ServerLevel` 引用；Mekanism 严格能量桥缓存接口类；抽取升级在无物可取时退避 20 tick 并跳过空槽；生命支持戒指脉冲表在卸下时清理；反应堆冷却液分类结果缓存；Curios 槽位解析改为无锁快速路径；装备能量排行每 tick 只计算一次；检测器 HUD 请求表自动清理。
- 新增 `Round27GameTests`（两种故障拓扑、储电箱流量读数、缓存失效、单位与语言文件完整性、默认／实验性外观布局）。
