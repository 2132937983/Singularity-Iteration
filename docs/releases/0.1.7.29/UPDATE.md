# 奇点迭代 0.1.7.29 更新记录

## 0.1.7.29

### 崩溃修复

- 修复与 Presence Footsteps 同装时的 `NullPointerException`：其他模组的护甲材质可能没有穿戴音效，`ArmorItem#getEquipSound()` 返回 null，Presence Footsteps 直接调用 `.value()` 崩溃。新增 `ArmorEquipSoundMixin`，对所有护甲在返回 null 时回退为通用穿戴音效（`ARMOR_EQUIP_GENERIC`）。

### GUI / HUD 文字

- 新增统一的文字适配工具 `mio_icif_screen.drawFitted`：文字超出所在框时先缩小（最低 70%），仍放不下则以省略号截断；`SiButton` 按钮标签同样处理。
- 修复溢出／重叠：动能发电机、涡轮增压动能发电机、双涡轮增压动能发电机的转换效率；水力动能发电机（生物群系原样显示翻译键 `gui.mio_icif.water_kinetic...`，现正确翻译并与转子耐久合并为一行）；风力动能发电机；蒸汽发电机（压力阀、进水、流体输出改为短标签，完整说明移入悬停提示）；同位素温差发电机输出与能量条重叠；经验发电机（无物品槽却使用带槽位框的贴图，文字与能量条压在槽框上）；流体分配器模式；模式存储器（能量图与多余的箭头贴图压在"名称／UU"上，标签改为可翻译）；激光防御塔标题与状态行；期货交易所分类标签（宽度随文字）。
- GESU 核心界面的模块文字移到槽位右侧，不再压在放电槽上。
- 补回缺失的界面标题：动能发电机（电力）、热能发电机（电力）、斯特林动能发电机。
- 储电箱界面标题改用方块自身名称：CESU 不再显示"储电盒 / BatBox"；BatBox / MFE / MFSU / LESU / EESU 充电座也显示各自名称。
- 补全 30 个代码中引用但语言文件缺失的翻译键（发电机名称、反应堆模式、变压器按钮、钻头模式、地形改造机消息、储罐提示等）。

### 喷气背包 HUD

- 修复悬停模式开关提示在动作栏"烧屏"：装备 HUD 轮播以前每 tick 推送动作栏文字，现在只在文字内容变化（模式切换、换装备）时显示 3 秒；量子胸甲（喷气背包）在空中飞行时保持显示。

### 枪械持握姿势

- 电磁步枪、高级电磁步枪、战术激光步枪、超光速粒子干扰器、等离子枪、等离子空气炮、火箭发射器统一使用采矿镭射枪的双手持枪姿势（第三人称低持、开火时抵肩瞄准，第一人称后坐）。
- 重新计算各枪的 `thirdperson_*` / `firstperson_*` 显示变换：以每把枪的握把为锚点对齐到手部，缩放按枪长调整，不再出现枪身朝下或悬空的情况。

### GESU

- 能源管理终端可识别 GESU：核心与输入／输出端口被视为储能设备与电压缓冲节点，系统范围拓扑可经 GESU 穿越；储量与容量从核心读取，同一 GESU 只计一次。
- GESU 核心新增充电槽与放电槽（原界面只有贴图框，没有实际槽位）：充电槽为电池／电力工具／电力护甲／FE 物品充电，放电槽接受电池、FE 物品与红石；每 tick 最高 LuV 速率，物品随存档保存、拆除时掉落或随扳手保留。界面同时加入与其他储电箱相同的护甲显示槽。

### 架构与性能

- 新增 `core/api/machine/IStorageMember`（多方块储能成员）与 `core/runtime/energy/DirectItemCharging`（不经 FE 账本的物品充放电），GESU 与终端不再互相硬编码。
- 首原料配方查找（`RecipeAPIImpl.findRecipe`，高级压缩机、高级粉碎机、高级金属成型机、高炉、中子聚合机、炼油厂等每 tick 调用 2～3 次）按"物品 + 组件"记忆结果，配方表重载时自动失效。
- 流体反应堆每 tick 及每次流体能力查询都会重新扫描约 105 个方块，改为只在 20 tick 周期的结构刷新中扫描；未连接反应堆的流体接口不再每 tick 扫描 5×5×5 范围；访问接口不再每秒重复尝试成型并刷屏日志。
- 磁化机的铁栏杆搜索（最多 512 格 BFS）由每 tick 改为每秒一次。
- 防止同步加载区块：传送机仅在有实体待传送时才校验（并可能加载）目标；无线输电节点跳过未加载的目标；GESU 输入端口在访问核心前检查区块是否已加载。
- 新增 `Round29GameTests`：护甲音效非空、储电箱标题、GESU 充放电槽、终端将 GESU 视为单一储能、配方记忆结果一致。
