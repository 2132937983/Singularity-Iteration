# 奇点迭代 0.1.7.30 更新记录

## 0.1.7.30

### 储电箱（BatBox / CESU / MFE / MFSU / LESU / EESU 等）

- 修复充电槽内有物品时对外输出完全中断：充电槽物品与导线／FE 面共用同一份每 tick 输出额度，而物品充电在方块自身 tick 中先于电网结算执行；能吃满一个电压等级包的物品（如超级兰波顿水晶、电力护甲）会用光额度，储电箱的"满包输出"规则随即判定不足一包而停止送电。现在充电槽拥有独立的、按电压等级计的额度（与 IC2 一致：充电槽与输出互不影响），共享余额与输出版本号仍保护电网报价。已用回归测试确认：旧代码下输出为 0 EU，修复后与无物品时相同。

### 装罐机

- 动态装罐配方不再以 `cannable_foods` 标签作为白名单：任何带原版食物组件（`FoodProperties`）且饱食度大于 0 的物品都可装罐，包括其他模组的食材（幼虫、料理等）。产出数量 = 饱食度 × 倍率，最多一组；消耗的空锡罐与产出数量严格相同（以前超过 64 时会多扣空罐）。已装满的锡罐与无营养物品不被接受。

### 锡罐食品

- 食用时间由 32 tick 缩短为 12 tick（0.6 秒）。
- 每罐恢复 2 点饥饿值（IC2 经典版）与 3.2 点饱和度（IC2），此前为 1 点饥饿值、1 点饱和度。
- 食用后返还空锡罐：最后一罐留在手中，其余放入背包，背包已满时掉落在脚下（创造模式不返还）。

### 测试

- 新增 `Round30GameTests`：任意食物组件物品可装罐、锡罐食用速度／恢复量／空罐返还、储电箱充电时仍持续对外输出。
