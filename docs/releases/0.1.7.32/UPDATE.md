# 奇点迭代 0.1.7.32 更新记录

## 0.1.7.32

基于上游 0.1.7.31（`2132937983/Singularity-Iteration` 分支 `0.1.7.31-beta` @ 7ec4f49）。

### GESU 模块界面崩溃（IndexOutOfBounds）

- 原因：网络通道版本固定为 `"1"`，客户端与服务器模组版本不同也能连接。0.1.7.29 起 GESU 核心界面（模块右键打开的也是它）增加了充放电槽与护甲槽：新服务器同步 42 个槽，旧客户端只建 36 个槽，`getSlot(36)` 越界导致客户端断开。当前版本服务器与客户端两侧的槽位一致（新增测试逐一核对所有 SI 方块菜单的两侧槽位数，以及 GESU 输入／输出模块实际打开的菜单）。
- 通道版本改为模组版本：版本不同的客户端在登录时即被 NeoForge 以"通道版本不匹配"拒绝，不再进入游戏后崩溃。
- 所有 SI 菜单在收到超出槽位数的同步内容时忽略多余部分并记录一次警告，不再抛出异常。

### 导线内嵌防爆石（建筑泡沫）

- 导线可放入铁质脚手架（保留脚手架外观）；用 CF 喷枪按脚手架方式喷涂时连同其中的导线一起变为强化泡沫，硬化后成为内含导线的防爆石：外观与爆炸抗性同防爆石，挖掘速度同防爆石，导线照常导电。普通泡沫包裹的导线硬化为 CF 墙。
- 以前包裹在导线上的泡沫永远不会硬化（硬化处理为空方法），喷枪喷导线时也总是去掉强化标记。现在按与泡沫方块相同的 IC2 公式随光照硬化，也可用沙子立即硬化。
- 拆除时掉落导线及其外层（铁脚手架或对应墙体方块）。

### 电动工具的装备特性

- 新增 `core/api/item/IFeatureToolItem`：工具与武器可像护甲一样声明特性，在装备特性控制台（主手／副手）切换、存储并显示在提示中。
- 电动扳手：保留机器内容物（关闭后拆除时内容物散落）、点击正面拆除（关闭后作为防误拆保护）。电动扳手此前拆除机器时不保留物品栏，现与普通扳手共用同一拆除流程。
- 纳米剑：收起时自动关闭、保护友方（对宠物、村民与傀儡只造成基础伤害且不耗电）。

### 树脂收集器审查

- 采集逻辑本身是事件驱动加 20 tick 轮询，开销很小；改为以 `isLoaded` 检查木头所在区块（区块边界不强制加载），并在区块加载时立即检查一次，不必等待下一次轮询。

### 期货交易所改为数据包定义

- 商品由 `data/<命名空间>/si_futures/*.json` 定义（物品、基础价格、波动率、分类、调价周期 `period_days`、解锁进度 `unlock.advancement`、`remove` 删除条目），同一物品后读到的覆盖先前的；`/reload` 生效并同步给所有在线玩家。格式见 `docs/datapacks/si_futures.md`。
- 默认 54 种商品移入 `data/mio_icif/si_futures/`；配置项 `FutureMarket.commodities` 删除。
- 未解锁商品在界面中显示为灰色并提示所需进度，服务器拒绝交易。分类标签宽度随文字。

### 无线输电节点

- 没有目标的节点现在作为接收端向相邻机器与导线供电（以前只能接收，电量停留在缓冲中）；接收端的输出包大小不超过相邻机器的输入等级或导线额定值，避免直接贴放的低压机器过压爆炸。
- 发送端不再等缓冲满 32768 EU 才发送；修复目标为 SI 机器时可能按请求量而非实际扣除量入账的问题。

### 分子重构仪与超导合金导线

- 分子重构仪：输入电压与接收功率不设上限（不会过压），每 tick 使用缓冲中的全部能量，能量充足时同一 tick 内连续完成多件（最多 64 件）。以前缓冲不足 32768 EU 时完全不工作。
- 超导合金导线：电压等级与可承载包大小不设上限（熔毁阈值与额定值均为最大值，零损耗）。

### 太阳能头盔与飞行装备

- 太阳能头盔为 Curios 饰品栏中的电池类物品充电（经 `BatteryTargetProviders`，与电池腰带等共用）。
- 混合／终极混合太阳能头盔（以量子头盔合成）继承量子头盔的全部特性：氧气补给、夜视、自动进食、中毒／凋零／辐射清除，且可在控制台切换；高级太阳能头盔（以纳米头盔合成）继承夜视。
- 飞行戒指或创造模式飞行期间，胸甲喷气背包不再工作；以前悬停模式会把"在空中"当作悬停而持续消耗量子胸甲电量。

### 橡胶树苗兼容

- 橡胶树苗加入 `minecraft:saplings` 与 `c:saplings` 标签（方块与物品），去皮橡胶木加入 `c:stripped_logs`。
- 新增 Thermal 有机培养仪（Phytogenic Insolator）配方（仅在安装 Thermal 时加载）：橡胶树苗 → 橡胶木 ×6、树苗、树脂。Ender IO 农场站按 `SaplingBlock` 种植、按原版原木／树叶标签砍伐，橡胶树均已满足。
- 本环境未安装 Thermal 与 Ender IO，兼容内容按两者源码确认，未在游戏内实测。

### 其他修复（全源码扫描）

- 期货 `CommodityCategory.WOOD` 枚举项被乱码注释吞掉，木材类商品全部落入"其他"标签页；已恢复。
- 反应堆流体端口界面的物品栏标题绘制语句同样被乱码注释吞掉；已恢复。
- 期货界面分类标签页改为一行排列在图表上方（左侧商品列与右侧日期／金币列之间），宽度按文字自适应，不再与列表重叠。

### 测试

- 新增 `Round32GameTests`：所有菜单两侧槽位一致、GESU 模块打开核心界面、导线放入脚手架→喷涂→硬化后防爆并导电、无线接收端为相邻机器供电、分子重构仪无上限且并行、超导导线无上限、太阳能头盔为高级量子胸甲充电并继承特性、飞行时喷气背包不耗电、工具特性、期货数据包字段、通道版本。上游的 `CommonConfigGameTests` 商品校验改为验证数据包解析。
