# 奇点迭代 0.1.7.35 更新记录

基于 0.1.7.34。修复纳米靴前后颠倒、武装库手持物不回收、武装库悬浮提示误判、装备 HUD 残留；纳米套装物品改为直接渲染 3D 模型；电池改为右键切换背包自动充电并防止太阳能头盔循环充电；新增「省电」附魔；对每 tick 热路径做了一轮减分配与清理。

### 纳米套装

- 纳米靴模型在 Blockbench 中朝向 +z（南）制作，穿戴时前后颠倒。`tools/gen_nano_armor.py` 新增 `TURN_AROUND`，对靴子先绕竖轴转 180° 再拆分左右腿（左右按转后坐标判定）。
- 物品图标：四件纳米装备的物品模型改为 `builtin/entity`，新类 `BakedArmorItemRenderer`（BEWLR）直接绘制与穿戴时相同的 Blockbench 几何体：自动求包围盒并缩放进物品立方体，模型空间绕 x 轴翻转使正面朝向观察者，使用盔甲贴图与附魔光效缓冲。物品栏、手持、掉落物、展示框统一为 3D 外观，显示变换写在各物品模型 JSON 中。原 16×16 平面图标只保留作破坏粒子贴图。

### 武装库

- 返还套装（远程「返回」）此前只收护甲槽，主手与副手的武器、工具留在玩家手上。现在两只手的可召唤物品也一起爆开飞回并入库；武装库遥控器本身仍留在玩家身上，不计入费用。
- GUI 悬浮提示：基类 `mio_icif_screen` 有一个参数顺序为（鼠标 x, 鼠标 y, x, y, w, h）的 `isHovering(int…)` 重载，`ArmoryScreen` 传入 int 时绑定到了它，导致「维护」提示覆盖屏幕下半大部分区域，而能量条、魔力条与改名提示从不显示。改用 GUI 相对坐标的私有判定 `over()`，四处提示都只在各自区域出现。
- 飞行动画：客户端不再直接用世界时间计算飞行进度（服务器每秒校时一次会让世界时间跳变、迟到的 tick 会停顿），改为每个部件自己的平滑时钟（每 tick +1，并以 10% 的比例缓慢向世界时间收敛，偏差超过 4 tick 才直接对齐）。悬停起伏函数在交接点从 0 开始（原先有 4 cm 跳动）；吸附曲线改为起点速度为 0 的三次缓入（`s³(1.6−0.6s)`），从悬停到吸附不再顿挫。

### 电动工具与充电

- 装备 HUD（`EquipmentHudCycler`）重写：每个槽位独立计时。文字（数字除外）变化后显示 60 tick（3 秒），只有数字变化（能量）不会重新显示；`keepEquipmentHudVisible` 只对提出请求的那一行生效。此前空中的喷气胸甲请求常亮时，会把量子剑／纳米剑的能量行一起常亮。固定 6 槽数组，tick 路径不再分配集合，数字遮罩不再使用正则。补充日文 HUD 文本（纳米剑、量子剑、喷气背包）。
- 电池（`IEnergyDistributable`：充电电池、能量水晶、兰波顿水晶等）：右键不再把电量一次性分给背包，改为切换「背包自动充电」模式（`BatteryAutoCharge`，状态存于 CustomData `SiAutoCharge`）。开启时每 10 tick（按槽位错开）以电池的充电速率 ×10 给背包、护甲槽与饰品栏中的电动工具和电力护甲供电；关闭时不供电。开启状态显示附魔光效，并在提示中注明。四种充电背包（电池包、高级电池包、能量包、兰波顿包）以潜行 + 右键切换同一模式（普通右键仍为穿戴）。基于电池基类的工具（无线管理器、地磁探测器）通过 `supportsAutoCharge()=false` 保留原有右键。
- 防循环：自动充电的来源不会给其他来源（电池、充电背包、处于自动模式的物品）充电；太阳能头盔（普通／高级／混合／终极）的背包游标、护甲槽、胸甲与饰品充电均跳过处于自动模式的电池与背包，电量不再在头盔与电池之间来回流动。

### 新附魔「省电」（`mio_icif:energy_saving`）

- 最高 V 级，每级耗电 −5%（I 95%、II 90%、III 85%、IV 80%、V 75%）。数据驱动附魔，适用物品为新标签 `mio_icif:enchantable/electric`（50 件电动工具、电动武器与电力护甲；充电背包只供电，不在其中），加入附魔台、交易、随机战利品与非宝藏标签（`required: false`）。
- `EnergySaving.apply()` 在所有耗电点生效：工具使用与付费动作（`BatteryTransfer.consume`）、电力护甲每 tick 消耗、伤害吸收（每点伤害耗电按比例降低）、量子靴与纳米靴的摔落保护、喷气背包与通用飞行控制器、武器射击、橡胶树采集、各类电子小工具（急救、打火机、无线管理器、地磁探测、钓竿、力场、营养供给、遮蔽器）、电动船、量子套装单元耗电以及特殊机动模式（经 `SuitModules.extract`）。不足 1 EU 的部分按概率补齐，长期平均与百分比完全一致。充电与电池间转移不受影响。

### 性能与代码清理

- 套装单元判定（每 tick 多次调用）：`SuitModuleType` 缓存 `VALUES`、`featureKey`、名称键与槽位数组；`isActive` 直接读取开关状态，不再每次构建特性列表；`totalDrain` 不再生成临时列表。`ArmorFeatureState` 缓存 `feat_` 存储键，避免每次字符串拼接。
- `EquipmentEnergyMonitor`（客户端，每 tick）：改为每 4 tick 采样一次（增量累计结果相同），样本以物品引用比较，不再每次生成注册名字符串。
- `MachineStatusTracker`：每 10 tick 的两层映射快照改为复用的暂存列表。
- 删除注释掉的旧代码：10 个方块类的 `getStateForPlacement`（失效的潜行放置分支）、未使用的 `gatherData` 监听、创造栏与期货机的残留调用、若干界面类的残留坐标计算与手摇发电机的注释音效。保留 IC2 参考算法的引用注释（用于说明行为来源）。新代码注释按 ASD-STE100 书写。

### 测试

- 新 GameTest 类 `Round35GameTests`（8 项）：省电系数与小额概率均值、附魔注册与适用物品、工具与套装单元扣费、电动物品标签完整性、电池右键切换与供电／停止、太阳能头盔不给自动模式电池充电、返还套装回收主副手、纳米物品模型为 `builtin/entity` 且靴子朝前。`Round25GameTests` 的经典盔甲贴图检查不再包含纳米套装（0.1.7.34 起使用专用模型）。
- 捕获场景 15（`run_scene15.sh`）：武装库 GUI 各提示区域、3D 物品栏图标、电池与省电提示、纳米靴正面与侧面、装备 HUD 显示后 3 秒消退、武装库投送飞行与就位。
