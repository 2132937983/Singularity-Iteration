# 0.1.8.3 更新说明

基于 0.1.8.2（工作树 `pr-0.1.8.2-upstream-20261012`）。构建环境为 Gradle 8.10.2、JDK 21、NeoForge 21.1.218，离线构建。物品 ID 与显示名称均未改变。

## 1. 资源导入（`resources.zip`）

压缩包是旧代码库的完整 `src/main/resources` 快照（旧 mixin 包名 `com.singularity_iteration.mio_icif`、旧配方与标签、旧语言文件）。整体覆盖会使模组倒退，因此 `tools/intake_resources_183.py` 只导入本轮重绘的美术：

* `assets/mio_icif/textures/` 下的 `.png` 与 `.png.mcmeta`，归档日期为 2026-09-17 及以后，且与树中文件不同；
* 排除 2 张与旧版本（0.1.7.24）逐字节相同的饰品腰带纹理，以及 2022 年的旧速子干扰器图标、16×16 旧电子打火机图标（日期早于重绘期）；
* 不导入纹理目录中的脚本与说明（`*.py`、`*.txt`），也不导入配方、标签、语言、mixin 配置。

结果：114 个文件——103 张 PNG（粉、矿石与储存方块、板、轴、转子叶片、电路、透镜、铀系、废料等，以及青铜工具与青铜盔甲图标）和 11 个动画 `.mcmeta`（7 个新增：场发生器、生体电路、纳米活性金属、中子板、植物提取物、铀-235 与小撮铀-235；4 个工具动画改为不插值）。被替换的 107 个文件备份在工作区 `art-backup-183/`。

## 2. 武器改回 2D 图标

| 问题 | 原因 | 修复 |
|---|---|---|
| 青铜剑、纳米剑、量子剑在手中与物品栏中透明 | 三个 3D 模型带 `elements`，但父模型是 `minecraft:item/handheld`，其根为 `builtin/generated`：原版按 `layer0` 生成物品模型并忽略 `elements`，而模型没有 `layer0`，结果为空模型 | 删除 3D 模型，改为 `item/handheld` + `layer0` 的 2D 图标 |
| 纳米弓纹理闪烁、错乱 | `pulling` 属性用 `getUseItem() == stack`（同一对象判定）。纳米弓是电力物品，每次能量同步都会替换手中的物品堆，判定在“拉弓”与“未拉弓”模型之间来回切换 | 改为按物品判定（`isDrawingNanoBow`）。`pull` 改为箭的蓄力进度（`mio_icif_nano_bow.drawProgress`，第 4 tick 满力，与实际射击威力一致），不再用原版 20 tick。模型改用 `minecraft:item/bow` 的握持变换 |

新图标（32×32，`tools/art/weapons_183.py`）按“名称不变、外形不受传统长剑限制”的设计方针绘制：

* **青铜剑**：重型战术刀。单刃、 tanto 刀尖、锯齿刀背、减重孔、螺栓固定的全龙骨握柄（G10 握片）、钢制护手与带挂绳孔的钢柄头。配色与导入的青铜工具一致。
* **纳米剑**：纳米高频振动切割器。带通风槽与状态灯的振动发生器外壳、刀背的纳米发射轨、钢刃。启动时（6 帧动画）刃口发绿光，刃外侧出现随帧移动的振动残影。
* **量子剑**：量子力场发射器／奇点刃。叉形发射器夹着奇点（黑色核心与旋转的吸积环），刀身是半透明的光场：白色核心线、青色边缘、移动的干涉波纹、两处断开的边缘与飘向刀尖的火花（8 帧动画，`translucent` 渲染）。
* **纳米弓**：复合弓重绘：碳纤维弓臂与亮色边、带握把和瞄准灯的弓身、两端滑轮、能量弓弦；拉弓的 3 张图带搭好的箭。

## 3. 纳米／量子套装的物品栏图标

物品栏不再渲染 3D 盔甲模型，改为由当前 Blockbench 模型绘制的 2D 图标（`tools/art/suit_icons_183.py`：软件光栅化烘焙几何体与纹理，8× 超采样后按覆盖率缩到 32×32，深色套装提亮暗部，加左上轮廓光与暗色描边；护腿与靴子左右分开以便识别）。手持、掉落与物品展示框仍显示 3D 模型：物品模型改为 `neoforge:separate_transforms`，基础模型是 `item/3d/armor/*`（`builtin/entity`），`gui` 视角为 2D 图标。

## 5. 第一人称手臂与量子手部闪烁

* **手臂摆动不自然**：0.1.8.2 在原版设置玩家模型姿势之前绘制护甲，护甲沿用上一个被渲染玩家的手臂姿势（弓、弩、枪械姿势、特殊机动飞行姿势），与皮肤手臂不一致。现在 `SuitHandRenderer` 自行绘制整条手臂（皮肤、袖子层、护甲），从中性姿势开始：空手姿势、零运动、`xRot = 0`（与原版 `renderHand` 相同）。挥动与装备动画仍由 `ItemInHandRenderer` 的姿势栈提供。与手部护甲开关无关。
* 原版第一人称手臂（未穿套装时）同样修正：设置手臂时（`setupAnim(player, 0, 0, 0, 0, 0)`）由 `FirstPersonArm` 标记，特殊机动飞行姿势与枪械持握姿势不再作用于第一人称手臂（以前飞行或副手持枪时手臂会侧转）。
* **量子手部闪烁**：护手内侧面正好在皮肤手臂平面上（手臂空间 x = ±1.00），手端在 y = 10，并处于 0.25 的袖子层之内，产生深度冲突。`tools/armor_clearance.py` 把手臂与手部顶点中位于皮肤平面或皮肤与袖子之间的部分移到皮肤外 0.32（量子胸甲 176 个顶点、纳米胸甲 128 个）；`gen_suit_armor.py` 以后烘焙胸甲时自动执行。

## 6. 音爆云（蒸汽锥）与音爆

* **蒸汽锥**：改为 Prandtl–Glauert 凝结云的结构：紧贴锥顶的明亮领环（`exp(-z/0.22)`），之后变薄的尾部；钟形外形（`0.18 + 1.1(1 − e^(−2.4z))`，长 2.2 格，前密后疏的 10 圈、40 段）；沿锥面向后的细条纹；外层白色与内层（0.82 半径、1/3 不透明度、冷蓝色）两层，体现厚度。
* **音爆**：凝结环改为带浅杯形、三段渐变的柔和环（缓出扩张、湍流）；新增加法混合的冲击波前（锐利前缘、柔和尾光，比凝结环扩张更快）和起爆闪光（第一人称下自己的音爆不画闪光）；起爆时在环面喷出 26 个云团粒子。
* 新客户端选项 `vapor_effects`、`vapor_intensity`。

## 7. 激光武器、画面闪白与后坐力

* **画面闪白**：单发能量 ≥ 7,500 EU（power ≥ 0.75：战术激光步枪、速子干扰器、等离子枪与采矿镭射的强模式）时在枪口生成原版 `FLASH` 粒子。这是烟花闪光，约 7 格宽、面向镜头；第一人称时枪口离眼睛不到 1 格，整个画面变白（战术激光步枪每 3 tick 一次）。已删除，改为大小正确的枪口闪光：枪色的四芒星与光晕（0.1–0.26 格，90 ms，加法混合，跟随枪口）。
* **激光束**：能量弹（步枪、等离子枪、速子干扰器）以前用原版箭矢四边形与激光纹理绘制，受世界光照影响且很小；从射击者视角看光束指向正前方，缩成一个点。现在与采矿镭射一样用 `BeamFx` 绘制：加法、全亮、三层（光晕、彩色辉光、白热核心）与弹头光斑；颜色与宽度来自枪（服务器同步 `setBeam`）；前 3 tick 光束尾部从枪口开始（曳光），第一人称下也能看到自己的射击。命中时（服务器）产生电火花与枪色粉尘。
* **后坐力**：自己开枪时镜头上跳 0.5–2.4°（随单发能量）并带少量侧倾，约 150 ms 回位；只移动渲染镜头，不改变准星与玩家朝向。
* 新客户端选项 `muzzle_flash`、`reduced_flashes`（光敏保护：闪光约降至 1/3，也作用于激光塔光斑）、`recoil_camera`（0–2）、`beam_tracers`。

## 8. 推进器音效

* 量子胸甲与高级量子胸甲使用的 `sfx_jetpack_ionic_loop` 循环点前后样本差为满幅 0.21（其他循环 0.02–0.06）。四个循环音（离子、高级、电力、机动风声）用等功率交叉淡化重建（`tools/sfx_loop_183.py`，淡化 0.3 s，长度 4.0 → 3.7 s），循环点按构造连续。
* 新客户端选项 `jetpack_volume`、`jetpack_cues`（点火／熄火音）。
