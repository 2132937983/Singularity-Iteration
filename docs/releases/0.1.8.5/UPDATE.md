# 0.1.8.5 更新说明：纳米套装模块系统（第 1 阶段）

基于 0.1.8.4（工作树 `pr-0.1.8.4-20261013`）。构建环境为 Gradle 8.10.2、JDK 21、NeoForge 21.1.218，离线构建。
设计依据为已确认的设计案（LP 方式、储备／热量／爆发、改装台通用化、纳米专用单元、PvP 默认开启并可逐项关闭、17 种单元）。本版本实现第 1 阶段：基础系统与 6 种代表单元，以及纳米剑高频同步。

## 1. 基础系统

| 项目 | 内容 |
|---|---|
| 套装类别 | 新增物品标签 `mio_icif:nano_suit`（4 件纳米装甲）。`SuitModules.suitClass` 区分 QUANTUM／NANO；`isSuitPiece` 对两类都为真，`hasVisor(Player)` 仍只认量子头盔 |
| 纳米晶格（LP） | 纳米部件按晶格点数计：头 4、胸 6、腿 4、脚 4。纳米晶格致密剂每次 +2 LP，每件最多 2 次（数据组件 `mio_icif:suit_lattice`）。量子部件仍按个数（4/3/2/2） |
| 安装检查 | 新结果 `WRONG_CLASS`（单元不适用该套装类别）与 `NO_LATTICE`（LP 不足） |
| 共用规则 | 纳米专用：肌纤维、热调节膜、EMP、光学迷彩、微电容。共用：毒素过滤器（纳米 1 LP／量子 1 槽）、起爆警告与威胁传感器（纳米 1 LP）。其余量子单元为量子专用 |
| 面罩 | 量子头盔照常显示全部 HUD 单元；纳米头盔可作为“可装于纳米的 HUD 单元”（起爆警告、威胁传感器）的面罩 |
| 纳米核心 | 玩家附件 `mio_icif:nano_core`：储备 0–100（穿戴纳米部件时每秒 +2，每点 400 EU，从套装能量池支付）、热量 0–100（每秒散热 4，热调节膜下为 8）、过热锁定（达到 100 后，降到 40 以下才解锁）、两个爆发键的分配。保存并随死亡复制 |
| 爆发键 | V（主）与 B（副），可在按键设置中修改。面板为每个键选择单元；“自动”按 动能冲刺 → 光学迷彩 → EMP 的顺序选择已穿戴的爆发单元，两个键不会选同一单元 |
| 微电容 | 核心新钩子 `ArmorCapacityBonus`：`AbstractElectricArmor#getMaxEnergy(stack)` 加上各提供者的额外容量（读取、写入、充电、电量条、提示一致使用） |

### 纳米剑高频同步

纳米肌纤维开启并在主手持开启的纳米剑时：攻击速度 +12%（`ADD_MULTIPLIED_TOTAL`），近战命中时护甲减伤 ×0.85（护甲穿透 15%，`DamageContainer.Reduction.ARMOR`）。命中时目标迸出电火花。同步建立时播放同步音。Mk.II 的强化与运动装甲网的同步属于第 2 阶段。

## 3. 通用套装改装台

* 量子改装台改为“通用套装改装台”（方块 ID 不变：`producer/block_quantum_modification_station`，旧存档中的方块保留）。
* 接受量子与纳米部件；单元槽也接受晶格致密剂与附属单元物品（以前 GUI 槽位只接受内置单元物品）。
* 纳米部件显示晶格条：每格 1 LP，用占用它的单元的颜色；下方槽位中的单元会在将要占用的位置闪烁（放不下时为红色）；显示致密剂等级。单元较多时行高自动缩小。
* 新外观（`tools/station_185.py`）：石墨色基座与六边形晶格地板、带晶格环的工作台、后方立柱与朝向工作台的发射头、两根前立柱（青色纳米灯与紫色量子灯）、两侧机械夹具；发光部件为全亮。渲染器：工作台上的晶格环（纳米部件为青色，量子部件为紫色），安装时发射头投射扇形光束与扫描面，纳米部件还有上升的晶格编织环。
* 配方降为纳米层级：高级电路 ×2、OV 扫描仪、防爆玻璃 ×2、高级机器外壳、碳板 ×2、能量水晶。理由：纳米玩家先需要它；量子单元自身仍需要铱板。

## 4. 视觉与音效

| 效果 | 实现 |
|---|---|
| 动能冲刺 | 本地玩家的冲刺由客户端驱动（6 tick 速度曲线，平滑无回拉），视野瞬间加宽，屏幕边缘速度线。所有玩家可见：沿路径每 tick 一个全息网格残像（同一玩家模型，加法网格贴图，逐渐消失），路径上的热扭曲带（折射着色器）与青色速度拖尾，起点的压力环与气浪 |
| EMP | 核心闪光，扩张冲击波（中心高度的环带、地面环、三条旋转经线），冲击波前沿的扭曲环，到被命中生物与地面的锯齿放电弧（每 2 tick 重新生成），被眩晕生物身上的放电，被抹除弹体处的火花与闪光；使用者的蓝白闪屏与屏幕环 |
| 光学迷彩 | 启动：全息网格扫过身体，身体按稳定的伪随机图案闪烁消失；生效中：身体折射背后的场景（着色器 `mio_icif:nano_refract`：按法线偏移采样、边缘色散、轻微波纹），偶尔出现网格故障闪烁；解除：网格闪回。名牌隐藏。使用者屏幕边缘青色微光、扫描线与剩余时间条。未加载着色器或关闭折射时，隐藏的身体保留淡淡的网格残影 |
| 纳米 HUD | 准星周围：左侧储备弧（带 V/B 消耗刻度），右侧热量弧（青→琥珀→红，散热箭头，过热时红色脉冲与“VENT”及解锁刻度），下方两个爆发标签（键位、单元、冷却条、就绪脉冲、使用时的扩张括号、拒绝时的红叉与原因），高频同步时上方的波形标签。无变化时自动变暗。过热时红色边框与 “OVERHEAT // VENTING” |
| 高频振动刃 | 第一人称：高频同步时刀刃以约 110 Hz 的图案微颤（`applyForgeHandTransform`）；所有人可见：手部电火花 |
| 音效 | 7 个合成音效（`tools/sfx_185.py`，纯 Python）：冲刺、EMP、迷彩开启／解除、过热、拒绝、高频同步 |

渲染实现：`NanoRender` 定义三种渲染类型——`HOLOGRID`（原版能量漩涡着色器 + 网格贴图 + 滚动纹理矩阵，加法）、`REFRACT`（实体格式，采样场景拷贝）、`HAZE`（位置颜色格式的热扭曲）。场景拷贝在方块实体之后用 `glBlitFramebuffer` 从主目标复制；迷彩玩家在实体阶段只记录姿态矩阵，在方块实体之后统一绘制（因此背后的其他实体也会被折射）。物品栏预览中的玩家不受影响。`RemapBuffers` 把整个玩家（身体、护甲、手持物）的实体格式渲染类型重定向到效果类型，其它格式（附魔光效等）丢弃。

## 5. 管理面板

装备标签中选中纳米部件时，新增“纳米晶格”小节：晶格条与致密剂等级、储备与热量条、两个爆发键行（点击左半／右半循环：自动 → 各已穿戴的爆发单元 → 无）。能量标签已满，未改动。

## 6. 配置

* 通用配置新节 `NanoSuit`：`units`（6 个单元开关）、`pvp`（`empAffectsPlayers`、`camoHidesFromPlayers`、`hfSyncPiercesPlayers`，默认全开）、`core`（储备回复、每点 EU、散热、解锁阈值）、`tuning`（微电容、疾跑、冲刺距离、高频同步攻速与穿透、EMP 半径与眩晕、迷彩上限）、`bursts`（三种爆发的储备、热量、冷却）。
* `camoHidesFromPlayers` 关闭时，迷彩只对生物生效，其他玩家看到身体与淡淡的网格微光。
* 客户端配置 `nano_suit`：`nano_hud`、`nano_refraction`（光影包冲突时关闭）、`nano_fx_intensity`、`nano_hf_jitter`。

## 7. 公共 API（向后兼容）

* `SuitClass`、`SuitModuleTraits`（LP、类别、爆发）、`SuitBurstSpec`、`SuitBurstBehavior`、`SuitNanoCore`（储备、热量、上限、过热的只读视图）、`ArmorCapacityBonus`。
* `SuitModuleRegistry.register(spec, behavior, traits, burst)`：新重载；旧的两参数注册不变（视为仅量子）。`Entry` 增加 `traits()` 与 `burst()`，保留两参数构造。
* 附属的爆发单元可以分配到爆发键；附属爆发当前只支持单次型（不支持持续型）。
