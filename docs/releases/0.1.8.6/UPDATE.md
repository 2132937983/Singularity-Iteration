# 0.1.8.6 更新说明：纳米套装模块系统（第 2 阶段）

基于 0.1.8.5（工作树 `pr-0.1.8.5-20261013`）。构建环境为 Gradle 8.10.2、JDK 21、NeoForge 21.1.218，离线构建。
本版本完成已确认设计的第 2 阶段：其余 11 种单元、Mk.II 强化、高频同步等级、动能装甲网与光学迷彩的互斥、纳米改造为量子时的单元返还，以及新增特效与音效。

## 2. Mk.II

* 17 种纳米单元各有 Mk.II 物品（`module/item_module_<id>_mk2`，附魔光泽，紫金色边框图标）。配方：Mk.I 单元 + 生体电路 + 4 中子板 + 3 同系材料（终局材料）。
* 层级保存在部件的新数据组件 `mio_icif:suit_mk2`（与 `suit_modules` 同格式的 ID 列表），安装 ID 格式不变，旧存档兼容。
* 改装台：在已装 Mk.I 的部件上放入 1 个 Mk.II 即原地升级（不额外占 LP），完成后 Mk.I 返回单元槽；放入多个时显示“每次一个”。拆卸会返还对应层级的物品。列表中 Mk.II 单元带紫色“II”标记。
* Mk.II 常时耗电 ×0.8（配置 `mk2DrainFactor`）。第 1 阶段单元的 Mk.II：肌纤维疾跑 +22%、冲刺 10 格；热调节膜火 −70%/熔岩 −50%/散热 ×2.5；EMP 半径 8、眩晕 4.5 秒、紫色冲击波；光学迷彩最长 22 秒、每秒储备 4.5；毒素过滤器辐射 −85% 并过滤饥饿与反胃；微电容 +40 万 EU。

## 3. 高频同步等级

主手开启的纳米剑与纳米肌纤维、动能装甲网的织物同步：每个 Mk.I 来源 1 级，Mk.II 来源 2 级，最多 3 级。

| 等级 | 攻击速度 | 护甲穿透 |
|---|---|---|
| 1 | +12%（配置值） | 15%（配置值） |
| 2 | +15% | 22% |
| 3 | +18% | 30% |

刀刃颤动幅度与命中火花随等级增强；HUD 的 HF SYNC 标签显示等级点。

## 4. 互斥与改造

* 动能装甲网与光学迷彩：不能同时分配到 V 与 B（分配一个时清除另一个键上的冲突单元，“自动”也会跳过），运行时也互相拒绝（HUD 显示 CONFLICT）。
* 纳米改造为量子（`NanoRebuild`，合成事件）：用纳米部件合成量子部件时，共用单元（含层级）转移到量子部件；纳米专用单元、放不下的单元与晶格致密剂作为物品返还给玩家。
