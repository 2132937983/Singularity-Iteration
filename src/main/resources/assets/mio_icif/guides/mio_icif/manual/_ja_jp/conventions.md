# 単位と電圧Tier

EUは電気エネルギーの単位だ。EU/tはゲーム1 tickあたりのEUを示す。1秒は20 tickだ。
ケーブルはEUをパケット単位で運ぶ。電圧Tierは1パケットの大きさを制限する。
機械は入力電圧Tierを超えるパケットを受けると爆発する。
電源と機械の間の電圧Tierを変えるには変圧器を使う。

| 電圧Tier | 最大パケット |
|---|---|
| LV | 32 EU |
| MV | 128 EU |
| HV | 512 EU |
| EV | 2,048 EU |
| IV | 8,192 EU |
| LuV | 32,768 EU |
| ZPM | 131,072 EU |
