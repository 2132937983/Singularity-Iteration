# 発電機

発電機は燃料・日光・風・水・熱・運動エネルギーからEUを作る。
各ページに出力電圧Tierと出力EU/tを示す。

## ソーラーの2つのルート

ソーラー発電機は基本のソーラー発電機から2つのルートに分かれ、量子発電機で合流する。

| 項目 | 集光ルート | 光子共振ルート |
|---|---|---|
| 機械 | 高度 → ハイブリッド → アルティメットハイブリッド → 量子ソーラー | METS 高度 → 光子共振 → アルティメット光子共振 |
| 昼の定格 | 12 / 96 / 768 / 7,168 EU/t | 48 / 384 / 3,072 EU/t |
| 夜 | 0 | 定格の 15% / 25% / 35%（晴れた夜） |
| 定格出力の日射 | 850 W/m² | 600 / 450 / 350 W/m² |
| 遮られたとき | 発電しない | 空の光の 30% / 45% / 60% |
| 雨 / 雷雨 | 約 37% / ほぼゼロ | 約 85% / 約 61% |
| 温度 | 熱に弱い。ハイブリッド各段が冷却 | ほとんど影響しない |
| 向いている場所 | 砂漠など雨の降らない晴れた場所 | 雨の多い場所、遮られた場所、夜間の電力 |

量子発電機は両ルートの頂点（量子ソーラーパネルとアルティメット光子共振ソーラー発電機）から作る。常に 8,192 EU/t、天候の影響を受けない。
