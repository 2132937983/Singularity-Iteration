# Voltage Detector

<Row>
  <BlockImage id="mio_icif:checker/block_checker" scale="3" />
</Row>

## 機能

電圧検出器はケーブル網に接続して、網の電圧を測る。
検出器を見ると、画面に電圧、電圧Tier、入力電力が出る。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 電圧検出器を網のケーブルの隣に置く。
2. 照準を検出器に合わせる。
3. 画面で電圧と電圧Tierを読む。
4. その電圧Tierを機械の入力電圧Tierと比べる。
