# 核融合炉コントローラー

<Row><BlockImage id="mio_icif:fusion/block_fusion_controller" scale="3" /></Row>

## 機能

トカマク型核融合炉のコントローラー。構造は幅25ブロック、高さ11ブロックのトーラス（ドーナツ）で、中心ソレノイド、D形のトロイダル磁場コイル8基、外側ポロイダル磁場コイル2本、真空容器、その内側のブランケット、ダイバータ、プラズマの通路からなる。

D-T核融合のエネルギーの20%はプラズマに残って温度を保ち、80%は中性子としてブランケットに入る。ブランケットには原子炉の部品を入れられる：燃料棒は中性子で核分裂し（未臨界：核融合が止まれば核分裂も止まる）、リチウムセルは三重水素を増殖し、放熱板・熱交換器・冷却セルが冷やす。出力に上限はない：下の例のブランケットで41,440,000 EU/t（Mekanism核融合炉の2倍以上）、より強いブランケットはさらに多く出す。

## 原理

この節では、実際のトカマクに沿って炉の各部を説明する。ゲーム内の数値は縮尺されており、実際に適用される値は以下の各節に従う。

- **核融合反応**：重水素（D）と三重水素（T）の原子核が融合してヘリウム4の原子核と中性子1個になり、17.6 MeVを放出する。ヘリウム核（α粒子）は3.5 MeV、約20%を持つ。電荷を帯びているので磁場によってプラズマ内にとどまり、プラズマをさらに加熱する。中性子は14.1 MeV、約80%を持つ。電荷がないのでそのままプラズマを抜け、ブランケットに入る。
- **なぜ1億度が必要か**：どちらの原子核も正の電荷を持って反発し合うため、十分に速くないと融合できる距離まで近づけない。D-T反応は10〜20 keV（1 keVは約1,160万K）で最も効率がよく、プラズマは1億K以上に加熱する必要がある。この温度に触れられる材料はないので、磁場でプラズマを壁から浮かせて閉じ込める。
- **磁場閉じ込め**：荷電粒子は磁力線の周りを回りながら磁力線に沿っては自由に動くが、磁力線を横切ることはほとんどできない。D形の**トロイダル磁場コイル**8基がトーラスを一周する強い磁場を作る。プラズマ自身の電流が断面を回る磁場を加え、両者が合わさって磁力線がらせん状にねじれ、粒子が壁へ漂っていくのを防ぐ。**ポロイダル磁場コイル**はプラズマの位置と形を保つ。
- **中心ソレノイド**：プラズマ電流は変圧器の原理で流す。中心ソレノイドが一次巻線、リング状のプラズマが1巻きだけの二次巻線になる。ソレノイドの磁束が変化している間だけプラズマに電流が誘導されるので、燃焼は磁束を使い切るまでしか続かず（パルス運転）、その後ソレノイドを充電し直す必要がある。電子サイクロトロン加熱装置はマイクロ波で電子を押し、ソレノイドなしで電流を保てるので、燃焼を続けられる。
- **加熱と点火**：プラズマ電流の抵抗による発熱だけでは数千万度までしか上がらない。その先は外部加熱が必要になる。**中性粒子ビーム入射装置**は高速の中性原子をプラズマに撃ち込み、**電子サイクロトロン加熱装置**はマイクロ波で電子を加熱する。温度が上がるにつれてα粒子がプラズマに残す熱が増え、α粒子だけでプラズマの熱損失を補えるようになった状態が**点火**である。外部加熱を切っても燃焼は自ら続く。核融合出力と外部加熱パワーの比を**Q**と呼ぶ。ITERの目標はQ = 10で、点火したプラズマのQは無限大になる。
- **ローソン条件**：点火するには、プラズマの密度n、温度T、エネルギー閉じ込め時間τE（加熱しないときにプラズマの熱が失われるまでの時間）の積が約3 × 10²¹ keV·s/m³を超える必要がある。磁場が強く装置が大きいほど閉じ込めはよくなる。
- **ダイバータと排気**：エネルギーを失ったヘリウム核は「ヘリウム灰」となって燃料を薄め、放っておくとプラズマを消してしまう。磁場はプラズマの最外層をトーラス下部のダイバータへ導き、排気ポートのクライオポンプが灰を燃え残った燃料と一緒に排出する。
- **ブランケット**：中性子は真空容器を抜けてブランケットに入り、そのエネルギーを熱に変える。ブランケット内のリチウムは中性子を吸収して三重水素になり（リチウム6 + n → 三重水素 + ヘリウム4 + 4.8 MeV）、燃料を自給できる。この炉のブランケットには核分裂燃料棒も入れられる。中性子が核分裂を起こし、1回の核分裂で約200 MeV、核融合1回の10倍以上を放出するため、この炉は実際には**核融合・核分裂ハイブリッド炉**である。燃料棒は単独では臨界に達せず、核融合が止まれば核分裂も止まる。
- **超伝導磁石と冷却**：コイルは超伝導体なので電流は抵抗損失なしで流れるが、約−269 ℃まで冷やす必要がある。「磁石維持」の電力は実際には極低温冷凍プラントの消費電力である。冷却が追いつかないとコイルの一部が超伝導を失って抵抗のある導体に戻り、磁石に蓄えられたエネルギーがそこで一気に熱になる。これが**クエンチ**である。
- **ディスラプション**：プラズマが数ミリ秒のうちに熱と電流をすべて失う現象を**ディスラプション**と呼ぶ。プラズマの熱が第一壁を打ち、急減する電流は構造物に巨大な電磁力を誘導する。緩和システムは直前にプラズマへ大量の物質を注入し、エネルギーを一点に集中させず放射として壁全体に分散させる。

- すべてのブロックがそろっている必要がある。リング内のプラズマの通路は空気のままにする。
- ポート位置（各ダクトの先端。東側は3つ縦に並び、上がディスラプション緩和、中が極低温、下が排気）には任意の核融合ポートを置ける。使わない位置は真空容器壁でふさぐ。
- 運転には、極低温ポート、加熱ポート（中性粒子ビーム入射装置か電子サイクロトロン加熱装置）1基以上、排気ポート、電力出力ポートが必要。燃料注入ポートとディスラプション緩和ポートは任意。
- 構造全体がコントローラーの向きに合わせて回る。画面には最初に違うブロックとその座標が出る。

## 使用手順

1. 構造を組み、コントローラーにLuVの電力をつなぐ。
2. 重水素燃料棒と三重水素燃料棒を燃料スロットに入れる（燃料注入ポートに入れてもよい。下の「自動化」を参照）。新しい燃料棒1本で燃料10,000単位になり、空の燃料棒が戻る。
   - 重水素燃料棒：熱遠心分離機（熱4,000以上、1,200 tick）で熱水セルを重水セルにする。熱水は蒸気として入り、遠心分離機が重いHDOとD₂Oを分子の質量で分ける（気体遠心分離は質量差で分けるので、水の質量差は六フッ化ウランと同程度になる）。缶詰機の缶詰モードで左スロットに重水セル、中央スロットに空の燃料棒を入れると、缶詰機が重水を電気分解して重水素ガスを燃料棒に詰める。
   - 重水素燃料棒は原子炉でも中性子源として使える：隣接する燃料棒が1サイクルごとに1回多くパルスを受ける。5,000サイクル（三重水素燃料棒の半分）、崩壊熱なし。使い切ると空の燃料棒が残る。
3. ブランケット（9列×6行、第1列がプラズマ側）に部品を入れる。
4. コントローラーにレッドストーン信号を入れる。磁石の冷却（30秒）、ソレノイドの充電、加熱、点火（10 keV以上でα加熱が損失を上回ったとき）、燃焼（16段で15 keV、約1.7億K）の順に進む。
5. 画面のボタンで燃料供給（1〜20段。16段が基準で、17段以上は運転限界に近づく。後述）を変える。点火すると加熱は自動で止まる。出力は電力出力ポートから出る。

## 自動化

燃料注入ポートとディスラプション緩和ポートには専用のスロットがあり、右クリックで画面を開ける（原子炉の流体ポートと同じ）。

- **燃料注入ポート**：重水素燃料棒2枠、三重水素燃料棒2枠、空の燃料棒の出力2枠。パイプやホッパーは燃料棒を対応する枠にだけ入れられ、取り出せるのは空の燃料棒だけ。
- **ディスラプション緩和ポート**：凍結ネオンペレット4枠（このバージョンでは冷却セルも入る）。
- 構造が完成すると、コントローラーは重水素・三重水素・緩和スロットが空になるたびにポートから1つ取り、出てきた空の燃料棒を燃料注入ポートの出力枠へ送る。構造が未完成の間、アイテムはポートに残る。
- 画面にはコントローラーとの接続状態と、コントローラーにある燃料または冷却セルが表示される。ポートを壊すと中身を落とす。
- コントローラー自体にもホッパーで燃料を入れられるが、開いているのは燃料スロットと空の燃料棒の出力だけで、ブランケットには入らない。冷却セルはディスラプション緩和ポートか手で入れる。

## プラズマ

- プラズマは、ITERと同じ大きさ（830 m³）の基準装置の0次元パワーバランスで計算する：
  - 燃料供給の段数が電子密度を決める。k段は k/16 × 10²⁰ m⁻³ を目標とし、約1秒で追いつく；
  - 核融合出力 = (n/2)² × ⟨σv⟩ × 17.6 MeV × 体積。⟨σv⟩ はBosch-Haleの式で、出力は密度の2乗に比例し、10〜20 keVでは温度のほぼ2乗で増える；
  - 損失 = 熱伝導（エネルギー閉じ込め時間τEはITERのIPB98比例則に従って密度と加熱パワーで変わり、基準燃焼で約2秒）+ 制動放射。
- **点火**：10 keV以上でα加熱だけで損失をまかなえるようになると、加熱ポートは自動で止まり、Qは無限大になる。点火後に8 keVを下回ると（段数を下げたときなど）、加熱が再開する。
- **ローソン条件**：密度が低すぎると n·T·τE が約3 × 10²¹ keV·s/m³ に届かず、点火できない。8段以下は**駆動燃焼**のみで、加熱は動き続け、Qは有限（加熱装置1基で約0.5〜13）。
- **LモードとHモード**：上の閉じ込め時間は高閉じ込めモード（Hモード）のもの。プラズマ周辺を通るパワー（α加熱 + 外部加熱 − 制動放射）がL-H遷移しきい値（Martin 2008の比例則：10²⁰ m⁻³で約87 MW、密度が高いほど大きい）に達したときだけHモードに入り、その80%を下回ると低閉じ込めモード（Lモード）に戻って閉じ込め時間が半分になる。
- **加熱装置の数**：点火には9段以上かつHモードが必要。加熱装置1基（約40 MW）では点火密度のプラズマをHモードにできず、低い段での駆動燃焼しかできない。2基で9〜14段を点火でき、それより上は低い段で点火してから段数を上げる（実際の装置も密度を段階的に上げる）。3基以上なら16段で直接点火でき、4基で約4秒。
- **ELM（周辺局在モード）**：Hモードのプラズマ周辺はときどき崩れ、熱エネルギーの約1.5%をダイバータに放出する（基準燃焼で約2秒ごと、周辺パワーが大きいほど頻繁、1〜6秒）。その間の熱伝導がその分減るので平均出力は変わらないが、核融合出力は数パーセント揺れる。
- **運転限界**：燃料供給は最大20段。基準の16段を超えると出力は密度の2乗で増える（20段で約1.56倍）が、2つの限界に近づく：
  - グリーンワルド密度 n_G = I_p/(πa²) ≈ 1.19 × 10²⁰ m⁻³（16段で84%、19段で約100%）；
  - トロヨンβ限界 β_N ≤ 3.5（16段・15 keVで87%）。
  - どちらかが90%を超えるとディスラプションの危険がある。100%で毎秒約2%、それを1%超えるごとに毎秒2%ずつ増える。16段は安全、17段はほぼ安全、18段は危険、19〜20段は数秒でディスラプションする。画面にディスラプションの原因が表示される。
- 画面右の数値にマウスを乗せると、密度、τE、三重積（ローソン条件に対する割合）、α加熱と損失、外部加熱、閉じ込めモード（HモードではELMの回数）、グリーンワルド密度とβ限界に対する割合（90%から黄、100%から赤）が表示される。
- ソレノイドの磁束でプラズマを約400秒（加熱開始から）保ち、その後は再充電が要る。電子サイクロトロン加熱装置が2基あれば、プラズマ電流を駆動し（それぞれ核融合出力の1.25%を使う）、燃焼が続く。
- **燃料サイクル**：核融合率が全出力の1/16に達するごとに、ペレット入射装置が1 tickあたり重水素と三重水素を1単位ずつ入れる（16段の全出力でそれぞれ16単位）。1回の通過で核融合するのはその**3%**だけ（燃焼率：ITERで約0.3〜1%、発電炉で1〜3%）で、残りはヘリウム灰と一緒に排気ポートのクライオポンプが抜き取り、トリチウムプラントが燃料タンクに戻す。だから全出力でも実際の消費は1 tickあたりそれぞれ0.48単位で、新しい燃料棒（10,000単位）は約17分もつ。排気ポートがないと何も戻らず、入れた分をすべて使う（しかも60秒以内にヘリウム灰でディスラプションする）。
- 燃料が尽きると静かに消える。
- 出力が出始めると、コントローラーは自分の出力から40 tick分の磁石の維持電力を確保する。

## ブランケット

- 核融合の中性子は列ごとに減る：最大出力で第1・2・3列の各スロットに1サイクルあたり2・1・1個、それより後の列には届かない。
- 燃料棒はそれを追加のパルスとして数え、発熱と発電が増える（原子炉と同じ規則）。リチウムセルは核融合中性子1個につき三重水素を1単位増殖し（リチウム6 + n → 三重水素 + ヘリウム4）、10,000で三重水素燃料棒になる。第1列にリチウムセルを5個置くと三重水素増殖比は約1.04（ちょうど自給）、6個で約1.25。燃料棒の隣のリチウムセルは核分裂中性子でも増殖する。（劣化同位体棒は今も核融合中性子1個につき40進む。）
- これは**核融合・核分裂ハイブリッド炉**のブランケットで、熱だけを生み、コントローラー内蔵の蒸気サイクルがその **35%** を電気に変える（加圧水型原子炉並み）。熱出力は4つの部分からなる：
  - α粒子が第一壁とダイバータに与える熱：中性子出力の1/4；
  - 中性子自身のエネルギー：中性子出力 × 1；
  - リチウム6が中性子を吸収して放つ4.8 MeV：中性子出力 × 0.34 × リチウムセルが吸収した中性子の割合；
  - 中性子が起こす核分裂（1回約200 MeV）：45,250 × 燃料棒の核分裂出力（原子炉のEU/t換算）× 出力の割合。
- 出力 ＝ 熱出力 × 35%。上限はない（オーバーフロー防止のため、電力網の最高電圧 2,147,483,647 EU/t でのみ打ち切る）。
- 画面のマウスオーバー表示の「発電所」の部分には、熱出力と発電量、ブランケットのエネルギー増倍M（ブランケットの熱出力 ÷ 中性子出力：リチウムだけなら約1.3、例のブランケットで約14.9）、核融合中性子1個あたりの核分裂回数（例のブランケットで約1回）、三重水素増殖比TBR（1サイクルに増殖した三重水素 ÷ 燃やした三重水素。1を超えれば自給できる）、工学的Q（出力 ÷ コントローラー自身の消費電力）が出る。
- たとえば、イリジウムオーバークロック放熱板で囲んだプロトン4連燃料棒で熱出力118,400,000 EU/t、出力41,440,000 EU/t（フルパワーの進捗の39,200,000を超える）。燃料棒のないブランケットは熱出力の35%しか出ず、空なら約3,430,000 EU/t。核分裂出力の高いブランケットならさらに多い。ブランケットの熱が最大（10,000＋装甲板）に達するとメルトダウンする（下記）。

## 危険

- **ディスラプション**：次の場合に起きる。
  - 磁石がクエンチした。
  - プラズマがあるときに構造が壊れた。
  - 排気ポートがなくヘリウム灰がたまった（60秒）。
  - 運転限界（密度またはβ、上記）を超えた。

  プラズマの熱エネルギーが第一壁を打ち、ブランケットの熱はそれに比例して増える：基準燃焼（16段、15 keV）で1、低い段や加熱の初期はより少なく、20段ではより多い。
  - 緩和なし：基準燃焼でブランケットの熱が最大値の半分増える。プラズマのエネルギーが基準の25%以上なら、ブランケット第1列の部品が壊れる。
  - **破砕ペレット入射**：ディスラプション緩和スロットに**凍結ネオンペレット**があれば、直前に1個を砕いてプラズマに入れる（消費）。ネオンが熱を放射に変えて壁全体に均一に逃がすので、部品は残り、基準燃焼でもブランケットの熱は最大値の5%しか増えない。凍結ネオンペレットは圧縮機で圧縮空気セルを凍らせて作る（32 EU/t、400 tick）。
  - 冷却セルもこのバージョンでは緩和スロットに入れられる（10k 30%、30k 20%、60k 5%、同じく熱エネルギーで比例）。後のバージョンで使えなくなる。
  - ディスラプションで構造ブロックが壊れることはない。
- **メルトダウン**：ブランケットの熱が最大に達する（ブランケット自体の過熱、またはディスラプションの熱が加わる）と、メルトダウンし、コントローラーと中身が消える。トカマクには数グラムの燃料しかなく、核爆発は起こりえないので、既定では：
  - 超伝導磁石がクエンチし、蓄えた磁気エネルギー（ITERで約51 GJ）が一気に放出される：トーラスの中心で威力16の通常の爆発、さらにプラズマのリングに沿って8基のトロイダル磁場コイルの脇でそれぞれ威力8の爆発が起き、真空容器とブランケットを吹き飛ばす（enableNuclearExplosion がオフなら地形も構造も壊さない）；
  - 溶けたハイブリッドブランケット（核分裂燃料を含む）が半径48ブロックの放射能汚染区域を24時間（実時間）残す。
  - 設定 fusionNuclearMeltdown を true にすると旧来の核爆発になる：威力は原子炉の爆発威力上限の fusionExplosionMultiplier 倍（既定 50 × 45 = 2,250）。fusionExplosionMultiplier が0ならどちらも起きず、ブランケットの過熱でプラズマがディスラプションするだけになる。
- **クエンチ**：磁石の維持電力が足りないと超伝導が切れる。60秒後に冷却をやり直す。
- **放射線**：燃焼中、トーラスから16ブロック以内の生物は毎秒0〜3の放射線ダメージを受ける。遮蔽ブロックで減り、防護服一式で完全に防げる。
