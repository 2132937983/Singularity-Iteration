# 核融合炉コントローラー

<Row><BlockImage id="mio_icif:fusion/block_fusion_controller" scale="3" /></Row>

## 機能

トカマク型核融合炉のコントローラー。構造は幅25ブロック、高さ11ブロックのトーラス（ドーナツ）で、中心ソレノイド、D形のトロイダル磁場コイル8基、外側ポロイダル磁場コイル2本、真空容器、その内側のブランケット、ダイバータ、プラズマの通路からなる。

D-T核融合のエネルギーの20%はプラズマに残って温度を保ち、80%は中性子としてブランケットに入る。ブランケットには原子炉の部品を入れられる：燃料棒は中性子で核分裂し（未臨界：核融合が止まれば核分裂も止まる）、リチウムセルは三重水素を増殖し、放熱板・熱交換器・冷却セルが冷やす。出力に上限はない：下の例のブランケットで41,440,000 EU/t（Mekanism核融合炉の2倍以上）、より強いブランケットはさらに多く出す。

## 電力データ

| 項目 | 値 |
|---|---|
| 出力 | 上限なし；例のブランケットで 41,440,000 EU/t |
| 核融合出力 | 燃料供給1段あたり 612,500 EU/t、16段で 9,800,000 EU/t |
| 入力電圧Tier | LuV (32,768 EU)、どの面からでも |
| 入力蓄電 | 20,000,000 EU |
| 磁石の維持 | 392,000 EU/t |
| 起動（中心ソレノイド） | 300,000,000 EU、最速30秒 |
| 加熱 | 加熱ポート1基あたり 245,000 EU/t、最大で核融合出力の10分の1 |

- すべてのブロックがそろっている必要がある。リング内のプラズマの通路は空気のままにする。
- ポート位置（各ダクトの先端。東側は3つ縦に並び、上がディスラプション緩和、中が極低温、下が排気）には任意の核融合ポートを置ける。使わない位置は真空容器壁でふさぐ。
- 運転には、極低温ポート、加熱ポート（中性粒子ビーム入射装置か電子サイクロトロン加熱装置）1基以上、排気ポート、電力出力ポートが必要。燃料注入ポートとディスラプション緩和ポートは任意。
- 構造全体がコントローラーの向きに合わせて回る。画面には最初に違うブロックとその座標が出る。

## 使用手順

1. 構造を組み、コントローラーにLuVの電力をつなぐ。
2. 重水素燃料棒と三重水素燃料棒を燃料スロットに入れる（燃料注入ポートに入れてもよい。下の「自動化」を参照）。新しい燃料棒1本で燃料10,000単位になり、空の燃料棒が戻る。
   - 重水素燃料棒：熱遠心分離機（熱4,000以上、1,200 tick）で熱水セルを不安定な熱水セルにし、缶詰機の缶詰モードで左スロットに不安定な熱水セル、中央スロットに空の燃料棒を入れる。
   - 重水素燃料棒は原子炉でも中性子源として使える：隣接する燃料棒が1サイクルごとに1回多くパルスを受ける。5,000サイクル（三重水素燃料棒の半分）、崩壊熱なし。使い切ると空の燃料棒が残る。
3. ブランケット（9列×6行、第1列がプラズマ側）に部品を入れる。
4. コントローラーにレッドストーン信号を入れる。磁石の冷却（30秒）、ソレノイドの充電、加熱、点火（14 keV、約1.6億K）、燃焼（約15 keV）の順に進む。
5. 画面のボタンで燃料供給（1〜16段）を変える。点火後は加熱がいらない。出力は電力出力ポートから出る。

## 自動化

燃料注入ポートとディスラプション緩和ポートには専用のスロットがあり、右クリックで画面を開ける（原子炉の流体ポートと同じ）。

- **燃料注入ポート**：重水素燃料棒2枠、三重水素燃料棒2枠、空の燃料棒の出力2枠。パイプやホッパーは燃料棒を対応する枠にだけ入れられ、取り出せるのは空の燃料棒だけ。
- **ディスラプション緩和ポート**：冷却セル（10k・30k・60k）4枠。
- 構造が完成すると、コントローラーは重水素・三重水素・緩和スロットが空になるたびにポートから1つ取り、出てきた空の燃料棒を燃料注入ポートの出力枠へ送る。構造が未完成の間、アイテムはポートに残る。
- 画面にはコントローラーとの接続状態と、コントローラーにある燃料または冷却セルが表示される。ポートを壊すと中身を落とす。
- コントローラー自体にもホッパーで燃料を入れられるが、開いているのは燃料スロットと空の燃料棒の出力だけで、ブランケットには入らない。冷却セルはディスラプション緩和ポートか手で入れる。

## プラズマ

- 点火までは加熱ポートで加熱する（Q = 10）。14 keVからはα粒子の熱で燃え続け、Qは無限大になる。
- ソレノイドの磁束で約400秒燃焼し、その後は再充電が要る。電子サイクロトロン加熱装置が2基あれば、プラズマ電流を駆動し（それぞれ核融合出力の1.25%を使う）、燃焼が続く。
- プラズマは燃料供給1段・1 tickあたり重水素と三重水素を1単位ずつ使う。燃料が尽きると静かに消える。
- 出力が出始めると、コントローラーは自分の出力から40 tick分の磁石の維持電力を確保する。

## ブランケット

- 核融合の中性子は列ごとに減る：最大出力で第1・2・3列の各スロットに1サイクルあたり2・1・1個、それより後の列には届かない。
- 燃料棒はそれを追加のパルスとして数え、発熱と発電が増える（原子炉と同じ規則）。リチウムセルは中性子1個につき40進み、10,000で三重水素燃料棒になる。第1列にリチウムセルを約5個置けば三重水素を自給できる。
- 出力 ＝ 中性子出力 ×（1 ＋ 0.2 × リチウムセルが吸収した中性子の割合）＋ 14,000 × 燃料棒の核分裂出力（原子炉のEU/t換算）× 出力の割合。上限はない（オーバーフロー防止のため、電力網の最高電圧 2,147,483,647 EU/t でのみ打ち切る）。
- たとえば、イリジウムオーバークロック放熱板で囲んだプロトン4連燃料棒で41,440,000 EU/t（フルパワーの進捗の39,200,000を超える）。核分裂出力の高いブランケットならさらに多い。ブランケットの熱が最大（10,000＋装甲板）に達するとメルトダウンする（下記）。

## 危険

- **ディスラプション**：次の場合に起きる。
  - 磁石がクエンチした。
  - プラズマがあるときに構造が壊れた。
  - 排気ポートがなくヘリウム灰がたまった（60秒）。

  ブランケット第1列の部品が壊れ、熱が最大値の半分だけ増える。ディスラプション緩和スロットに冷却セルがあれば1個注入し（消費）、部品は残り、熱の増え方は少なくなる：10k冷却セルで30%、30k冷却セルで20%、60k冷却セルで5%（使用済みのセルは残りの冷却量で計算）。ディスラプションで構造ブロックが壊れることはない。
- **メルトダウン**：ブランケットの熱が最大に達する（ブランケット自体の過熱、またはディスラプションの熱が加わる）と、メルトダウンする。コントローラーと中身が消え、トーラスの中心で核爆発が起きる。威力は原子炉の爆発威力上限の50倍（設定 fusionExplosionMultiplier、既定 50 × 45 = 2,250）、最大半径はその2倍だが2,000ブロックまで。倍率0ではブランケットの過熱でプラズマがディスラプションするだけになり、enableNuclearExplosion がオフなら周囲の地形を壊さない局所的な爆発になる。
- **クエンチ**：磁石の維持電力が足りないと超伝導が切れる。60秒後に冷却をやり直す。
- **放射線**：燃焼中、トーラスから16ブロック以内の生物は毎秒0〜3の放射線ダメージを受ける。遮蔽ブロックで減り、防護服一式で完全に防げる。
