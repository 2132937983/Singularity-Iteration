# 原子炉発電機

<Row>
  <BlockImage id="mio_icif:generator/block_nuclear_reactor_generator" scale="3" />
</Row>

## 機能

機械は核燃料棒を燃やしてEUと熱を作る。
隣接する原子炉チャンバー1個ごとに部品スロットが1列増える。
原子炉圧力容器の構造を作ると、機械は流体モードに切り替わりクーラントを加熱する。流体モードでは EU は出ない。熱は高温冷却材として出ていき（Jade に毎秒の HU が出る）、<ItemLink id="mio_icif:hugenerator/block_heat_source_fluid" />で使う。MOX 燃料棒は炉温が最大の半分を超えると発熱が 2 倍になる。

## 電力データ

| 項目 | 値 |
|---|---|
| 出力電圧Tier | IV (8,192 EU) |
| 出力 | 524,288 EU/t |
| 蓄電容量 | 1,000,000 EU |

この値は本バージョンのブロックエンティティから計測した。

## 使用手順

1. 原子炉チャンバーを原子炉の各面に接して置く。
2. 燃料棒と冷却部品をスロットに入れる。
3. ケーブルを原子炉に接続する。
4. 原子炉にレッドストーン信号を入れて起動する。原子炉チャンバーや圧力容器のレッドストーンポートでも信号を受け取る。信号がないと原子炉は動かず、画面と Jade に「停止中：レッドストーン信号なし」と出る。

## 炉温の段階

炉の熱が 4,000 HU 以上になると、原子炉はサイクルごと（1 秒）に「炉の熱 / 最大熱容量」で次の段階を判定する。
確率とダメージには封じ込め係数を掛ける：原子炉プレートなしで 1、プレート 1 枚ごとに下がる（原子炉プレートは ×0.95）。
サーバーが原子炉の爆発を無効にしている（爆発倍率か威力上限が 0）とき、これらの効果も起きない。

| 炉温 / 最大 | 効果（原子炉が中心） | 範囲 |
|---|---|---|
| ≥ 40 % | 封じ込め係数の確率でランダムな 1 ブロック：燃えるブロック（板材、原木、葉、苗木、花、作物、草）が火になる。 | 5×5×5 |
| ≥ 50 % | 封じ込め係数の確率でランダムな 1 ブロック：水が蒸発する。水源と流れる水は消え、水浸しのブロックは水だけを失い、コンブ・海草・気泡柱は干上がる。 | 5×5×5 |
| ≥ 70 % | サイクルごとに、範囲内の各生物が 0〜3 の放射線ダメージ（封じ込め係数倍）を受ける。ハズマットスーツ一式か量子スーツ一式で完全に防げる。ナノの毒素フィルターはダメージを減らす。 | 7×7×7 |
| ≥ 85 % | 20 % × 封じ込め係数の確率でランダムな 1 ブロック：空気は火に、石・金属などツルハシで掘るブロックは溶岩に、その他の壊せるブロックは火になる。 | 5×5×5 |
| 100 % | 原子炉が爆発する。 | - |

熱で変わらないブロック：岩盤などの壊せないブロック、ブロックエンティティを持つブロック（チャンバー、ポート、機械など）、
データタグ `mio_icif:reactor_heat_immune` のブロック：建築フォームとその壁、原子炉、原子炉チャンバー、
原子炉圧力容器とそのインターフェースブロック（アクセスハッチ、流体ポート、レッドストーンポート）、冷却材注入器。

> **注意：** 水中の原子炉では、85 % 段階の溶岩がバニラの規則で隣の水と反応する：溶岩源は黒曜石に、流れる溶岩は丸石か石になる。
> 保護されたブロック自体は変わらないが、原子炉のまわりの普通のブロック（石など）は先に溶岩になり、そのあと黒曜石になることがある。

## 放射線の遮蔽

鉛は放射線を止める。放射線は原子炉から生物へ直線で進み、その線上の各ブロックは一部だけを通す。

| ブロック | 通過する放射線 |
|---|---|
| 鉛ブロックと c:storage_blocks/lead タグの全ブロック（データタグ mio_icif:radiation_shielding） | 10 % |
| 強化石、黒曜石、泣く黒曜石、強化深層岩、鉄ブロック、ネザライトブロック、鋼鉄ブロック（データタグ mio_icif:radiation_shielding_weak） | 50 % |

- 5 % 未満は何も通らない：鉛ブロック 2 個、または鉛ブロック 1 個と弱い遮蔽ブロック 2 個で完全に止まる。
- 生物は、目への線と体の中心への線のうち、遮蔽の少ない方を通して被曝する。体全体を覆うこと。
- 核爆発で生まれる放射性ブロック（ブロックからの線）と核爆発ゾーンにも同じ規則が働く。爆発ゾーンでは、爆心方向の遮蔽と屋根（上 16 ブロックの線）の両方が必要：2 本の線のうち開いている方が数えられる。
- ハズマット一式と量子スーツ一式は、これまでどおり完全に防ぐ。
- <ItemLink id="mio_icif:normal/item_contain_ment_box" /> に入れた放射性アイテムは被曝させない。箱は 18 スロット：使うと開く。

## 事故調査

原子炉は最新 40 サイクルを記録している。事故の後、<ItemLink id="mio_icif:reactor/item_reactor_blackbox" /> が現場に落ちる。それを使うか `/mio_icif reactor audit` を実行すると、主因、融解した部品を示す炉心レイアウト、炉熱グラフのレポートを読める。詳しくは[原子炉事故調査](reactor_audit.md)を参照。

## 注意


> **警告：** 炉の温度が上限に達すると、原子炉は爆発する。


> **警告：** 炉温 40 % から、原子炉はブロックに火をつけ、水を蒸発させ、生物を被曝させ、溶岩を作る（「炉温の段階」を参照）。
