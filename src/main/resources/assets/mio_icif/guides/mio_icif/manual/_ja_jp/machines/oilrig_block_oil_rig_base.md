# Oil Rig Base Module

<Row>
  <BlockImage id="mio_icif:oilrig/block_oil_rig_base" scale="3" />
</Row>

## 機能

石油リグ基礎モジュールは石油リグの構造ブロックだ。モジュールの位置を埋めるだけで、独自の機能はない。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 石油リグコアの周りにモジュールの輪を作る。
2. 必要な位置に入力モジュールと貯油モジュールを置く。
3. 残りのモジュール位置を基礎モジュールで埋める。
