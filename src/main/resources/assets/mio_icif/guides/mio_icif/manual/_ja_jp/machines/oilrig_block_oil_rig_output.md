# Oil Rig Output Module

<Row>
  <BlockImage id="mio_icif:oilrig/block_oil_rig_output" scale="3" />
</Row>

## 機能

石油リグ貯油モジュールはドリルが掘り出した原油を蓄える。パイプでモジュールから原油を取り出せる。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 貯油モジュールをリグのモジュール位置に置く。
2. 抽水パイプの背面をモジュールに向けて置く。
3. 抽水パイプからタンクか機械へパイプをつなぐ。

## 注意

- すべての貯油モジュールが満杯になると、リグは止まる。
