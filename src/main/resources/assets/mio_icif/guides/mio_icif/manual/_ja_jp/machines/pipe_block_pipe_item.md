# Item Transport Pipe

<Row>
  <BlockImage id="mio_icif:pipe/block_pipe_item" scale="3" />
</Row>

## 機能

アイテム輸送パイプはパイプの間でアイテムを運び、接続したコンテナに入れる。
パイプはアイテム抽出パイプからアイテムを受け取り、空きのあるコンテナを探す。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 元のコンテナの隣にアイテム抽出パイプを置く。
2. 抽出パイプから目標のコンテナまでアイテム輸送パイプをつなぐ。
3. レンチでパイプの枝を右クリックし、その方向を閉じる。

## 注意

- パイプを壊すと、中のアイテムが地面に落ちる。
