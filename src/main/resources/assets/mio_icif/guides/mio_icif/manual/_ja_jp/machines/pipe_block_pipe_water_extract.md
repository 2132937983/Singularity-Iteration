# Water Extraction Pipe

<Row>
  <BlockImage id="mio_icif:pipe/block_pipe_water_extract" scale="3" />
</Row>

## 機能

抽水パイプは背面のブロックから流体を吸い出し、正面から出力する。
LVケーブルのEUで転送速度が上がる。EUがない時、パイプは低い基本速度で流体を運ぶ。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 元のタンクを見ながら、タンクに接してパイプを置く。
2. 抽水パイプの正面に輸水パイプを接続する。
3. LVケーブルを接続し、転送速度を上げる。

## 注意

- 抽水パイプは正面と背面だけで接続する。
