# Mining Pipe

<Row>
  <BlockImage id="mio_icif:produce/block_mining_pipe" scale="3" />
</Row>

## 機能

採掘パイプは採掘機の構造ブロックだ。採掘機は掘り進むときに自分の下へパイプを置く。
採掘機がないと、パイプに機能はない。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 採掘パイプをクラフトする。
2. 採掘パイプを採掘機のパイプスロットに入れる。
3. 採掘機が深く掘る間、パイプスロットを空にしない。
