# Mining Drill Tip

<Row>
  <BlockImage id="mio_icif:produce/block_mining_tip" scale="3" />
</Row>

## 機能

採掘ドリル先端は採掘機の構造ブロックだ。採掘機は採掘パイプの下端に先端を置く。
先端そのものに機能はない。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 採掘機に先端を自動で置かせる。
2. 採掘機が動いている間、先端をそのままにする。
