# アーマーショーケース

<Row>
  <BlockImage id="mio_icif:producer/block_armor_showcase" scale="3" />
</Row>

## 機能

アーマーショーケースはマネキンに一式の装備を飾る。
武装庫リモートがあれば、装備特性管理で着ている装備とショーケースの装備を交換できる。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 防具か武器を持ってショーケースを右クリックし、マネキンに着せる。
2. 素手でスニークしてショーケースを右クリックし、装備一式を交換する。
3. 素手でショーケースを右クリックし、マネキンを回す。
4. ペア済みの武装庫リモートで右クリックし、武装庫のスーツを映す。
5. ショーケースにレッドストーン信号を入れ、ターンテーブルを回す。
6. 素手で台座の側面を右クリックし、ホログラム展示と実体展示を切り替える（台座の上面はこれまでどおりマネキンを回す）。

## 注意

- 武装庫のスーツを映すショーケースはアイテムを持たない。リモートを持ってスニークで使うと、リンクを解除する。
- コンソールの換装は、自分か武装庫の近くのショーケースだけが対象だ。
- 装備はホログラムで映る：透けるシアンの光とホログラムの格子、下から上へ走るスキャンの帯、ときどき短い横ずれのグリッチ。装備が変わると、新しい装備がスキャンラインに沿って足元から組み上がる。
- 実体展示：本物の装備がグラファイトのマネキンに着せられ、世界の光で照らされ、機械式の台座（人形の背後の支柱と、肩と腰へ伸びる固定アーム）で支えられる。切り替えると台座が展開する。ナノ・量子スーツは呼吸する発光を保つ。モードは投影機ごとに保存される。
