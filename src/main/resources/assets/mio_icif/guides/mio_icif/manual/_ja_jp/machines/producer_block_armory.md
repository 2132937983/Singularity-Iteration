# 武装庫

<Row>
  <BlockImage id="mio_icif:producer/block_armory" scale="3" />
</Row>

## 機能

武装庫は6着のスーツを保管する。各スーツはヘルメット、チェストプレート、レギンス、ブーツ、メインハンド、オフハンドの6部位だ。
武装庫は指令に従い、保管したスーツを所有者へ飛ばす。
武装庫はEUで保管中の装備を修理し、充電する。Botaniaの装備には武装庫のマナタンクのマナを使う。

## 電力データ

| 項目 | 値 |
|---|---|
| 入力電圧Tier | HV (512 EU) |
| 最大入力 | 512 EU/t |
| 蓄電容量 | 1,000,000 EU |

この値は本バージョンのブロックエンティティから計測した。

## 使用手順

1. HVケーブルを武装庫に接続する。
2. 通電した武装庫を右クリックし、所有者になる。
3. GUIでスーツのスロットに装備を入れる。
4. 武装庫リモートコントローラーを持ち、スニークして武装庫を右クリックし、ペアにする。
5. リモートをチャームかベルトのアクセサリスロットに着ける。
6. 装備特性管理の武装庫セクションを開き、召喚を押す。

## 注意

- 武装庫はEUを蓄えてから所有者を受け付ける。所有者だけが登録済みの武装庫を開き、使い、壊せる。
- 他のMODの装備は、コネクターキットで接続してから武装庫に入れる。
- 召喚ごとにEUを使う。距離と次元の移動でコストが増える。

## ウィングマンの安全機構

- モブ捕獲ツール（ソウルバイアル、モブ収容ツール、封じ込めの瓶、捕獲ボール）ではウィングマンを捕まえられない：ウィングマンに使ったアイテムは何もせず、ウィングマンはこれらの MOD の捕獲禁止タグと c:capturing_not_supported に入っている。
- 出撃ごとに出撃トークンがある。スーツがすでに帰還したウィングマンの複製（たとえば旧バージョンの捕獲ツールから）は、現れた時点でアイテムなしで消える。持ち主にチャットで知らせる。
- ウィングマン、またはウィングマンが生んだ効果（抜刀剣の斬撃など）の tick が失敗すると、クラッシュの代わりにスーツが帰還し、ウィングマンは消える。詳細はサーバーログにある。
- ウィングマンはプレイヤーの全属性（リーチ、範囲攻撃、幸運など）を持つので、他 MOD の武器も手に持って使える。

## ウィングマンの戦術

- **目標：** あなたが攻撃した敵（全ウィングマンが集中）、近くのクリーパー（着火中は最優先）、あなたを攻撃した敵、あなたを狙う敵（遠距離攻撃の敵を優先）、それ以外の近い敵の順。呼びかけた敵以外は別々の目標に分散する。
- **遠隔武器：** 目標の向こう側の高い位置で、射線が通りあなたが射線に入らない場所を選ぶ。敵が近づきすぎるとスラスターで退避する。
- **近接・刀剣：** 側面や背後から入り、斬って離脱し、また別の角度から攻める。クリーパーはあなたから遠ざけるように弾き飛ばす。
- **演出：** モード色のスキャンレーザーとホログラムマーカーで目標を示し、射撃の閃光、ブースト時の噴射、旋回ごとの姿勢制御噴射が見える。クライアント設定 wingman_fx。
- **待機時の着地：** あなたが地上に立ったまま 2 秒間目標がないと、ウィングマンはあなたのそばの地面に降りてスラスターを止める。待機命令の地点でも着地する。目標・命令、またはあなたが歩き去る・飛ぶ・滑空すると、すぐに離陸する。
- **抜刀剣：** 腕は刀を構えたまま静止し、斬撃ごとに振る動作を再生する。コンボは袈裟斬り、突進は水平の薙ぎ払い、SA は両手の振り下ろし。どの斬撃も最後まで見えるよう、コンボ入力は 8 tick ごと。

量子スーツに量子もつれ中継器があれば、コマンドホイールから僚機に命令（移動、待機、区域制圧、集中攻撃）もできる（「量子指揮」を参照）。
