# Barrel

<Row>
  <BlockImage id="mio_icif:producer/block_barrel" scale="3" />
</Row>

## 機能

酒樽は小麦、ホップ、水でビールを造る。酒樽はサトウキビと水でラム酒を造る。
ビールは醸造時間が長いほど強い段階に変わる。酒樽はEUを使わない。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 酒樽を右クリックしてGUIを開く。
2. 材料と水バケツをスロットに入れる。
3. スニークして酒樽を右クリックし、醸造の進み具合を見る。
4. 石のジョッキで酒樽を右クリックして酒を取り出す。
