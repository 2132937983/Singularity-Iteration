# 高級チタン合金高炉

<Row>
  <BlockImage id="mio_icif:producer/block_blast_furnace_advanced" scale="3" />
</Row>

## 機能

高級チタン合金高炉は熱（HU）と圧縮空気を使い、高炉のレシピを処理する。
この高炉は高炉より速い。この高炉は正面からだけ熱を受け取る。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 高炉の正面に熱発生機を置く。
2. 圧縮空気セルを空気スロットに入れる。
3. 入力アイテムを入力スロットに入れ、高炉が熱くなるまで待つ。
4. 出力スロットから成果物と空セルを取り出す。

## 注意

- レッドストーン信号は高炉を熱いまま保ち、処理を止める。
