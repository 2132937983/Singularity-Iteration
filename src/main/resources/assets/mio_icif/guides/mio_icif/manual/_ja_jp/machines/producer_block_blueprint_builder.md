# ブループリントビルダー

<Row>
  <BlockImage id="mio_icif:producer/block_blueprint_builder" scale="3" />
</Row>

## 機能

4機の建築ドローンが設計図のブロックを1つずつ設置します。
ドローンは[武装庫資材インターフェース](producer_block_material_interface.md)から建材を取り出します。クリエイティブでは[無限武装庫資材インターフェース](producer_block_infinite_material_interface.md)がすべての建材を無限に供給します。

## 設計図のソース

* スロットに入れた配置済みのCreate設計図。アンカー・回転・反転は設計図の値を使います。
* ゲームの `schematics` フォルダのファイル（サーバーではサーバーフォルダ）。`.nbt` 構造物ファイル（Create設計図を含む）と `.litematic` ファイル（Litematica）を読み込みます。
* サーバーでは、自分のコンピューターのファイル：「送信」を押して自分の `schematics` フォルダのファイルを選びます。ファイルはサーバーへ送られ（Createの設計図テーブルと同じ）、建築機がすぐ読み込みます。サーバーは `schematics/uploads/<あなたのUUID>/` に保存し、同じファイルは二度送りません。シングルプレイでは不要です（ファイルはすでに一覧にあります）。
* このMODのマルチブロック構造：「構造集」を押して左の一覧から選びます（核融合炉トカマク、TESU、蒸気トンネル、各種原子炉など。JEI「マルチブロック構造」の建造図と同じ）。右側では JEI と同じくドラッグで回転、ホイールで拡大縮小、層ごとの表示ができ、下に必要な材料が並びます。「これを建てる」で決定します。複数のブロックを置ける位置にはおすすめのブロックを置き、核融合炉のポートはおすすめの配置どおり、TESU のポート位置には入力ポートと出力ポートを交互に置きます。構造の中で空気が必要な場所（核融合炉のプラズマ通路、TESU や蒸気トンネルの内部）は自動では空けません。

## 電力データ

| 項目 | 値 |
|---|---|
| 入力電圧 | MV（128 EU） |
| 蓄電容量 | 200,000 EU |
| 1ブロックあたりのエネルギー | 40 EU |
| 範囲 | 制限なし（設計図のオフセットは各軸 1,024 ブロックまで）。読み込まれていないチャンクのブロックは読み込まれるまで待ちます（大規模な建築にはチャンクローダーが便利です） |
| 設計図の大きさ | ブロック数の上限なし。サーバーのメモリだけが制限です（収まらないときは「大きすぎます」と表示） |
| ドローン | 4機 |

## 手順

1. ビルダーから16ブロック以内に武装庫資材インターフェースを置きます。
2. 建材をインターフェースまたは隣接するストレージに入れます。
3. 配置済みのCreate設計図をスロットに入れるか、`<` `>` ボタンでファイルを選びます。サーバーでは「送信」で自分のコンピューターのファイルを送れます（すぐ読み込まれるので手順 4 へ）。
4. ファイルの場合は、設計図を配置します：「ワールドで調整」を押し、ホログラムを見ながら操作します。ホイールで視線の方向へ 1 ブロック移動（Ctrl で 5）、R で回転、M で反転、右クリックか Esc で終了します。画面の R・M ボタンでも回転・反転できます。Esc は配置を終えるだけで、ポーズメニューは開きません。
5. 「読込」をクリックすると、ホログラムが作業範囲を表示し、まだ置かれていないブロックをそれぞれ半透明で表示します。範囲ボタンで「ブロック」（すべて）、「現在層」（まだ建っていない一番下の層だけ）、「枠」（範囲の枠だけ）、「非表示」を切り替えます。ブロックの表示は自分だけ、枠は全員に見えます。大きな設計図でも重くなりません：表示は一度だけ作り、変わった部分だけ作り直します。
6. 「開始」をクリックします。

## 規則

* ドローンは最下層から順に上へ設置します。
* ドローンはブロックを壊しません。別のブロックがある位置はスキップし「障害物」として数えます。
* 通常のアイテムのみ使用します。中身・名前・エンチャントのあるアイテムは使いません。
* ドアや背の高い植物の上半分、ベッドの頭側はアイテム不要です。
* 水没ブロックは水なしで設置します。液体は設置しません。
* 設置ごとにビルダー所有者としてブロック設置イベントを発行します。保護Modはこれを止められます。

**注意：** 「開始」の前に作業範囲のホログラムを確認してください。ドローンは範囲内の空き位置をすべて埋めます。設計図の位置に別のブロックがあると、ドローンはそれを掘り取り（ドロップは一番近い武装庫資材インターフェースへ）、設計図のブロックを置きます。ブロックエンティティを持つブロック（機械、チェスト）と壊せないブロックは掘らず、土地保護には先に確認します。サーバーは設定 `clearObstructions` でこの機能を切れます。

最後のブロックを置くと、建築機は 2 秒待ってから設計図全体をもう一度確認します。支えがなくて落ちたブロック（支えより先に置かれた次元石油リグの足場など）や途中で壊されたブロックは建て直します。確認は最大 3 回です。完成後にもう一度「開始」を押しても、確認して抜けを埋めます。
