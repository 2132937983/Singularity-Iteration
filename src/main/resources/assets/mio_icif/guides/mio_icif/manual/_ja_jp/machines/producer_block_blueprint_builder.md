# ブループリントビルダー

<Row>
  <BlockImage id="mio_icif:producer/block_blueprint_builder" scale="3" />
</Row>

## 機能

4機の建築ドローンが設計図のブロックを1つずつ設置します。
ドローンは[武装庫資材インターフェース](producer_block_material_interface.md)から建材を取り出します。

## 設計図のソース

* スロットに入れた配置済みのCreate設計図。アンカー・回転・反転は設計図の値を使います。
* ゲームの `schematics` フォルダのファイル（サーバーではサーバーフォルダ）。`.nbt` 構造物ファイル（Create設計図を含む）と `.litematic` ファイル（Litematica）を読み込みます。

## 電力データ

| 項目 | 値 |
|---|---|
| 入力電圧 | MV（128 EU） |
| 蓄電容量 | 200,000 EU |
| 1ブロックあたりのエネルギー | 40 EU |
| 範囲 | ビルダーから64ブロック以内（設計図の全ブロック） |
| ドローン | 4機 |

## 手順

1. ビルダーから16ブロック以内に武装庫資材インターフェースを置きます。
2. 建材をインターフェースまたは隣接するストレージに入れます。
3. 配置済みのCreate設計図をスロットに入れるか、`<` `>` ボタンでファイルを選びます。
4. ファイルの場合は回転（R）・反転（M）・オフセット（X、Y、Z）を設定します。オフセットはビルダーから設計図の最小角までです。
5. 「読込」をクリックすると、ホログラムが作業範囲を表示します。
6. 「開始」をクリックします。

## 規則

* ドローンは最下層から順に上へ設置します。
* ドローンはブロックを壊しません。別のブロックがある位置はスキップし「障害物」として数えます。
* 通常のアイテムのみ使用します。中身・名前・エンチャントのあるアイテムは使いません。
* ドアや背の高い植物の上半分、ベッドの頭側はアイテム不要です。
* 水没ブロックは水なしで設置します。液体は設置しません。
* 設置ごとにビルダー所有者としてブロック設置イベントを発行します。保護Modはこれを止められます。

**注意：** 「開始」の前に作業範囲のホログラムを確認してください。ドローンは範囲内の空き位置をすべて埋めます。
