# 熱遠心分離機

<Row>
  <BlockImage id="mio_icif:producer/block_centrifuge_elc" scale="3" />
</Row>

## 機能

熱遠心分離機はEUで加熱し、アイテムを最大3種類の成果物に分ける。

**加熱：** 各レシピには最低熱量が書かれている（丸石 100 HU、粘土 250 HU、粉砕鉱石 500 から 4,000 HU、書かれていないものは 5,000 HU）。機械はレシピに必要な熱量まで加熱すると処理を始める。材料があり、出力に空きがあり、停止されていないときだけ加熱する：1 tick ごとに +4 HU、4 EU を使い、最高 5,000 HU。それ以外は 1 tick ごとに −2 HU。

**ローター：** 稼働中は回転数が毎秒 10% 上がり、稼働していないときは毎秒 5% 下がる。全速より低いと回転数に比例して動く。全速は 12,000 rpm、遠心力は約 16,000 g。

画面には上から見た加熱リングとローターが描かれ、大きな数字が回転数。

## 電力データ

| 項目 | 値 |
|---|---|
| 入力電圧Tier | MV (128 EU) |
| 最大入力 | 128 EU/t |
| 蓄電容量 | 24,000 EU |
| 稼働時消費 | 48 EU/t |
| 1回の処理時間 | 500 tick (25 s) |
| 1回あたりの電力 | 24,000 EU |
| 加熱 | 1 tick ごとに +4 HU、4 EU、最高 5,000 HU |

表の処理時間と電力はオーバークロックなしの値。オーバークロックアップグレード 1 個ごとに処理時間は 0.7 倍、電力は 1.6 倍になる。画面と JEI は現在の入力の実際の値を表示する。

## 使用手順

1. MVケーブルを機械に接続する。
2. 粉砕鉱石を入力スロットに入れる。
3. 機械が作業温度に達するまで待つ。
4. 3つの出力スロットから成果物を取り出す。

## 注意

- レッドストーン信号は機械を止める。レッドストーン信号反転アップグレードはこの動作を逆にする。

> **警告：** MVを超える過電圧で機械は爆発する。上位の電圧Tierには変圧アップグレードを入れる。
