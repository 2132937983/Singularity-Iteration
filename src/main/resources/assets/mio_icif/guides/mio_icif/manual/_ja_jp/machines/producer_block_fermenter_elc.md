# Fermenter

<Row>
  <BlockImage id="mio_icif:producer/block_fermenter_elc" scale="3" />
</Row>

## 機能

発酵槽は熱（HU）を使い、バイオマスをバイオガスに変える。
機械は正面の熱源からだけ熱を受け取る。
機械は処理したバイオマスから肥料も作る。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 発酵槽の正面に熱発生機を置く。
2. バイオマスセルかパイプでバイオマスを供給する。
3. バイオガスを集めるため、セル入力スロットに空セルを入れる。
4. 肥料スロットから肥料を取り出す。

## 注意

- レッドストーン信号は発酵槽に影響しない。
- アップグレードスロットはアイテムと流体のエジェクターと吸入のアップグレードだけを受け付ける。
