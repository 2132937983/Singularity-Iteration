# Fluid Distributor

<Row>
  <BlockImage id="mio_icif:producer/block_fluid_distributor_elc" scale="3" />
</Row>

## 機能

流体分配機は2つのモードで流体を送る。このブロックはEUを使わない。
分配モードは正面で流体を受け、残りの5面へ分ける。
集中モードは残りの5面で流体を受け、正面から出す。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 正面を流体源か送り先に向けて分配機を置く。
2. GUIのモード切替をクリックしてモードを選ぶ。
3. 各面にパイプかタンクを接続する。
4. タンクの流体で満たすため、容器スロットに空の容器を入れる。
