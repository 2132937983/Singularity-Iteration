# Industrial Workbench

<Row>
  <BlockImage id="mio_icif:producer/block_industrial_workbench" scale="3" />
</Row>

## 機能

工業作業台は3×3グリッドと18スロットの保管庫を持つ作業台だ。このブロックはEUを使わない。
左の工具スロットは鍛造ハンマーで、右の工具スロットは板切断ばさみで素材を加工する。
GUIを閉じても、グリッドと保管庫のアイテムは残る。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 作業台を右クリックしてGUIを開く。
2. 材料をクラフトグリッドに入れる。
3. 鍛造ハンマーと素材を左の工具スロットに入れる。
4. 出力スロットから成果物を取り出す。
