# Item Buffer

<Row>
  <BlockImage id="mio_icif:producer/block_item_buffer_elc" scale="3" />
</Row>

## 機能

アイテムバッファは24スロットずつの2つの区画にアイテムをためる。このブロックはEUを使わない。
上面と下面は左の区画に、4つの側面は右の区画につながる。
各区画はオーバークロッカー、エジェクター、吸入のアップグレード用スロットを1つ持つ。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 2つのインベントリの間にアイテムバッファを置く。
2. 上から入れたアイテムは左の区画に入る。
3. 空にしたい区画のアップグレードスロットにエジェクターアップグレードを入れる。
