# アイテムバッファ

<Row>
  <BlockImage id="mio_icif:producer/block_item_buffer_elc" scale="3" />
</Row>

## 機能

アイテムバッファは24スロットずつの2つの区画（画面の左右）にアイテムをためる。このブロックはEUを使わない。
- 上面と下面は48スロットすべてにつながり、入れることも取り出すこともできる。
- 側面から入れたアイテムは右の区画だけに入る。側面から取り出すときは右の区画が先で、右が空になると左の区画から取り出す。
- 2つのアップグレードスロットにはエジェクターと吸入のアップグレードを入れる。どちらも48スロットすべてに働く。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 2つのインベントリの間にアイテムバッファを置く。
2. パイプで側面か上面からアイテムを入れ、下のホッパーやパイプで取り出す（側面から取り出してもよい）。
3. パイプを使わないときは、片方のアップグレードスロットに吸入、もう片方にエジェクターを入れる。向きを決めるには、アップグレードを持って普通のブロック（機械ではない）のその向きの面を右クリックする。同じ面をもう一度右クリックすると全方向に戻る。
