# Large Matter Fabricator Input Module (IV)

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_input_iv" scale="3" />
</Row>

## 機能

入力モジュール（IV）は大型物質生成機の部品だ。モジュールはIVケーブルからEUを受け取る。
コアは各入力モジュールのEUでUU物質を作る。入力モジュールが多いほど入力も多い。

## 電力データ

| 項目 | 値 |
|---|---|
| 入力電圧Tier | IV (8,192 EU) |
| 最大入力 | 8,192 EU/t |
| 蓄電容量 | 800,000 EU |

この値は本バージョンのブロックエンティティから計測した。

## 使用手順

1. 大型物質生成機コアの1面にモジュールを置く。
2. IVケーブルをモジュールに接続する。

## 注意


> **警告：** IV以下の電圧を供給する。モジュールは過電圧で爆発する。
