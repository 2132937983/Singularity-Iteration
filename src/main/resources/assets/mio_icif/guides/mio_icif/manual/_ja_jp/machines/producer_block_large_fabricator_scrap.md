# Large Matter Fabricator Scrap Input Module

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_scrap" scale="3" />
</Row>

## 機能

スクラップ入力モジュールは大型物質生成機の部品だ。モジュールはスクラップ、スクラップボックス、トリウムスクラップボックスを受け付ける。
スクラップ値はUU物質のEU消費を減らす。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 大型物質生成機コアの1面にモジュールを置く。
2. スクラップかスクラップボックスをモジュールのスロットに入れる。

## 注意

- 構造はスクラップ入力モジュールを最大1つまで受け付ける。
