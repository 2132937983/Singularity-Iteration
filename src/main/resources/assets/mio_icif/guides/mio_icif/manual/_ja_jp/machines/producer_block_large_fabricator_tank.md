# Large Matter Fabricator Tank Module

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_tank" scale="3" />
</Row>

## 機能

タンクモジュールは大型物質生成機の部品だ。モジュールはコアのUU物質をためる。
パイプでモジュールからUU物質を取り出せる。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 大型物質生成機コアの1面にモジュールを置く。
2. UU物質を取り出すため、パイプをモジュールに接続する。
