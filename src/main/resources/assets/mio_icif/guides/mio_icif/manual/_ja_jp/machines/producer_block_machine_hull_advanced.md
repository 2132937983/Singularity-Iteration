# Advanced Machine Hull

<Row>
  <BlockImage id="mio_icif:producer/block_machine_hull_advanced" scale="3" />
</Row>

## 機能

高度マシンハルはクラフト素材だ。設置しても機能はない。
高度な機械のレシピがこのハルを使う。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 作業台で高度マシンハルをクラフトする。
2. 高度な機械のレシピの材料としてハルを使う。
3. レシピビューアでハルを使う機械を調べる。
