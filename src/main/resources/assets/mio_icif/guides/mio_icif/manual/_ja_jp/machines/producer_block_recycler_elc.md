# リサイクラー

<Row>
  <BlockImage id="mio_icif:producer/block_recycler_elc" scale="3" />
</Row>

## 機能

リサイクラーはEUを使い、アイテムを破砕してスクラップを選別する。機械は各処理で入力アイテムを1個消費する。

**原理：** 二軸破砕。逆回転する二本の刃軸がアイテムを裂き、破片から使える部分を選別する。

**産出は比例で累積：** 1個リサイクルするごとに、収率（スクラップは 1/8。リサイクルレシピは独自の産物と比率を書ける）を累積値に加え、1 に達すると産物が1個出る。そのため 8 個ごとにちょうど 1 個のスクラップが出て、ランダムはない。別の産物に変わると、累積値は 0 から始まる。画面には収率、現在の累積値、あと何個かを表示する。

## 電力データ

| 項目 | 値 |
|---|---|
| 入力電圧Tier | LV (32 EU) |
| 最大入力 | 32 EU/t |
| 蓄電容量 | 45 EU |
| 稼働時消費 | 1 EU/t |
| 1回の処理時間 | 45 tick |
| 1回あたりの電力 | 45 EU |
| 産出 | 8 個ごとにスクラップ 1 個（比例で累積） |

表の処理時間と電力はオーバークロックなしの値。オーバークロックアップグレード 1 個ごとに処理時間は 0.7 倍、電力は 1.6 倍になる。画面と JEI は現在の入力の実際の値を表示する。

## 使用手順

1. LVケーブルを機械に接続する。
2. 不要なアイテムを入力スロットに入れる。
3. オーバークロッカーアップグレードを入れて処理を速くする。
4. 出力スロットから成果物を取り出す。

## 注意

- レッドストーン信号は機械を止める。レッドストーン信号反転アップグレードはこの動作を逆にする。

> **警告：** LVを超える過電圧で機械は爆発する。上位の電圧Tierには変圧アップグレードを入れる。
