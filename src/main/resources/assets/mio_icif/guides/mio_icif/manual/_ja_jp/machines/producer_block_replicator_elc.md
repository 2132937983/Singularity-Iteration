# Replicator

<Row>
  <BlockImage id="mio_icif:producer/block_replicator_elc" scale="3" />
</Row>

## 機能

複製機はUU物質とEUを使い、保存したパターンからアイテムを複製する。
パターンはメモリスロットのパターン保存クリスタルか、隣のパターン保管機から来る。

## 電力データ

| 項目 | 値 |
|---|---|
| 入力電圧Tier | EV (2,048 EU) |
| 最大入力 | 8,192 EU/t |
| 蓄電容量 | 2,000,000 EU |
| 稼働時消費 | 512 EU/t |
| 1回の処理時間 | 100 tick (5 s) |
| 1回あたりの電力 | 51,200 EU |

この値は本バージョンのブロックエンティティから計測した。

## 使用手順

1. 変圧器を通してEV電源を機械に接続する。
2. UU物質セルかパイプでUU物質を供給する。
3. パターン保存クリスタルをメモリスロットに入れるか、機械の隣にパターン保管機を置く。
4. GUIで単発かループをクリックして開始する。
5. 出力スロットから成果物を取り出す。

## 複製できるアイテムとデータパック

- 複製機は、UU 価格を持つアイテムをそのパターンから作る（先にアイテムをスキャンする）。
- 価格の出どころ：IC2 の参照表、アイテムに至るレシピ（クラフトや精錬で作るアイテムは材料の価格を受け継ぐ）、複製リスト。
- 既定のリストで 95 アイテムを追加した：新しい鉱石と原石（銅、深層鉱石、古代の残骸）、ネザークォーツ、アメジスト、新しい石材、モブドロップ（ガストの涙、シュルカーの殻、プリズマリンの欠片、ファントムの皮膜、イカスミ、オウムガイの殻、ネザースター、生肉と魚）、植物（ツタ、ネザーウォート、竹、昆布、ベリー、コーラスフルーツ）、本 MOD の原石と粘着樹脂。ドラゴンの卵は複製できない。
- データパックは独自のリストを追加できる：自分の名前空間の uu_replication フォルダに JSON ファイルを置く（data/（名前空間）/uu_replication/（名前）.json）。data/mio_icif/uu_replication/defaults.json に置いたファイルは既定のリストを置き換える。
- 配列 "entries" の各項目は "item"（アイテム ID）か "tag"（アイテムタグ）と、"uu"（1 個あたりの UU 物質 mB）を持つ。任意："eu"（1 個あたりの EU。標準は 1 mB あたり 5,120 EU）、"deny": true（複製不可）、"required": false（未知の ID を警告なしで飛ばす）。
- 項目の例：`{ "item": "minecraft:netherite_scrap", "uu": 1500, "eu": 2000000 }`
- ファイルは ID 順に読み込まれ、同じアイテムでは後の項目が勝つ。誤った項目はサーバーログに警告を出して飛ばされ、残りは読み込まれる。ログ行 "[UU] Replication lists" に件数が出る。

## 注意

- レッドストーン信号は機械を止める。レッドストーン信号反転アップグレードはこの動作を逆にする。

> **警告：** EVを超える過電圧で機械は爆発する。上位の電圧Tierには変圧アップグレードを入れる。
