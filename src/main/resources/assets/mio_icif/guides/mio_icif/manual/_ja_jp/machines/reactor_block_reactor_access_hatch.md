# Reactor Access Hatch

<Row>
  <BlockImage id="mio_icif:reactor/block_reactor_access_hatch" scale="3" />
</Row>

## 機能

原子炉アクセスハッチは外殻から流体原子炉のGUIを開く。ハッチ自体にインベントリはない。
構造が完成すると、ハッチは接続した原子炉を流体モードにする。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 原子炉外殻の圧力容器1個をアクセスハッチに替える。
2. ハッチを右クリックし、原子炉のGUIを開く。
3. スニークしてハッチを右クリックし、構造の診断を表示する。

## 注意


> **警告：** 2基の原子炉から2ブロック以内にハッチを置かない。置くとハッチが爆発する。
