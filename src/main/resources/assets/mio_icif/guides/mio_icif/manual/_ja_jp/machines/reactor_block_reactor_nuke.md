# Nuclear Bomb

<Row>
  <BlockImage id="mio_icif:reactor/block_reactor_nuke" scale="3" />
</Row>

## 機能

核爆弾には工業用TNTのスロット8個と核物質のスロット1個がある。装填量が爆発の威力を決める。
レッドストーン信号で核爆弾が起爆の秒読みを始める。爆発の後に放射線区域が残る。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 拠点と他のプレイヤーから遠い場所に核爆弾を置く。
2. 核爆弾を右クリックしてGUIを開く。
3. スロットに工業用TNTと核物質を入れる。
4. GUIで爆発の威力を確認する。
5. 核爆弾にレッドストーン信号を入れる。
6. 秒読みが終わる前に遠くへ離れる。

## 注意


> **警告：** 起爆した後、秒読みを止める方法はない。


> **警告：** 爆発は広い範囲を破壊する。爆発の後も放射線区域が残り、生物に害を与える。
