# Reactor Redstone Port

<Row>
  <BlockImage id="mio_icif:reactor/block_reactor_redstone_port" scale="3" />
</Row>

## 機能

原子炉レッドストーンポートは流体原子炉の外殻ブロックだ。ポートに信号が入ると原子炉が起動する。
ポートにGUIはない。信号を受けると、ポートの見た目が変わる。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 5x5x5の流体原子炉の外殻を作る。
2. 外殻の圧力容器1個をレッドストーンポートに替える。
3. ポートにレバーを付ける。
4. レバーをオンにして原子炉を起動する。
5. レバーをオフにして原子炉を止める。

## 注意


> **警告：** 原子炉の部品を変える前に信号を切る。稼働中の原子炉は過熱して爆発することがある。
