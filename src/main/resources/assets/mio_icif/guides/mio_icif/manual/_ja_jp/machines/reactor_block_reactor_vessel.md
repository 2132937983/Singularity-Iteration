# Reactor Pressure Vessel

<Row>
  <BlockImage id="mio_icif:reactor/block_reactor_vessel" scale="3" />
</Row>

## 機能

原子炉圧力容器は流体原子炉の構造ブロックだ。GUIも独自の機能も持たない。
圧力容器は5x5x5の流体原子炉の外殻になる。圧力容器の爆発耐性は高い。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 5x5x5の範囲の中心に原子炉発電機を置く。
2. 原子炉の6面すべてにチャンバーを置く。
3. 5x5x5の立方体の外層を圧力容器で埋める。
4. 外層の容器を1個以上ポートかハッチに替える。

## 注意

- 外殻には流体ポート、アクセスハッチ、レッドストーンポートのどれかが1個以上必要だ。
