# 蒸気原子炉チャンバー

<Row>
  <BlockImage id="mio_icif:reactor/block_steam_reactor_chamber" scale="3" />
</Row>

## 機能

蒸気原子炉チャンバーは隣接する蒸気原子炉に部品スロットを1列追加する。
チャンバーは原子炉のインベントリ・熱・水・蒸気を共有する。パイプはチャンバー経由で原子炉に給水し、蒸気を抜く。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. チャンバーを蒸気原子炉の1つの面に接して置く。
2. 水のパイプをチャンバーに接続して原子炉に給水する。

## 注意

- チャンバーは原子炉発電機に接続しない。原子炉チャンバーは蒸気原子炉に接続しない。
- チャンバーは原子炉1基だけに接する必要がある。
