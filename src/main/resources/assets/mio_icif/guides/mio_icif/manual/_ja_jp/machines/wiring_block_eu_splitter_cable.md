# EU Splitter Cable

<Row>
  <BlockImage id="mio_icif:wiring/block_eu_splitter_cable" scale="3" />
</Row>

## 機能

EU分離ケーブルはレッドストーンスイッチ付きのIVケーブルだ。
信号がないとケーブルがEUを通す。信号があるとケーブルが線路を切る。

## 電力データ

このブロックはEUを使わない。

## 使用手順

1. 線路のケーブル1ブロックをEU分離ケーブルに置き換える。
2. 分離ケーブルの隣にレバーを置く。
3. レバーをオンにし、EUの流れを止める。
4. レバーをオフにし、線路を再接続する。
