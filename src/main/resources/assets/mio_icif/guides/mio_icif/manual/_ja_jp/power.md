# 送電と蓄電

ケーブルはブロック間でEUを運ぶ。変圧器は電圧Tierを変える。
蓄電ブロックはEUを貯め、アイテムを充電する。

## 電力網のサーバー負荷

- 管理者は /mio_icif perf で、サーバーの tick と、ディメンションごとに電力網が 1 tick にかける時間（直近 256 tick の中央値、95 パーセンタイル、最大）を見られる。
- ケーブル経由の配送は、経路のプロファイル（溶断・絶縁・感電の最小の限界値）を使う。すべての限界値以下の配送は、ケーブルを 1 本ずつ調べない。溶断、被覆の焼損、感電はこれまでどおり起きる。
- ケーブルは tick しない。直近 1 秒に電力が通ったケーブルは通電中として扱う。
- /mio_icif perf は、直近 100 tick の 1 tick あたりの負荷も表示する：隣接ブロックへ通知するブロックエンティティの変更、クライアントへの更新、ランプの判定、隣接の能力の取得とそのうちキャッシュから答えた数、休眠で省いた機械の tick。
- 大きな電力網は、電源 32 台までのウィンドウに分けて精算する。各ウィンドウの経路計画は、ケーブル・機械・その面が変わらない間は保持され、毎 tick 探し直さない。

## 他の MOD のブロック（FE）

SI 電力網は、ケーブルの隣にある他の MOD のブロックと Forge Energy（FE）をやり取りする。比率はどちら向きも 4 FE = 1 EU（Mekanism と同じく損失なし）。0.1.11.1 から：

- 電力網はこれらのブロックを、SI の機械や蓄電設備と同じ公平な配分で精算する。他の MOD の機械は、SI の蓄電設備と同じく SI の負荷が使った残りから分け前を受け取る。求められると FE を出す他の MOD の発電機は、SI の発電機と同じく電力網へ供給する。FE は電圧 0 で入る。ケーブルが焼けることはなく、変圧器も要らない。
- 他の MOD の電池（FE を受け取りも出しもする）は 90 % まで充電し、その後 10 % になるまで SI の負荷へ供給する。これを繰り返す。SI の蓄電設備を充電することはない。そのため SI の蓄電設備との間でエネルギーが行き来しない。
- SI のケーブルは FE を受け取らない。FE を押し込むだけの（求められても FE を出さない）他の MOD のブロックは、SI の機械か系統連系インターフェースに接して置く。
- SI のケーブルは他の MOD のケーブルにはつながらない（ブロックタグ `mio_icif:foreign_energy_cables`、または ID に cable、duct、conduit、transmitter、wire、energy_pipe を含むブロック）。他の MOD のネットワークにつなぐには系統連系インターフェース（送出・受入・双方向）を使う。GregTech と Modern Industrialization のケーブルは従来どおりつながる（EU、1 EU = 1 EU）。
- ジュールで扱う機械の窓口（Mekanism）は、1 EU に満たない端数を次の転送まで保持する。小さな流れも全量届く。
- `/mio_icif perf` に、1 tick あたり系統連系インターフェースが動かした FE、他の MOD のブロックへ送った FE と受け取った FE、隣接ブロックの確認回数が出る。
