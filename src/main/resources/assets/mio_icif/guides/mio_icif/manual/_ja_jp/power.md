# 送電と蓄電

ケーブルはブロック間でEUを運ぶ。変圧器は電圧Tierを変える。
蓄電ブロックはEUを貯め、アイテムを充電する。

## 電力網のサーバー負荷

- 管理者は /mio_icif perf で、サーバーの tick と、ディメンションごとに電力網が 1 tick にかける時間（直近 256 tick の中央値、95 パーセンタイル、最大）を見られる。
- ケーブル経由の配送は、経路のプロファイル（溶断・絶縁・感電の最小の限界値）を使う。すべての限界値以下の配送は、ケーブルを 1 本ずつ調べない。溶断、被覆の焼損、感電はこれまでどおり起きる。
- ケーブルは tick しない。直近 1 秒に電力が通ったケーブルは通電中として扱う。
- /mio_icif perf は、直近 100 tick の 1 tick あたりの負荷も表示する：隣接ブロックへ通知するブロックエンティティの変更、クライアントへの更新、ランプの判定、隣接の能力の取得とそのうちキャッシュから答えた数、休眠で省いた機械の tick。
- 大きな電力網は、電源 32 台までのウィンドウに分けて精算する。各ウィンドウの経路計画は、ケーブル・機械・その面が変わらない間は保持され、毎 tick 探し直さない。

## ユニバーサルケーブル（FE）

0.1.10.39 から SI のケーブルは Forge Energy（FE）も運ぶ。比率はどちら向きも 4 FE = 1 EU（Mekanism と同じく損失なし）。

- ケーブルの隣にある他の MOD の機械、発電機、電池はケーブルへ FE を押し込める。FE は電圧 0 でネットワークに入る。ケーブルが焼けることはなく、変圧器も要らない。失われるのは通常のケーブル損失だけ。
- SI の機械と蓄電設備は、ケーブルの隣にある他の MOD の機械へ FE を送る。それらの機械は SI の機械と蓄電設備の後に回される。
- SI のケーブルは他の MOD のケーブルにはつながらない（ブロックタグ `mio_icif:foreign_energy_cables`、または ID に cable、duct、conduit、transmitter、wire、energy_pipe を含むブロック）。2 つのネットワークが同じ FE をやり取りし続けるため。GregTech と Modern Industrialization のケーブルは従来どおりつながる（EU、1 EU = 1 EU）。
- `/mio_icif perf` に、1 tick あたりケーブルへ入った FE、送った FE、受け取った FE と隣接ブロックの確認回数が出る。
- エネルギー変換器は旧ブロックになった。クラフトできないが、設置済みのものは動く。
