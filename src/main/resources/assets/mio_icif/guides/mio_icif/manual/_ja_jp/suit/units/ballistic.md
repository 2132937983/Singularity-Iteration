# 弾道計算機

<ItemImage id="mio_icif:module/item_module_ballistic" scale="3" />

## 機能

このユニットは手持ち武器の弾体の軌道を計算する。
計算はゲームと同じ重力と抵抗の手順を使うので、軌道は実際の飛行と一致する。
バイザーは軌道を動く点の列で表示する。点は着弾点に近いほど明るい。
表面で回るリングが着弾点を示す。横のタグが射程と飛翔時間を示す。
軌道が生物に当たると、赤いブラケットがその生物をロックしてロック音が鳴る。
照準線の近くに動く生物がいると、黄色のLEADひし形が狙う位置を示す。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | ヘルメット |
| 消費電力 | 4 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子ヘルメットに取り付ける。
2. 弓・クロスボウ・トライデント・投擲物を持つ。
3. パネルにREADYが出るまで弓を引く。
4. 着弾リングをLEADひし形に重ねる。
5. 射撃する。

## 注意

- 軌道は武器の準備中は灰色、準備完了で琥珀色、生物に当たると赤になる。
