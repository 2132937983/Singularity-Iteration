# 弾道計算機

<ItemImage id="mio_icif:module/item_module_ballistic" scale="3" />

## 機能

このユニットは手持ち武器の弾体の軌道を計算する。
計算はゲームと同じ重力と抵抗の手順を使うので、軌道は実際の飛行と一致する。
バイザーは軌道・着弾リング・飛翔時間・射程・落下量を表示する。
照準線の近くに動く生物がいると、黄色のLEADマーカーが狙う位置を示す。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | ヘルメット |
| 消費電力 | 4 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子ヘルメットに取り付ける。
2. 弓・クロスボウ・トライデント・投擲物を持つ。
3. パネルにREADYが出るまで弓を引く。
4. 着弾リングをLEADマーカーに重ねる。
5. 射撃する。

## 注意

- 武器の準備が整うか軌道が生物に当たると、リングが赤に変わる。
