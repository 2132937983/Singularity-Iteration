# 爆発警告タイマー

<ItemImage id="mio_icif:module/item_module_blast_warning" scale="3" />

## 機能

このユニットは28ブロック内（核爆弾は最大100ブロック）の爆発物の導火時間を計る。対象は「検知する爆発物」を参照。
各爆発物の上に丸いアイコンが浮かぶ。導火線が燃えるにつれてリングが減り、タグが残り秒数を示す。
地面のゾーンが爆発半径を示す。ゾーンは導火線が燃えるにつれて満ちる。
爆発物が近いと、照準点の周りに矢印付きアイコンが出て爆発物の方向を示す。導火線が燃えるにつれてビープが速くなる。
爆発半径の内側では視界の縁が赤く点滅する。

## 検知する爆発物

| 爆発物 | 半径 | タイマー |
|---|---|---|
| 点火 TNT、および点火 TNT を元にした他 MOD の TNT | 4 | 導火線 |
| TNT トロッコ、膨張クリーパー（他 MOD のクリーパーも） | 4 / 3（帯電 6） | 導火線 / 膨張 |
| 工業用 TNT（ITNT） | 8 | 導火線 |
| 核爆弾 | 40 | 導火線（30 秒） |
| ダイナマイト / 粘着ダイナマイト | 3 / 2 | 導火線。遠隔起爆の粘着ダイナマイトは「--」 |
| ロケット、ガストの火の玉、ウィザーの頭蓋骨、ドラゴンの火の玉 | 5 / 2 / 2 / 3 | 着弾までの時間（自分へ飛んでくる間だけ） |
| 他 MOD：ID に爆発系の語（tnt, nuke, bomb, dynamite, grenade, explosive, missile, warhead, landmine, c4, primed, rocket）を含むエンティティ | 4（核系の語は 24） | 導火線の取得メソッド。なければ「--」 |

- データパックで任意の爆発物を定義できる：エンティティタイプのデータマップ mio_icif:blast_warning（半径ブロック数、導火秒数、ラベル）、またはエンティティタイプタグ mio_icif:blast_warning（半径 4）。
- 「--」はタイマーのない爆発物。ゾーンとアイコンで位置を示す。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | チェストプレート / ヘルメット |
| 消費電力 | 2 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子チェストプレートかヘルメットに取り付ける。
2. 照準点の周りのアイコンを見る。
3. 矢印と反対の方向へ離れる。
4. 爆発までは地面のゾーンに入らない。

## 注意

- 最後の1秒でアイコンとゾーンが赤になる。
