# 爆発警告タイマー

<ItemImage id="mio_icif:module/item_module_blast_warning" scale="3" />

## 機能

このユニットは28ブロック内の点火TNT・TNTトロッコ・膨張クリーパーの導火時間を計る。
各爆発物の上にカウントダウンが浮かぶ。
地面の赤リングは爆発半径、黄リングはその2倍を示す。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | チェストプレート / ヘルメット |
| 消費電力 | 2 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子チェストプレートかヘルメットに取り付ける。
2. 爆発警告パネルを見る。
3. パネルにIN RADIUSが出たら黄リングの外へ出る。

## 注意

- 最後の1秒でラベルが赤になる。
