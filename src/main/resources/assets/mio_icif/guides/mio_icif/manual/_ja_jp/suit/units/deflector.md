# 量子偏向器

<ItemImage id="mio_icif:module/item_module_deflector" scale="3" />

## 機能

このユニットは防具が防げなかったダメージを打ち消す。
ダメージ1点ごとにチェストプレートから4000 EUを使い、1回の命中で最大12点を止める。
待機中の力場は見えない。命中すると着弾点に六角セルと偏向プレートが光る。
防具貫通ダメージは止めない。爆発は例外とする。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | チェストプレート |
| 消費電力 | ダメージ1点につき4000 EU、1回最大12点 |
| 表示 | バイザー不要 |

## 使用手順

1. ユニットを量子チェストプレートに取り付ける。
2. チェストプレートを充電する。
3. 戦闘のたびにチェストプレートの残量を確認する。

## 注意

- このユニットに常時消費はない。命中を止めたときだけEUを使う。
