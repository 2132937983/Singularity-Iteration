# 生体スキャナー（ESP）

<ItemImage id="mio_icif:module/item_module_entity_esp" scale="3" />

## 機能

このユニットは32ブロック内の全生物にタグを付ける。
タグはコーナーブラケット・名前・距離・体力バーを表示する。
バイザーはタグ付きの各生物に透視輪郭を描く。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | ヘルメット |
| 消費電力 | 12 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子ヘルメットに取り付ける。
2. 洞窟か暗い場所に入る。
3. 進む前に赤い輪郭の数を数える。

## 注意

- 色：赤は敵対、黄は中立、緑は友好、シアンはプレイヤー。
