# 戦術3Dホロマップ

<ItemImage id="mio_icif:module/item_module_holomap" scale="3" />

## 機能

このユニットは着用者の周囲 25 x 14 x 25 ブロックを箱型の3Dホログラムで表示する。
ホログラムは地面・壁・洞窟・建物を含む周囲の形をすべて表示する。箱の側面は地層の断面を示す。
箱は着用者と一緒に回り、視線方向は常に箱の奥を向く。
支柱付きのひし形が24ブロック内の生物を高さ付きで示す。白い矢印が着用者を示す。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | ヘルメット |
| 消費電力 | 10 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子ヘルメットに取り付ける。
2. 装備コンソールを開く。
3. HUD配置をクリックする。
4. ホロマップパネルを空いた隅へドラッグする。
5. パネル上でスクロールしてサイズを決める。

## 注意

- 箱は10 tickごとにブロックを取り直す。
