# 戦術3Dホロマップ

<ItemImage id="mio_icif:module/item_module_holomap" scale="3" />

## 機能

このユニットは半径20ブロックの地形を傾いた3D起伏で表示する。
マップは着用者と一緒に回り、視線方向が常に上になる。
支柱付きのひし形が32ブロック内の生物を高さ付きで示す。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | ヘルメット |
| 消費電力 | 10 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子ヘルメットに取り付ける。
2. 装備コンソールを開く。
3. HUD配置をクリックする。
4. ホロマップパネルを空いた隅へドラッグする。
5. パネル上でスクロールしてサイズを決める。

## 注意

- 地下では、マップは地表ではなく着用者付近の洞窟の床を表示する。
