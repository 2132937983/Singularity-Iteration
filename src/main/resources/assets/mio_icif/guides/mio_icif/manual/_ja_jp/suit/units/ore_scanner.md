# 震探鉱石スキャナー

<ItemImage id="mio_icif:module/item_module_ore_scanner" scale="3" />

## 機能

このユニットは着用者を中心に半径16ブロックの球をスキャンする。
バイザーは各鉱石ブロックを鉱石色のワイヤーフレームで表示する。
側面パネルは種類ごとに最も近い鉱石の距離と高さを表示する。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | ブーツ / レギンス |
| 消費電力 | 24 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子ブーツか量子レギンスに取り付ける。
2. 量子ヘルメットを着用する。
3. 採掘場所まで移動する。
4. ステータスパネルの鉱石リストを読む。
5. 強調表示のセルに向かって掘る。

## 注意

- 1回のスキャンは50 tickかかる。地面のリングが各スキャンの開始を示す。
