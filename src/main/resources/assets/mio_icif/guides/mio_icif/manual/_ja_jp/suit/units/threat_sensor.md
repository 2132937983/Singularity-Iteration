# 脅威センサー

<ItemImage id="mio_icif:module/item_module_threat_sensor" scale="3" />

## 機能

サーバーは32ブロック内の全生物を毎秒4回確認する。
黄色警告は、プレイヤーか中立生物が着用者を注視していることを示す。
赤色警告は、生物が着用者を標的にしているか、敵対生物が着用者を注視していることを示す。
HUD外周のマーカーが各脅威の方向を指す。ホロマップも同じ色を使う。

## 電力データ

| 項目 | 値 |
|---|---|
| 装着部位 | チェストプレート |
| 消費電力 | 6 EU/t（オン時） |
| 表示 | 量子ヘルメットのバイザーが必要 |

## 使用手順

1. ユニットを量子チェストプレートに取り付ける。
2. 量子ヘルメットを着用する。
3. 赤いマーカーの方を向く。
4. 目標と交戦するか、その場を離れる。

## 注意

- 上部のバナーはLOCK（赤）とWATCH（黄）の数を表示する。

## 飛来弾の警告

- 48 ブロック以内で、着用者が撃ったもの以外の矢・トライデント・投げたアイテム・ラマの唾・火の玉も監視する。それぞれの重力と空気抵抗で次の 2 秒を予測する。
- 1.5 ブロック以内を通るものには、リングにオレンジの印と最接近までの秒数が付く。
- 当たるものは赤くなり、1 回警告音が鳴る。照準の横の矢印がよける方向を示す：弾の進路を横切る向きで、弾が来る側の反対。
- 上部のバナーに INCOMING と命中する数が出る。
- 追尾するシュルカーの弾とロケット花火は表示しない。
