# 量子指揮

0.1.10.2 から、<ItemLink id="mio_icif:module/item_module_entanglement_relay" /> が有効な量子スーツは僚機を直接指揮できる：地点への命令、集中攻撃、データリンク、緊急回収。同じディメンションなら距離に関係なく命令が届く。

## コマンドホイール

**X** を押し続けるとホイールが開く。マウスをセクターか項目へ動かして離すと実行する。クリックでもよく、中央はキャンセル。**X** の短押し（ホイールを開かない）はスマートピン：照準の先の生物に集中攻撃、地面ならそこへ移動。0.1.11.230 以降、僚機や量子もつれ中継器がなくてもホイールは開く：僚機関連のセクターは灰色になり、「装備」と「よく使う」はそのまま使える。**G** は電動ツールのモード切り替えだけに使う。

ホイールを開いた瞬間に、照準の先の地点と生物を記録する（最大 256 ブロック。空を見ているときは前方 48 ブロックの空中の点）。ホイール上部のタグで全機か 1 機を選ぶ。マウスホイールでも切り替えられる。

| セクター | 内容 |
|---|---|
| 移動 | 地点へ飛び、そこを守る：待機半径（10 ブロック）内の敵対生物と戦う。移動中は戦わない。 |
| 区域制圧 | 区域の上空を周回し、範囲（14 ブロック）内の敵対生物をすべて倒す。 |
| 集中攻撃 | 照準の先の生物を倒すまで攻撃し（僚機から最大 128 ブロック）、その後編隊に戻る。 |
| 編隊復帰 | 命令を終了し、編隊と戦術モードに戻る。 |
| 制御 ▸ | 3 つの戦術モード、武装庫へ帰還、スタンス：自動スタンス、空中、地上（武装庫ページの「僚機の戦術」を参照）。1 機に設定したモードはその機体のもの。 |
| 戦甲 ▸ | 換装、脱甲出撃、遠隔操縦、クリーンスレート、単体召喚、量子回収（下記）。 |
| 装備 ▸ | 戦術マップ、ホロテーブル、ジェットパックモード、HUD オン/オフ、HUD レイアウト、特異点管理パネル。 |
| よく使う ★ | 自分で選んだ最大 3 項目。どの扇形メニューでも項目を右クリックすると追加・削除できる。初期値は戦術マップ、ジェットパックモード、遠隔操縦。 |

## キー一覧

0.1.11.230 でキーを統合し、初期状態で使うのは次のキーだけになった：

| キー | 動作 |
|---|---|
| **X** | 長押し：指揮ホイール。短押し：スマートピン。 |
| **V** / **B** | アクションキー（主 / 副）：ナノバースト、量子アクション、コアバースト。特異点管理パネルで割り当てる。 |
| **G** | 電動ツールを持っているとき：モード切り替え。 |
| **左 Alt** | 短押し：特異点管理パネル。長押し：スーツの詳細表示。 |
| ダッシュキー | 特殊機動モードのスロットルとジェットパックの加速。 |

戦術マップ、単体召喚、遠隔操縦、ジェットパックモード、HUD 切替とレイアウト、コアバースト、ブースト、詳細表示は「操作設定」で個別のキーを割り当てられる（初期状態は未割り当て）。旧バージョンから更新すると、旧初期値のままのキーは新しい初期値に移る。自分で変更したキーはそのまま。

命令を受けた僚機は着用者についてこない。28 ブロックの範囲に留まる代わりに命令地点を守る。未ロードのチャンクにいる僚機は動けない。編隊リストに「未読み込み」と表示され、量子回収かコンソールの「全機帰還」が届く。

## データリンク

データリンクがオンなら、僚機が見た敵（各機の周囲 24 ブロック）がホロマップ、戦術マップ、ホロテーブルに表示される。艦隊データリンクのシナジーがあれば、ワールド内のマーカーも出て、照準の先の敵が僚機の最優先目標になる。

## 量子回収

自分の僚機すべてを、その場で武装庫へ戻す。どのディメンションでも、ロードされていなくても届く（未ロードの僚機のチャンクは一瞬だけロードされる）。コヒーレンス 30 を使い、クールダウンは 30 秒。

## 編隊 HUD

指揮リンクが働いている間、左側の編隊パネルに各僚機を番号（W1〜W6：どの武装庫スーツから出たか。他の僚機が出入りしても変わらない）で並べ、モード（* は個別モード）、命令と距離、体力、自分からの距離が出る。画面外の僚機は画面端の矢印で示す。ワールドには待機点、制圧リング、集中攻撃の目標が自分にだけ表示される。

## 3D ホロテーブル

<ItemLink id="mio_icif:module/item_module_holomap_mk2" /> があれば、ホイールの「装備」でホロテーブルを選ぶ。目の前に周囲の地形のホログラムが立ち上がる：柱が中心から外へ伸び、干渉縞と走査線が流れる。自分、番号と命令付きの僚機、敵（データリンクの対象は輪付き）、他のプレイヤー、地脈ホロがあれば探知した鉱石を表示する。

- ドラッグ：テーブルを回す。マウスホイール：24、48、96 ブロック。
- 地形を左クリック：そこへ移動。右クリック：そこを区域制圧。生物を左クリック：集中攻撃。
- H：待機。F：編隊復帰。1〜6：その番号の僚機を選ぶ。0：全機。押し続けても一度だけ働く。
