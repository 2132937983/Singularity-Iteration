# ツール

この章では手持ちツール、武器、携帯装置を説明する。各ページに数値、キー、使い方のルールを示す。

## 共通ルール

- **電力。**電動ツールはEUを貯める。新しいツールは空である。ツールチップにTier、1回あたりの消費電力、残りのおおよその使用回数が出る。
- **充電。**蓄電ブロック、充電台、バッテリー、装着したバットパック類、武装庫でツールを充電できる。Tierは目安であり、充電を制限しない。充電速度はツール自身の充電レートで決まる：Tier 1 100、Tier 2 128、Tier 3 512、Tier 4 2,048、Tier 5 8,192 EU/t。
- **バットパックからの給電。**手持ちのツールは、使う前に装着したバットパック類から電力を取る。
- **電力がないとき。**ドリルとチェーンソーは素手と同じように掘り、ツールが必要なブロックはドロップしない。武器は撃てない。ツールの攻撃ボーナスはなくなる。
- **G キー。**手持ちツールのモードを切り替える。奇点管理パネルでもモードを選べる。切り替えのメッセージはアクションバーに出る。
- **エンチャント。**すべての電動ツールに省電力を付けられる。種類ごとに次も付けられる：ドリルとチェーンソー（効率強化、幸運、シルクタッチ）、ナノセイバーと量子剣（剣のエンチャント）、ナノ複合弓（弓のエンチャント）、電動釣り竿（入れ食い、宝釣り）。電動ツールには耐久力と修繕を付けられない。青銅ツールは普通のツールで、対応するエンチャントをすべて付けられる。
- **保護区域。**範囲ツールと武器は、ブロックごとに保護区域の権限を確認する。保護されたブロックは変化しない。
