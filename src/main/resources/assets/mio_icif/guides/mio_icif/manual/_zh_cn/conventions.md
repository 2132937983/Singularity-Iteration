# 单位与电压等级

EU是电能单位。EU/t表示每游戏tick的EU。一秒有20 tick。
导线以电力包传送EU。电压等级限制单个电力包的大小。
机器收到超过其输入电压等级的电力包时会爆炸。
用变压器在电源与机器之间改变电压等级。

| 电压等级 | 最大电力包 |
|---|---|
| LV | 32 EU |
| MV | 128 EU |
| HV | 512 EU |
| EV | 2,048 EU |
| IV | 8,192 EU |
| LuV | 32,768 EU |
| ZPM | 131,072 EU |
