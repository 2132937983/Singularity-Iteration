# 发电机

发电机用燃料、阳光、风、水、热能或动能产生EU。
每页给出输出电压等级与输出EU/t。

## 太阳能的两条路线

太阳能发电机从基础太阳能发电机出发，分成两条路线，最后在量子发电机合流。

| 项目 | 聚光光热线 | 光子振谐线 |
|---|---|---|
| 机器 | 高级 → 混合 → 终极混合 → 量子太阳能 | 进阶 → 光子振谐 → 终极光子振谐 |
| 白天额定 | 12 / 96 / 768 / 7,168 EU/t | 48 / 384 / 3,072 EU/t |
| 夜间 | 0 | 额定的 15% / 25% / 35%（晴夜） |
| 满功率辐照 | 850 W/m² | 600 / 450 / 350 W/m² |
| 被遮挡 | 不发电 | 保留 30% / 45% / 60% 天光 |
| 雨天 / 雷暴 | 约 37% / 几乎为零 | 约 85% / 约 61% |
| 温度 | 怕热，混合各档逐级冷却 | 影响很小 |
| 适合 | 沙漠等不下雨的晴朗地区 | 多雨地区、被遮挡、需要夜间供电 |

量子发电机用两条路线的顶端（量子太阳能发电机和终极光子振谐太阳能发电机）合成，恒定 8,192 EU/t，不受昼夜和天气影响。
