# 电压检测器

<Row>
  <BlockImage id="mio_icif:checker/block_checker" scale="3" />
</Row>

## 功能

电压检测器连接导线网络，并测量网络电压。
看向检测器时，屏幕显示电压、电压等级和输入功率。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把电压检测器放在网络导线旁边。
2. 把准星对准检测器。
3. 读取屏幕上的电压和电压等级。
4. 将该电压等级与机器的输入等级比较。
