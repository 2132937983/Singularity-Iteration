# 核反应堆发电机

<Row>
  <BlockImage id="mio_icif:generator/block_nuclear_reactor_generator" scale="3" />
</Row>

## 功能

机器燃烧核燃料棒，产生 EU 和热量。
每个相邻的核反应仓都增加一列元件槽位。
组成核反应堆压力容器结构后，机器切换到流体模式并加热冷却液。

## 电力数据

| 项目 | 数值 |
|---|---|
| 输出电压等级 | IV (8,192 EU) |
| 输出 | 8,192 EU/t |
| 储能 | 1,000,000 EU |

这些数值由本版本的方块实体实测得出。

## 使用步骤

1. 把核反应仓贴在反应堆的各个面上。
2. 把燃料棒和冷却元件放入槽位。
3. 把导线连接到反应堆。
4. 向反应堆输入红石信号来启动它。

## 堆温阶段

堆温达到 4,000 HU 后，反应堆每个循环（1 秒）按“堆温 / 堆温上限”检查以下阶段。概率与伤害乘以防爆系数：
没有反应堆装甲板时为 1，每块装甲板都会降低它（反应堆装甲板 ×0.95）。服务器关闭反应堆爆炸时（爆炸倍率或威力上限为 0），这些效果也不发生。

| 堆温 / 上限 | 效果（以反应堆为中心） | 范围 |
|---|---|---|
| ≥ 40 % | 以防爆系数为概率选择 1 个随机方块：可燃方块（木板、原木、树叶、树苗、花、作物、草类）变为火。 | 5×5×5 |
| ≥ 50 % | 以防爆系数为概率选择 1 个随机方块：水蒸发。水源与流动水消失，含水方块只失去水，海带、海草与气泡柱干涸。 | 5×5×5 |
| ≥ 70 % | 每个循环，范围内每个生物受到 0–3 点辐射伤害（乘以防爆系数）。全套防化服或全套量子装甲完全防护；纳米毒素过滤器降低伤害。 | 7×7×7 |
| ≥ 85 % | 以 20 % × 防爆系数为概率选择 1 个随机方块：空气变为火；石头、金属等可用镐挖掘的方块变为岩浆；其他可破坏方块变为火。 | 5×5×5 |
| 100 % | 反应堆爆炸。 | - |

高温不会改变的方块：基岩等不可破坏方块、带方块实体的方块（反应仓、端口、机器等），以及数据标签
`mio_icif:reactor_heat_immune` 中的方块：建筑泡沫及其墙、反应堆、反应仓、反应堆压力容器及其接口方块（访问舱口、流体端口、红石端口）、冷却液注入器。

> **注意：** 浸在水中的反应堆，85 % 阶段生成的岩浆会按原版规则与相邻的水反应：岩浆源变为黑曜石，流动岩浆变为圆石或石头。
> 受保护的方块本身不会改变，但反应堆周围的普通方块（例如石头）可能先变为岩浆，再变为黑曜石。

## 辐射屏蔽

铅能挡住辐射。辐射从反应堆沿直线射向生物，直线上的每个方块只让一部分通过：

| 方块 | 通过的辐射 |
|---|---|
| 铅块以及 c:storage_blocks/lead 标签中的所有方块（数据标签 mio_icif:radiation_shielding） | 10 % |
| 强化石头、黑曜石、哭泣的黑曜石、强化深板岩、铁块、下界合金块、钢块（数据标签 mio_icif:radiation_shielding_weak） | 50 % |

- 低于 5 % 时完全挡住：2 个铅块，或 1 个铅块加 2 个较弱的屏蔽方块，即可完全屏蔽。
- 生物按“到眼睛的线”和“到身体中心的线”中较开放的一条受辐射。要遮住整个身体。
- 核爆炸产生的放射性方块（从方块出发的线）和核爆炸辐射区也遵循同一规则。在辐射区中，需要朝向爆心的屏蔽和屋顶（向上 16 格的线）：两条线中较开放的一条计入。
- 全套防化服或全套量子套装仍然完全防护。
- 放入 <ItemLink id="mio_icif:normal/item_contain_ment_box" /> 的放射性物品不会辐射你。箱子有 18 格：使用即可打开。

## 注意


> **警告：** 堆温达到上限时，反应堆爆炸。


> **警告：** 堆温达到 40 % 起，反应堆会点燃方块、蒸发水、辐射生物并生成岩浆（见“堆温阶段”）。
