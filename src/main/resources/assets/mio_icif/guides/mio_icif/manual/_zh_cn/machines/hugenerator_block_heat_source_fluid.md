# 热交换机

<Row>
  <BlockImage id="mio_icif:hugenerator/block_heat_source_fluid" scale="3" />
</Row>

## 功能

机器把岩浆或热冷却液转换为热能（HU）。
岩浆变为绳状熔岩。热冷却液变为冷却液。
每个热传导器都使产热量增加。机器只从正面输出热能。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 放置机器，使其正面对着用热机器。
2. 把热传导器放入传导器槽位。
3. 把岩浆桶或热冷却液单元放入热流体输入槽位。
4. 把空容器放入冷流体槽位来收集产物流体。

## 注意

- 输出储罐满时，机器停止工作。
- 没有热传导器时，机器不产生热能。
