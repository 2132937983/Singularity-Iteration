# 斯特林动能发生机

<Row>
  <BlockImage id="mio_icif:kugenerator/block_stirling_kinetic_generator" scale="3" />
</Row>

## 功能

机器把热能（HU）和水转换为动能（KU）和热水。
机器从正面以外的所有面接收热能。
机器只从正面输出 KU。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 放置机器，使其正面对着动能机器。
2. 把加热机放在机器的其他面上。
3. 把水桶或水单元放入水输入槽位。
4. 把空容器放入热水槽位来收集热水。

## 注意

- 水储罐为空或热水储罐已满时，机器停止工作。
