# 物品传输管道

<Row>
  <BlockImage id="mio_icif:pipe/block_pipe_item" scale="3" />
</Row>

## 功能

物品传输管道在管道之间移动物品，并放入相连的容器。
管道从物品提取管道接收物品，并在管网中寻找有空位的容器。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 在源容器旁放置物品提取管道。
2. 用物品传输管道连接提取管道和目标容器。
3. 用扳手右键管道的一个分支，关闭该方向。

## 注意

- 拆除管道时，管道内的物品掉落在地上。
