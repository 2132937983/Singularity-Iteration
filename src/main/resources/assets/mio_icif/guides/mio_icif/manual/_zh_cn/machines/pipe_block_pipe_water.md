# 输水管道

<Row>
  <BlockImage id="mio_icif:pipe/block_pipe_water" scale="3" />
</Row>

## 功能

输水管道在相连的管道和流体容器之间传输流体。管道每次只容纳一种流体。
管道自动连接相邻的管道和带有流体储罐的方块。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 在管线起点放置抽水管道或输出流体的机器。
2. 从该处向目标储罐铺设输水管道。
3. 用扳手右键管道的一个分支，关闭该方向。
4. 用扳手在关闭的一侧右键管道中心，重新打开该方向。

## 注意

- 管道不会主动抽取流体。机器或抽水管道必须向管道推入流体。
- 拆除管道时，管道内的流体消失。
