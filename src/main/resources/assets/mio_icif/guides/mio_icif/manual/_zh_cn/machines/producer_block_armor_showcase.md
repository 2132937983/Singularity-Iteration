# 盔甲展示柜

<Row>
  <BlockImage id="mio_icif:producer/block_armor_showcase" scale="3" />
</Row>

## 功能

盔甲展示柜在人台上展示整套装备。
使用武装库遥控器时，装备综合控制台可把身上的装备与展示柜上的装备交换。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 手持盔甲或武器右键展示柜，把它放到人台上。
2. 空手潜行右键展示柜，交换全身装备。
3. 空手右键展示柜，转动人台。
4. 手持已配对的遥控器右键，显示武装库中的一套装备。
5. 向展示柜输入红石信号，使转台旋转。

## 注意

- 映射武装库装备的展示柜不存放物品。手持遥控器潜行使用，即可解除链接。
- 控制台换装只适用于你或武装库附近的展示柜。
