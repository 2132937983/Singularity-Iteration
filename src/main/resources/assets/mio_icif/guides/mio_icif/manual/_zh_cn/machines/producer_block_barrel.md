# 酒桶

<Row>
  <BlockImage id="mio_icif:producer/block_barrel" scale="3" />
</Row>

## 功能

酒桶用小麦、啤酒花和水酿造啤酒。酒桶用甘蔗和水酿造朗姆酒。
啤酒随酿造时间增加进入更烈的阶段。酒桶不消耗EU。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 右键酒桶，打开界面。
2. 把原料和水桶放入槽位。
3. 潜行并右键酒桶，查看酿造进度。
4. 手持石杯右键酒桶，取出酒。
