# 高炉

<Row>
  <BlockImage id="mio_icif:producer/block_blast_furnace" scale="3" />
</Row>

## 功能

高炉利用热量（HU）和压缩空气，把铁矿石、铁粉或铁锭炼成精炼铁锭。
副产物为炉渣。高炉只从正面的热源获取热量。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把热能发生器贴在高炉正面。
2. 用压缩机把空单元制成压缩空气单元。
3. 把压缩空气单元放入空气槽位。
4. 把铁放入输入槽位，等待高炉升温。
5. 从输出槽位取出铁锭、炉渣和空单元。

## 注意

- 只有输入槽位有有效物品时，高炉才接收热量。
- 红石信号使机器停止。红石信号反转升级可反转此行为。
