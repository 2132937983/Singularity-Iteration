# 进阶钛合金高炉

<Row>
  <BlockImage id="mio_icif:producer/block_blast_furnace_advanced" scale="3" />
</Row>

## 功能

进阶钛合金高炉利用热量（HU）和压缩空气，加工高炉配方。
本高炉比高炉更快。本高炉只从正面获取热量。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把热能发生器贴在高炉正面。
2. 把压缩空气单元放入空气槽位。
3. 把输入物品放入输入槽位，等待高炉升温。
4. 从输出槽位取出产物和空单元。

## 注意

- 红石信号使高炉保持高温，并暂停加工。
