# 蓝图建造机

<Row>
  <BlockImage id="mio_icif:producer/block_blueprint_builder" scale="3" />
</Row>

## 功能

蓝图建造机有四架建造无人机，逐个放置蓝图中的方块。
无人机从[军械库资材接口](producer_block_material_interface.md)取用建材。创造模式下可以用[无限军械库资材接口](producer_block_infinite_material_interface.md)，所有建材都无限供应。

## 蓝图来源

* 槽位中已部署的机械动力蓝图。使用该蓝图的锚点、旋转与镜像。
* 游戏 `schematics` 文件夹中的文件（服务器为服务器文件夹）。可读取 `.nbt` 结构文件（含机械动力蓝图）与 `.litematic` 文件（Litematica）。
* 在服务器上用自己电脑里的文件：点“上传”，从自己的 `schematics` 文件夹选一个文件。文件会传到服务器（和机械动力的蓝图桌一样），建造机随即读取。服务器把它存在 `schematics/uploads/<你的 UUID>/`，同一个文件不会再传第二次。单人游戏不需要上传，文件已经在列表里。
* 本模组的多方块结构：点“结构库”，左边选结构（托卡马克聚变堆、TESU、蒸汽隧道、各种反应堆等，和 JEI「多方块结构」的建造图相同），右边可以像 JEI 一样拖动旋转、滚轮缩放、逐层查看，下面列出所需材料，然后点“建造此结构”。一个位置可以放几种方块时放推荐的那种；聚变堆的各个端口按推荐布局摆好，TESU 的端口位轮流放输入端口和输出端口。结构内部要求是空气的地方（聚变堆的等离子体通道、TESU 和蒸汽隧道的内部）不会自动清空。

## 能量数据

| 项目 | 数值 |
|---|---|
| 输入电压等级 | MV（128 EU） |
| 储能 | 200,000 EU |
| 每个方块的能量 | 40 EU |
| 范围 | 不限（蓝图偏移每轴最多 1,024 格）；没有加载的区块里的方块会等区块加载后再建（超大工程可以配合区块加载器） |
| 蓝图大小 | 方块数不限，只受服务器内存限制（内存装不下时状态显示"蓝图太大"） |
| 无人机 | 4 架 |

## 步骤

1. 在建造机 16 格内放置军械库资材接口。
2. 将建材放入接口或其相邻的存储。
3. 将已部署的机械动力蓝图放入槽位，或用 `<` `>` 按钮选择文件。在服务器上也可以点“上传”传自己电脑里的文件（传完即读取，直接进行第 4 步）。
4. 对于文件，调整蓝图位置：点"在世界中调整"，然后看着投影操作。滚轮沿你看的方向移动一格（按住 Ctrl 一次 5 格），R 旋转，M 镜像，调好后右键或按 Esc 结束。旋转和镜像时，本模组机器的朝向、管道和电线的连接方向会跟着一起转。界面上的 R、M 按钮也能旋转和镜像。按 Esc 只结束调整，不会打开暂停菜单。
5. 点击"读取"，全息投影显示工作范围，还没放的每个方块都显示成半透明的投影。范围按钮依次切换："方块"（全部投影）、"本层"（只显示最低一层还没建完的）、"外框"（只有范围框）和"隐藏"。方块投影只在你自己这边显示，范围框所有人都能看到。大型蓝图也不会卡：投影只生成一次，之后只重建有变化的部分。
6. 点击"开始"。

## 规则

* 无人机从最底层开始逐层向上放置。
* 无人机不会破坏方块。已有其他方块的位置会被跳过并计为"被阻挡"。
* 仅使用普通物品：不使用带内容物、自定义名称或附魔的物品。
* 门或高大植物的上半部分、床的头部不需要物品。
* 含水方块以无水状态放置，不放置流体。
* 每次放置都以建造机所有者的身份触发方块放置事件，保护类模组可以阻止。

**注意：** 点击"开始"之前请检查工作范围全息投影。无人机会填满范围内的所有空位。蓝图位置上如果有别的方块挡路，无人机会把它挖掉（掉落物送进最近的军械库资材接口），再放上蓝图的方块；带方块实体的方块（机器、箱子）和不可破坏的方块不会被挖，领地保护会先询问。服务器可以在配置 `clearObstructions` 里关掉这个功能。

全部放完后，建造机会等 2 秒再把整张蓝图复检一遍：因为没有支撑而掉落的方块（比如维度石油钻机里先放下、还没等到支撑的脚手架）、中途被破坏的方块，都会重新补建，最多复检 3 遍。建完之后再点一次"开始"，也会重新复检并补齐缺漏。
