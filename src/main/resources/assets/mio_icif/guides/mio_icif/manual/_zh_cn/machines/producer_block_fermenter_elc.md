# 发酵机

<Row>
  <BlockImage id="mio_icif:producer/block_fermenter_elc" scale="3" />
</Row>

## 功能

发酵机利用热量（HU）把生物质转化为沼气。
机器只从正面的热源获取热量。
机器还用处理过的生物质产出肥料。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把热能发生器贴在发酵机正面。
2. 用生物质单元或管道供应生物质。
3. 把空单元放入单元输入槽位，以收集沼气。
4. 从肥料槽位取出肥料。

## 注意

- 红石信号对发酵机没有作用。
- 升级槽位只接受物品和流体的弹出与抽入升级。
