# 流体分配机

<Row>
  <BlockImage id="mio_icif:producer/block_fluid_distributor_elc" scale="3" />
</Row>

## 功能

流体分配机以两种模式输送流体。本方块不消耗EU。
分配模式从正面接收流体，并把流体分给其他5个面。
集中模式从其他5个面接收流体，并从正面输出。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 放置分配机，使正面朝向流体源或目标。
2. 点击界面中的切换模式按钮选择模式。
3. 将管道或储罐连接到各面。
4. 把空容器放入容器槽位，用储罐中的流体装满容器。
