# 电炉

<Row>
  <BlockImage id="mio_icif:producer/block_furnace_elc" scale="3" />
</Row>

## 功能

电炉消耗EU，按熔炉配方冶炼物品。
机器有1个输入槽位、1个输出槽位、1个电池槽位和4个升级槽位。

**原理：** 电阻加热。电热丝每 tick 让炉膛升温 10 °C，最高 1,100 °C。不工作时炉膛按牛顿冷却向 20 °C 降温（时间常数 30 秒），休眠时也照算。

**所需温度：** 食物 250 °C 就能开始，矿石、金属和其他物品要 1,000 °C。温度不够时机器只升温不推进，状态显示「升温中」，升温期间也耗 3 EU/t。从冷炉开始烧矿石要先升温约 100 tick；连续工作时炉子一直是热的，没有额外开销。不需要外部热源。

界面画出炉膛，电热丝的颜色随炉温变化，大字是炉温。

## 电力数据

| 项目 | 数值 |
|---|---|
| 输入电压等级 | LV (32 EU) |
| 最大输入 | 32 EU/t |
| 储能 | 600 EU |
| 工作耗电 | 3 EU/t |
| 单次工作时间 | 100 tick (5 s)，冷炉另加升温 |
| 单次耗电 | 300 EU |
| 所需温度 | 食物 250 °C，其他 1,000 °C |

表中的工时和耗电是没有超频时的值。每个超频升级让工时变为 0.7 倍、耗电变为 1.6 倍。界面和 JEI 显示当前输入的实际数值。

## 使用步骤

1. 将LV导线连接到机器。
2. 把要冶炼的物品放入输入槽位。
3. 安装超频升级以加快加工。
4. 从输出槽位取出产物。

## 注意

- 红石信号使机器停止。红石信号反转升级可反转此行为。

> **警告：** 电压高于LV时，机器因过压爆炸。安装变压升级可提高电压等级。
