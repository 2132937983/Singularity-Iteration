# 工业工作台

<Row>
  <BlockImage id="mio_icif:producer/block_industrial_workbench" scale="3" />
</Row>

## 功能

工业工作台是带3×3网格和18格存储的工作台。本方块不消耗EU。
左侧工具槽位使用锻造锤，右侧工具槽位使用板材切割剪刀加工材料。
关闭界面后，网格和存储中的物品保留。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 右键工作台，打开界面。
2. 把材料放入合成网格。
3. 把锻造锤和材料放入左侧工具槽位。
4. 从输出槽位取出产物。
