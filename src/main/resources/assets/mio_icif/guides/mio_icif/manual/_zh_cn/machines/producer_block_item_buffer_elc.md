# 物品缓冲机

<Row>
  <BlockImage id="mio_icif:producer/block_item_buffer_elc" scale="3" />
</Row>

## 功能

物品缓冲机把物品存放在两个各24槽位的区域。本方块不消耗EU。
顶面和底面访问左半区。4个侧面访问右半区。
每个半区有1个升级槽位，可放超频、弹出或抽入升级。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把物品缓冲机放在两个容器之间。
2. 从顶面输入物品，装入左半区。
3. 在需要清空的半区升级槽位安装弹出升级。
