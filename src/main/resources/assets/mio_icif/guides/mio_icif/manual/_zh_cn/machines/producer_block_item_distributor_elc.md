# 高级物品分配机

<Row>
  <BlockImage id="mio_icif:producer/block_item_distributor_elc" scale="3" />
</Row>

## 功能

高级物品分配机按优先顺序，把9格缓冲区中的物品送往相邻容器。
界面设置各面的顺序。本方块不消耗EU。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 在分配机各面旁放置容器。
2. 打开界面，按优先顺序添加各面。
3. 把物品送入分配机。

## 注意

- 只有前面的面无法接收全部物品时，下一个面才接收物品。
