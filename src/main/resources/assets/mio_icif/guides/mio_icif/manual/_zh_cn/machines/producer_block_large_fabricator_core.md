# 大型物质生成机核心

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_core" scale="3" />
</Row>

## 功能

大型物质生成机核心是多方块结构的中心。6个面都必须接触模块。
结构至少需要1个输入模块（IV）和1个储罐模块。废料输入模块最多1个。
核心把输入模块的EU转化为UU物质，并存入储罐模块。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 放置大型物质生成机核心。
2. 在核心的6个面上各放置1个模块。
3. 将IV导线连接到输入模块。
4. 用管道从储罐模块取出UU物质。

## 注意

- 界面显示模块数量，并在结构不完整时显示提示。
