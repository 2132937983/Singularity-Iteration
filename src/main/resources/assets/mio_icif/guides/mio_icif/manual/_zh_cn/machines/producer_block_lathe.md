# 车床

<Row>
  <BlockImage id="mio_icif:producer/block_lathe" scale="3" />
</Row>

## 功能

车床使用相邻动能源的动能（KU），用车刀加工车刀坯。
加工件有5个位置。每次切削可能产出副产物，例如木棍或小撮铁粉。
车刀必须比加工件更硬。每次切削消耗车刀耐久。
每个位置最多切削到厚度1。
车刀坯的图标和提示框显示其当前轮廓。图标下方的条显示剩余可切削的材料。

## 零件

部分配方需要切削成指定轮廓（位置1至5的厚度）的铁车刀坯。
加工完成的零件带有青色描边，提示框中显示其名称。在车刀坯上按住 Shift 可查看它还能车削成的零件。

| 零件 | 轮廓 | 用于 |
|---|---|---|
| 钻尖 | 5-4-3-2-1 | 钻石钻头 |
| 水轮轴 | 4-3-4-3-4 | 水力动能发生机 |
| 活塞杆 | 3-2-3-2-3 | 斯特林动能发生机 |
| 激光镜筒 | 4-3-2-2-2 | 采矿镭射枪 |
| 曲柄手柄 | 5-5-5-2-2 | 手摇动能发生机 |
| 风轮轮毂 | 5-3-3-3-5 | 风力动能发生机 |
| 涡轮主轴 | 1-3-5-3-1 | 蒸汽动能发生机 |

除电力动能发生机外，所有动能发生机都需要零件。请用电力动能发生机为第一台车床供能。

| 物品 | 硬度 | 次数 |
|---|---|---|
| 铁车刀 | 3 | 50 |
| 钻石车刀 | 4 | 64 |
| 木车刀坯（宽度3，木棍10%） | 0 | - |
| 铁车刀坯（宽度5，小撮铁粉50%） | 2 | - |

## 电力数据

该方块不使用EU。它最多储存10,000 KU，可从任意一面获取KU。
缓存每tick损失1%。KU高于500时车床处于工作状态。每次切削消耗1,000 KU。

## 使用步骤

1. 把车床放在动能发生机旁边。
2. 把车刀放入车刀槽位。
3. 把车刀坯放入加工件槽位。
4. 在界面中点击一个位置，切削该位置。
5. 从输出槽位取出副产物。
