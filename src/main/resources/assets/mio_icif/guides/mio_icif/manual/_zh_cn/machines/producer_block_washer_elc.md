# 洗矿机

<Row>
  <BlockImage id="mio_icif:producer/block_washer_elc" scale="3" />
</Row>

## 功能

洗矿机消耗EU和水，把粉碎矿石洗成纯净的粉碎矿石和副产物。机器有3个输出槽位。

**原理：** 重力选矿要持续的水流。每洗一次流过配方写的水量（粉碎矿石 1,000 mB），沉淀池收回 80%，所以净耗是流量的五分之一（粉碎矿石 200 mB）。净耗的水在整个工时里逐 tick 取，供水不足时按比例变慢，水箱空了显示「缺水」。

**工时和功率：** 默认 400 tick × 16 EU/t。配方写了工时和功率时按配方运行：粉碎铌矿和粉碎钛矿 200 tick × 10 EU/t，用水 200 mB（净耗 40 mB）。

界面画出洗矿筒、沉淀池和回水管，显示水箱存量、流量和净耗。

## 电力数据

| 项目 | 数值 |
|---|---|
| 输入电压等级 | MV (128 EU) |
| 最大输入 | 128 EU/t |
| 储能 | 8,000 EU |
| 工作耗电 | 按配方（默认 16 EU/t） |
| 单次工作时间 | 按配方（默认 400 tick） |
| 单次耗电 | 按配方（默认 6,400 EU） |
| 用水 | 流量按配方（粉碎矿石 1,000 mB），回收 80% |
| 粉碎矿石净耗水 | 每次 200 mB (0.5 mB/t) |

表中的工时和耗电是没有超频时的值。每个超频升级让工时变为 0.7 倍、耗电变为 1.6 倍。界面和 JEI 显示当前输入的实际数值。

## 使用步骤

1. 将MV导线连接到机器。
2. 把水桶或水单元放入水槽位，或连接输水管道。
3. 把粉碎矿石放入输入槽位。
4. 从3个输出槽位取出产物。

## 注意

- 红石信号使机器停止。红石信号反转升级可反转此行为。

> **警告：** 电压高于MV时，机器因过压爆炸。安装变压升级可提高电压等级。
