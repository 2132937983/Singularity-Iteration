# 反应堆事故调查

<Row>
  <ItemImage id="mio_icif:reactor/item_reactor_blackbox" scale="3" />
</Row>

## 功能

每台[核反应堆发电机](generator_block_nuclear_reactor_generator.md)都带有一个飞行记录器。
它每个反应周期（1 秒）写入一条记录，并保留最近 40 个周期。
反应堆出事时，服务器把记录保存为一起事故并分析原因。
事故调查报告显示事故的经过、地点和原因。

服务器保留最近 64 起事故。记录随世界一起保存。

## 什么会产生事故记录

| 事件 | 类型 | 黑匣子 |
|---|---|---|
| 核爆炸 | 核爆炸 | 掉落在现场 |
| 反应堆局部爆炸 | 反应堆爆炸 | 掉落在现场 |
| 配置中关闭了反应堆爆炸，外壳热量达到上限 | 熔毁（爆炸已关闭） | 无（反应堆保留） |
| 运行中、或外壳热量不低于 10 % 的反应堆被拆除 | 高温时被拆除 | 无 |

黑匣子不会烧毁，能承受爆炸，会发光，且永不消失。

## 打开报告

* 使用（右键）反应堆黑匣子。持有者都可以阅读它的报告。
* `/mio_icif reactor audit` 按从新到旧列出事故。点击一行即可打开报告。
* `/mio_icif reactor audit 12` 打开 12 号事故的报告。
* `/mio_icif reactor audit clear` 清空记录（仅限管理员）。

玩家可以看到自己反应堆的事故，以及自己在附近（64 格内）时发生的事故。
管理员可以看到全部事故。反应堆的所有者是放置它的玩家。

## 报告内容

* **标题栏**：事故编号、类型、日期时间、游戏天数、维度、坐标、所有者和附近的玩家。
* **主因**以红色显示，附有说明和建议。下方是次要因素。
* **堆芯布局**：最后一个周期的槽位。
  * 熔毁的元件显示在原槽位，红色并打叉。耗尽的反射板为橙色。
  * 枯竭燃料为灰色。槽位下方的条表示元件的热量或燃料棒的剩余燃料。
  * 暗色的列没有反应仓。
  * 鼠标指向槽位可查看详情。
* **曲线图**：最近 40 秒的外壳热量。红色虚线为上限。
  橙色柱为每周期产热，蓝色柱为每周期散热。鼠标指向曲线图可查看每个周期。
* **指标**（最后一个周期）：外壳热量、产热与散热、EU/t、进料倍率、列数、冷却液、燃料棒、冷却元件、自动化。

## 原因

| 原因 | 含义 |
|---|---|
| 热失控：冷却不足 | 外壳热量连续上升数个周期：堆芯产热多于元件带走的热量。 |
| 冷却元件熔毁导致热失控 | 散热片、冷却单元或热交换器熔毁，其热量进入外壳。 |
| 高温冷却液储罐已满：排热停止 | 流体反应堆：高温冷却液没有被抽出。 |
| 冷却液耗尽 | 流体反应堆：低温冷却液用完。 |
| 液体冷却停止 | 发电机模式：液体冷却的冷却液用尽，或高温冷却液未被取出。 |
| 外部过电压（机器爆炸） | 事故前不久，反应堆旁的机器因过电压爆炸。 |
| 反应仓丢失 | 反应仓被拆除或摧毁，该列中的元件掉落。 |
| 反应仓位于未加载的区块 | 反应仓所在的区块未加载。请把反应堆放在同一区块内。 |
| 热量骤升 | 外壳热量在 1 秒内从一半以下升到上限。 |
| 运行中添加了燃料、高进料倍率、自动化搬运了物品、冷却元件饱和 | 次要因素。 |

## 注意

> **提示：** 先在[核反应堆模拟器](reactor_simulator.md)中测试设计。它使用相同的计算。

记录器只存在于内存中：世界刚加载后还没有任何周期记录。
