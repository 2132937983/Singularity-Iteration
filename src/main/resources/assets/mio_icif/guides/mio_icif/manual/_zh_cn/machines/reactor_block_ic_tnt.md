# 工业TNT

<Row>
  <BlockImage id="mio_icif:reactor/block_ic_tnt" scale="3" />
</Row>

## 功能

工业TNT是爆炸方块，威力比原版TNT更强。
红石信号、火、燃烧的弹射物或附近的爆炸会点燃它。工业TNT也是核弹的主装药。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把工业TNT放在远离基地的位置。
2. 在TNT旁边放置拉杆。
3. 打开拉杆。
4. 在引信结束前远离TNT。

## 注意


> **警告：** 手持任何物品右键该方块，都会点燃TNT。
