# 核弹

<Row>
  <BlockImage id="mio_icif:reactor/block_reactor_nuke" scale="3" />
</Row>

## 功能

核弹有八个工业TNT槽位和一个核材料槽位。装填量决定爆炸威力。
红石信号使核弹开始引爆倒计时。爆炸后留下辐射区域。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把核弹放在远离基地和其他玩家的位置。
2. 右键核弹，打开界面。
3. 在槽位中放入工业TNT和核材料。
4. 在界面中查看爆炸威力。
5. 向核弹输入红石信号。
6. 在倒计时结束前远离核弹。

## 注意


> **警告：** 核弹启动后，无法停止倒计时。


> **警告：** 爆炸会摧毁大片区域。辐射区域在爆炸后持续存在，并伤害生物。
