# 反应堆红石接口

<Row>
  <BlockImage id="mio_icif:reactor/block_reactor_redstone_port" scale="3" />
</Row>

## 功能

反应堆红石接口是流体反应堆的外壳方块。接口收到红石信号时，反应堆启动。
接口没有界面。接口收到信号时，外观改变。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 建造5x5x5流体反应堆外壳。
2. 把外壳中的一个压力容器换成红石接口。
3. 在接口上放置拉杆。
4. 打开拉杆，启动反应堆。
5. 关闭拉杆，停止反应堆。

## 注意


> **警告：** 更换反应堆元件前，先断开红石信号。运行中的反应堆可能过热并爆炸。
