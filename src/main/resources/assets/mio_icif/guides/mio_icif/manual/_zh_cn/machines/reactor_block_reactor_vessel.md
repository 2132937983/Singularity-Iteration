# 核反应堆压力容器

<Row>
  <BlockImage id="mio_icif:reactor/block_reactor_vessel" scale="3" />
</Row>

## 功能

核反应堆压力容器是流体反应堆的结构方块。它没有界面，也没有独立功能。
压力容器构成5x5x5流体反应堆的外壳。压力容器的抗爆性很高。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 把核反应堆发电机放在5x5x5区域的中心。
2. 在反应堆六个面上各放一个核反应仓。
3. 用压力容器填满5x5x5立方体的外层。
4. 把外层中至少一个容器换成接口。

## 注意

- 外壳中至少需要一个流体接口、访问接口或红石接口。
