# EU保险丝导线

<Row>
  <BlockImage id="mio_icif:wiring/block_eu_fuse_cable" scale="3" />
</Row>

## 功能

EU保险丝导线是廉价的一次性保护。它在过载、短路或过电压时像断路器导线一样熔断，但熔断后保持断开。红石信号不会使其断开。

## 电力数据

此方块不消耗EU。

## 使用步骤

1. 将线路中的一格导线替换为保险丝导线。
2. 空手右击，设置额定流量、额定电压与延时。
3. 熔断后，手持新的保险丝导线右击即可恢复，新的保险丝会被消耗。熔断的保险丝不掉落任何物品。
