# EU分流导线

<Row>
  <BlockImage id="mio_icif:wiring/block_eu_splitter_cable" scale="3" />
</Row>

## 功能

EU分流导线是带红石开关的IV导线。
无红石信号时导线导电。有红石信号时导线断开线路。

## 电力数据

该方块不使用EU。

## 使用步骤

1. 用EU分流导线替换线路中的一格导线。
2. 在分流导线旁放置拉杆。
3. 打开拉杆，停止EU流动。
4. 关闭拉杆，重新接通线路。
