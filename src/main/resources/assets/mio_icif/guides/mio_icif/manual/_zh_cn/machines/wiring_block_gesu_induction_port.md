# GESU 无线磁转端口

<Row>
  <BlockImage id="mio_icif:wiring/block_gesu_induction_port" scale="3" />
</Row>

## 功能

GESU 模块：装在 GESU 核心的任意一面，代替一个输入或输出模块。GESU 成型后，它从 GESU 取电，给自身 ±8 格内的所有玩家无线充电：护甲、手持和背包里的电动物品（按充电座的顺序），每件每 tick 最多 32,768 EU（一个 LuV 包）。它不接电线，也不向电网送电。

## 用法

1. 搭 GESU 时把它装在核心六个面中的一面上。
2. 站在端口 8 格以内，身上的电动装备就会充电，偶尔冒出的电火花表示正在充。
3. 右键端口可以打开 GESU 的界面。
