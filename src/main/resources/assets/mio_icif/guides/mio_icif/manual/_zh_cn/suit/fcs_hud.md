# FCS HUD

## 功能

FCS HUD在量子头盔面罩上显示已启用单元的数据。
布局仿照坦克炮手瞄准镜：带框视野、航向带与测距仪。
数据面板位于屏幕边缘。威胁标记位于外环。

## 步骤：移动面板

1. 打开装备控制台。
2. 点击HUD布局。
3. 把面板拖到新位置。
4. 在全息地图上滚动滚轮调整大小。
5. 点击完成。

## 操作

按H开关HUD。
在模组配置界面设定颜色与轮廓。
在按键设置中给布局编辑器绑定按键。
要隐藏航向带，在布局编辑器中点击航向带按钮。

## 读数

RNG显示到瞄准点方块或生物的距离。
EL显示视线俯仰角。
PWR显示全部已启用单元的EU/t。进度条显示头盔电量。
