# 爆炸预警计时器

<ItemImage id="mio_icif:module/item_module_blast_warning" scale="3" />

## 功能

该单元测量28格内已点燃TNT、TNT矿车与膨胀苦力怕的引信。
每个爆炸物上方显示倒计时标签。
地面红环显示爆炸半径，黄环显示两倍半径。

## 电力数据

| 项目 | 数值 |
|---|---|
| 适用部位 | 胸甲 / 头盔 |
| 功耗 | 2 EU/t（开启时） |
| 显示 | 需要量子头盔面罩 |

## 使用步骤

1. 把单元装入量子胸甲或头盔。
2. 注视爆炸预警面板。
3. 面板显示IN RADIUS时离开黄环。

## 注意

- 最后一秒标签变为红色。
