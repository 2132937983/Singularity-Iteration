# 爆炸预警计时器

<ItemImage id="mio_icif:module/item_module_blast_warning" scale="3" />

## 功能

该单元测量28格内已点燃TNT、TNT矿车与膨胀苦力怕的引信。
每个爆炸物上方浮现圆形图标。图标的圆环随引信燃烧而减少，标签显示剩余秒数。
地面区域显示爆炸半径。区域随引信燃烧而填满。
爆炸物靠近你时，瞄准点周围出现带箭头的图标并指向爆炸物。蜂鸣声随引信燃烧而加快。
在爆炸半径内时，视野边缘闪烁红色。

## 电力数据

| 项目 | 数值 |
|---|---|
| 适用部位 | 胸甲 / 头盔 |
| 功耗 | 2 EU/t（开启时） |
| 显示 | 需要量子头盔面罩 |

## 使用步骤

1. 把单元装入量子胸甲或头盔。
2. 注视瞄准点周围的图标。
3. 朝箭头相反的方向离开。
4. 爆炸前不要进入地面区域。

## 注意

- 最后一秒图标与区域变为红色。
