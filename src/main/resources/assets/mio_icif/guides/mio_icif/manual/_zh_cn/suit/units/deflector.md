# 量子偏转器

<ItemImage id="mio_icif:module/item_module_deflector" scale="3" />

## 功能

该单元抵消护甲未挡住的伤害。
每点伤害消耗胸甲4000 EU，每次命中最多抵消12点。
力场平时不可见。命中时，命中点亮起六边形单元与偏转板。
该单元不抵消无视护甲的伤害，爆炸除外。

## 电力数据

| 项目 | 数值 |
|---|---|
| 适用部位 | 胸甲 |
| 功耗 | 每点伤害4000 EU，每次最多12点 |
| 显示 | 不需要面罩 |

## 使用步骤

1. 把单元装入量子胸甲。
2. 给胸甲充电。
3. 每次战斗后检查胸甲电量。

## 注意

- 该单元没有持续功耗。只在挡下命中时消耗EU。
