# 威胁传感器

<ItemImage id="mio_icif:module/item_module_threat_sensor" scale="3" />

## 功能

服务器每秒四次检查32格内的全部生物。
黄色警告表示玩家或中立生物注视穿戴者。
红色警告表示生物锁定穿戴者，或敌对生物注视穿戴者。
HUD外环上的标记指向每个威胁。全息地图使用相同颜色。

## 电力数据

| 项目 | 数值 |
|---|---|
| 适用部位 | 胸甲 |
| 功耗 | 6 EU/t（开启时） |
| 显示 | 需要量子头盔面罩 |

## 使用步骤

1. 把单元装入量子胸甲。
2. 穿戴量子头盔。
3. 转向红色标记。
4. 攻击目标或离开该区域。

## 注意

- 顶部横幅统计LOCK（红）与WATCH（黄）的数量。
