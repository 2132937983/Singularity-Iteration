# 量子指挥

自 0.1.10.2 起，装有已启用 <ItemLink id="mio_icif:module/item_module_entanglement_relay" /> 的量子套装可以直接指挥僚机：按地点下达命令、集中攻击、数据链与紧急回收。同一维度内命令不受距离限制。

## 指挥轮盘

按住 **X** 打开轮盘，把鼠标移到扇区或子项上后松开即执行；也可以点击，中心为取消。点按 **X**（不打开轮盘）是智能标记：准星对着生物时集中攻击，对着地面时移动到那里。自 0.1.11.230 起，没有僚机或没装纠缠中继器也能打开轮盘：僚机相关的扇区变灰，“装备”和“常用”照常可用。**G** 只用于切换电动工具的模式。

轮盘打开时会记录准星所指的地点与生物（最远 256 格；看向天空时为前方 48 格的空中点）。轮盘上方的标签选择全部僚机或其中一架；滚轮也可切换。

| 扇区 | 内容 |
|---|---|
| 移动 | 飞往该地点并守住：攻击待机半径（10 格）内的敌对生物。途中不交战。 |
| 区域压制 | 在区域上空巡航，清除范围（14 格）内的所有敌对生物。 |
| 集中攻击 | 攻击准星所指的生物直到其倒下（距僚机最远 128 格），然后归队。 |
| 归队 | 结束命令：回到编队与战术模式。 |
| 控制 ▸ | 三种战术模式、返回武装库，以及立场：自动立场、空中、地面（见武装库页的“僚机战术”）。为单架僚机设定的模式属于该机。 |
| 战甲 ▸ | 换装、脱甲出击、远程驾驶、清白协议、单件召唤、量子回收（见下文）。 |
| 装备 ▸ | 战术地图、全息台、喷气背包模式、HUD 开关、HUD 布局、奇点管理面板。 |
| 常用 ★ | 你自己挑的最多 3 项。在任一扇形菜单里右键一个子项即可放进或移出“常用”。默认是战术地图、喷气背包模式、远程驾驶。 |

## 按键一览

自 0.1.11.230 起按键做了整合，默认只占用这几个键：

| 按键 | 作用 |
|---|---|
| **X** | 按住：指挥轮盘。点按：智能标记。 |
| **V** / **B** | 行动键（主 / 副）：纳米爆发、量子行动或核心爆发，在奇点管理面板中分配。 |
| **G** | 手持电动工具时切换模式。 |
| **左 Alt** | 点按：打开奇点管理面板。按住：套装详细视图。 |
| 疾跑键 | 特殊机动模式与喷气背包加速。 |

战术地图、单件召唤、远程驾驶、喷气背包模式、HUD 开关与布局、核心爆发、加速、详细视图仍可在“按键设置”中单独绑定，默认不绑。从旧版本升级时，仍是旧默认键的绑定会自动改成新默认，你自己改过的按键保持不变。

执行命令的僚机不再跟随你：它守卫命令地点，而不是停留在你周围 28 格内。位于未加载区块的僚机无法移动；编队列表中显示为“未加载”，量子回收或控制台的“全部召回”能到达它。

## 数据链

开启数据链后，僚机看到的敌对生物（每架僚机周围 24 格）会标记在全息地图、战术地图与全息台上。若有舰队数据链协同，还会显示世界标记，且你准星所指的敌人成为僚机的首要目标。

## 量子回收

让你的所有僚机立即折返其武装库：任何维度、无论是否加载都能到达（未加载僚机所在的区块会短暂加载）。消耗 30 相干度，冷却 30 秒。

## 编队 HUD

指挥链路有效时，左侧的编队面板按编号（W1 到 W6：僚机来自武装库的第几套，其他僚机出击或返航时编号不变）列出每架僚机的模式（* 为单独模式）、命令与距离、生命值以及与你的距离。视野外的僚机会在屏幕边缘显示箭头。世界中的待机点、压制圆环与集中攻击目标仅对你显示。

## 3D 全息台

装有 <ItemLink id="mio_icif:module/item_module_holomap_mk2" /> 时，在轮盘的“装备”里选择全息台。你面前会升起周围地形的全息投影：地形柱从中心向外升起，干涉条纹与扫描线掠过其上。显示你自己、带编号与命令的僚机、敌对生物（数据链中的目标带圆环）、其他玩家，以及有地脉全息时扫描到的矿石。

- 拖动：旋转全息台。滚轮：24、48 或 96 格。
- 左键点击地形：移动到该处。右键：压制该区域。左键点击生物：集中攻击。
- H：待机。F：归队。1 到 6：选择该编号的僚机。0：全部僚机。按住按键只生效一次。
