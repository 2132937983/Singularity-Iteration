# 工具

本章说明手持工具、武器和随身装置。每页给出数值、按键和使用规则。

## 共同规则

- **电量。**电动工具储存 EU。新物品没有电。物品提示写明等级、每次耗电和约可用次数。
- **充电。**储电箱、充电座、电池、背包式储电装备和军械库都能给工具充电。等级只是标识，不限制充电。充电速度受工具自身的充电速率限制：1 级 100、2 级 128、3 级 512、4 级 2,048、5 级 8,192 EU/t。
- **背包取电。**手持工具在使用前先从穿戴的背包式储电装备取电。
- **没电时。**钻头和链锯像空手一样挖，不掉落需要工具的方块。武器不开火。工具攻击没有伤害加成。
- **G 键。**切换手持工具的模式。装备控制台里也能选模式。切换消息显示在动作栏。
- **附魔。**所有电动工具都能附“节能”。按类别还能附：钻头和链锯（效率、时运、精准采集），纳米剑和量子剑（剑类附魔），纳米弓（弓类附魔），电钓竿（饵钓、海之眷顾）。电动工具不能附耐久和经验修补。青铜工具是普通工具，能附所有对应附魔。
- **领地。**范围工具和武器逐格检查领地权限。被保护的方块不会改变。
