# Voltage Detector

<Row>
  <BlockImage id="mio_icif:checker/block_checker" scale="3" />
</Row>

## Function

The Voltage Detector connects to a cable network and measures the voltage on the network.
Look at the detector to see the voltage, the voltage tier and the input power.

## Power data

This block uses no EU.

## Procedure

1. Place the Voltage Detector next to a cable of the network.
2. Point the crosshair at the detector.
3. Read the voltage and the voltage tier on the screen.
4. Compare the voltage tier with the input tier of your machines.
