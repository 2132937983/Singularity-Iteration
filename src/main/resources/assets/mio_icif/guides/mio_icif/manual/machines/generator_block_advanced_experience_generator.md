# Advanced Experience Generator

<Row>
  <BlockImage id="mio_icif:generator/block_advanced_experience_generator" scale="3" />
</Row>

## Function

The machine pulls experience orbs within its range and converts them into EU.
The machine has a larger range and a higher output than the Experience Generator.

## Power data

| Item | Value |
|---|---|
| Output voltage tier | ULV (8 EU) |
| Output | 320 EU/t |
| Energy storage | 4,000,000 EU |

The game measured these values from the block entity of this version.

## Procedure

1. Place the generator near a mob farm.
2. Connect an EV cable to the generator.
3. Kill mobs near the generator to release experience orbs.

## Notes

- The machine also takes the experience orbs that players need.
