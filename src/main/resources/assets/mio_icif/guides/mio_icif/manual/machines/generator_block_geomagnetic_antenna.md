# Geomagnetic Antenna

<Row>
  <BlockImage id="mio_icif:generator/block_geomagnetic_antenna" scale="3" />
</Row>

## Function

The block is a structural part of the Geomagnetic Generator.
The block has no function alone.

## Power data

This block uses no EU.

## Procedure

1. Place the Geomagnetic Generator.
2. Put one antenna directly on top of the generator.
3. Put a second antenna on top of the first antenna.
