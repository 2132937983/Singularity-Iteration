# Geomagnetic Pedestal

<Row>
  <BlockImage id="mio_icif:generator/block_geomagnetic_pedestal" scale="3" />
</Row>

## Function

The block is a structural part of the Geomagnetic Generator.
The block has no function alone.

## Power data

This block uses no EU.

## Procedure

1. Place the Geomagnetic Generator.
2. Find the block directly below the generator.
3. Put one pedestal against each of the four horizontal sides of that block.
