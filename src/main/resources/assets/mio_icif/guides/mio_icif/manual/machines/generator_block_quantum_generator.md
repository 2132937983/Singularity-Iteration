# Quantum Generator

<Row>
  <BlockImage id="mio_icif:generator/block_quantum_generator" scale="3" />
</Row>

## Function

The machine makes EU without fuel or sunlight.
The machine sends EU to the blocks on all six faces.

## Power data

| Item | Value |
|---|---|
| Output voltage tier | HV (512 EU) |
| Output | 512 EU/t |
| Energy storage | 100,000,000 EU |

The game measured these values from the block entity of this version.

## Procedure

1. Place the generator next to a machine or a cable.
2. Open the GUI to read the output and the voltage tier.

## Notes

- The GUI shows the status only. The GUI has no controls.
