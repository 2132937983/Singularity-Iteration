# Dimension Oil Rig Core

<Row>
  <BlockImage id="mio_icif:oilrig/block_dimension_oil_rig_core" scale="3" />
</Row>

## Function

The Dimension Oil Rig Core controls a larger oil rig. The drill moves in a spiral around the core and has no area limit.
The rig uses the same modules as the Oil Rig. The rig gives more crude oil per block and uses more EU.

## Power data

| Item | Value |
|---|---|
| Energy storage | 200,000 EU |

The game measured these values from the block entity of this version.

## Procedure

1. Place the core with eight modules around the core and two modules on top.
2. Place a ring of sixteen modules one layer below, two blocks from the core.
3. Stack four Titanium Drill Frames on top and put four frames around the third frame.
4. Put one frame three blocks from the core on each side, on the core layer.
5. Put one frame two blocks from the core on each side, one layer above the core.
6. Connect an HV cable to an Input Module.

## Notes

- The structure needs at least one Input Module and one Output Module.

> **WARNING:** The drill destroys the blocks in its path and drops no items. The drill area grows without limit.
