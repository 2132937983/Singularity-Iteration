# Oil Rig Base Module

<Row>
  <BlockImage id="mio_icif:oilrig/block_oil_rig_base" scale="3" />
</Row>

## Function

The Oil Rig Base Module is a structural part of the oil rig. The module fills a module position and has no function of its own.

## Power data

This block uses no EU.

## Procedure

1. Build the module ring around the Oil Rig Core.
2. Put Input Modules and Output Modules where you need them.
3. Fill the remaining module positions with Base Modules.
