# Oil Rig Output Module

<Row>
  <BlockImage id="mio_icif:oilrig/block_oil_rig_output" scale="3" />
</Row>

## Function

The Oil Rig Output Module stores the crude oil from the drill. Pipes can take the oil from the module.

## Power data

This block uses no EU.

## Procedure

1. Put the Output Module in a module position of the rig.
2. Place a Water Extraction Pipe with its back against the module.
3. Connect pipes from the extraction pipe to a tank or to a machine.

## Notes

- When all Output Modules are full, the rig stops.
