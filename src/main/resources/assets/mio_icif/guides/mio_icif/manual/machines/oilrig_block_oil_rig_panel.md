# Oil Rig Panel

<Row>
  <BlockImage id="mio_icif:oilrig/block_oil_rig_panel" scale="3" />
</Row>

## Function

The Oil Rig Panel shows the rig status and the current drill coordinate. The panel lights up while the rig works.

## Power data

This block uses no EU.

## Procedure

1. Put the panel in a module position of the rig.
2. Right-click the panel to open the status GUI.
3. Read the status line to find the cause of a stop.

## Notes

- The panel opens the GUI only when the rig structure is complete.
