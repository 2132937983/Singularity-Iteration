# Mining Pipe

<Row>
  <BlockImage id="mio_icif:produce/block_mining_pipe" scale="3" />
</Row>

## Function

Mining Pipe is a structural block of the Miner. The Miner places the pipe below itself as it mines down.
The pipe has no function without the Miner.

## Power data

This block uses no EU.

## Procedure

1. Craft Mining Pipe.
2. Put the Mining Pipe into the pipe slot of the Miner.
3. Keep the pipe slot filled while the Miner goes deeper.
