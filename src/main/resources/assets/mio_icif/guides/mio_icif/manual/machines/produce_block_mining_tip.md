# Mining Drill Tip

<Row>
  <BlockImage id="mio_icif:produce/block_mining_tip" scale="3" />
</Row>

## Function

The Mining Drill Tip is a structural block of the Miner. The Miner places the tip at the lower end of the Mining Pipe.
The tip has no function of its own.

## Power data

This block uses no EU.

## Procedure

1. Let the Miner place the tip automatically.
2. Leave the tip in place while the Miner works.
