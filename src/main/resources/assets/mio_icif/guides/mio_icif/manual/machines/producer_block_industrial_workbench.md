# Industrial Workbench

<Row>
  <BlockImage id="mio_icif:producer/block_industrial_workbench" scale="3" />
</Row>

## Function

The Industrial Workbench is a crafting table with a 3 x 3 grid and an 18-slot storage. The block uses no EU.
The left tool slot uses a Forge Hammer and the right tool slot uses Plate Cutting Shears to process materials.
The grid and the storage keep their items when you close the GUI.

## Power data

This block uses no EU.

## Procedure

1. Right-click the workbench to open the GUI.
2. Put the ingredients into the crafting grid.
3. Put a Forge Hammer and a material into the left tool slots.
4. Take the results from the output slots.
