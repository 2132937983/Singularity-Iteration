# Large Matter Fabricator Core

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_core" scale="3" />
</Row>

## Function

The Large Matter Fabricator Core is the center of a multiblock. Each of the six faces must touch a module.
The structure needs at least one Input Module (IV) and one Tank Module. The structure accepts a maximum of one Scrap Input Module.
The core converts EU from the Input Modules into UU-Matter and stores the UU-Matter in the Tank Modules.

## Power data

This block uses no EU.

## Procedure

1. Place the Large Matter Fabricator Core.
2. Place one module against each of the six faces of the core.
3. Connect IV cables to the Input Modules.
4. Take the UU-Matter from the Tank Modules with a pipe.

## Notes

- The GUI shows the module counts and a message when the structure is incomplete.
