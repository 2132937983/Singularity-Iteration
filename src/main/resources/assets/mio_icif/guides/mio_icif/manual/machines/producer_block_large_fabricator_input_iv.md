# Large Matter Fabricator Input Module (IV)

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_input_iv" scale="3" />
</Row>

## Function

The Input Module (IV) is a part of the Large Matter Fabricator. The module receives EU from IV cables.
The core uses the EU in each Input Module to make UU-Matter. More Input Modules give more input.

## Power data

| Item | Value |
|---|---|
| Input voltage tier | IV (8,192 EU) |
| Maximum input | 8,192 EU/t |
| Energy storage | 800,000 EU |

The game measured these values from the block entity of this version.

## Procedure

1. Place the module against a face of the Large Matter Fabricator Core.
2. Connect an IV cable to the module.

## Notes


> **WARNING:** Supply IV or lower. The module explodes on overvoltage.
