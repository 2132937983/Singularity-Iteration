# Large Matter Fabricator Scrap Input Module

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_scrap" scale="3" />
</Row>

## Function

The Scrap Input Module is a part of the Large Matter Fabricator. The module accepts Scrap, Scrap Box and Thorium Scrap Box.
The scrap value reduces the EU cost of the UU-Matter.

## Power data

This block uses no EU.

## Procedure

1. Place the module against a face of the Large Matter Fabricator Core.
2. Put Scrap or Scrap Boxes into the module slot.

## Notes

- The structure accepts a maximum of one Scrap Input Module.
