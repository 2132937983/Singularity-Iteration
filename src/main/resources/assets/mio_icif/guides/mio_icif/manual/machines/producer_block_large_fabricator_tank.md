# Large Matter Fabricator Tank Module

<Row>
  <BlockImage id="mio_icif:producer/block_large_fabricator_tank" scale="3" />
</Row>

## Function

The Tank Module is a part of the Large Matter Fabricator. The module stores the UU-Matter from the core.
A pipe can take the UU-Matter out of the module.

## Power data

This block uses no EU.

## Procedure

1. Place the module against a face of the Large Matter Fabricator Core.
2. Connect a pipe to the module to take the UU-Matter.
