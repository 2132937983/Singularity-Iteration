# Advanced Machine Hull

<Row>
  <BlockImage id="mio_icif:producer/block_machine_hull_advanced" scale="3" />
</Row>

## Function

The Advanced Machine Hull is a crafting component. The block has no function in the world.
Advanced machines use this hull in their crafting recipes.

## Power data

This block uses no EU.

## Procedure

1. Craft the Advanced Machine Hull at a crafting table.
2. Use the hull as an ingredient in an advanced machine recipe.
3. Look up the machines that use the hull in the recipe viewer.
