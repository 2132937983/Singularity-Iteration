# Basic Machine Hull

<Row>
  <BlockImage id="mio_icif:producer/block_machine_hull_basic" scale="3" />
</Row>

## Function

The Basic Machine Hull is a crafting component. The block has no function in the world.
Basic machines use this hull in their crafting recipes.

## Power data

This block uses no EU.

## Procedure

1. Craft the Basic Machine Hull at a crafting table.
2. Use the hull as an ingredient in a machine recipe.
3. Look up the machines that use the hull in the recipe viewer.
