# EU Splitter Cable

<Row>
  <BlockImage id="mio_icif:wiring/block_eu_splitter_cable" scale="3" />
</Row>

## Function

The EU Splitter Cable is an IV cable with a redstone switch.
Without a redstone signal, the cable conducts EU. With a redstone signal, the cable cuts the line.

## Power data

This block uses no EU.

## Procedure

1. Replace one cable block in the line with the EU Splitter Cable.
2. Place a lever next to the splitter cable.
3. Turn the lever on to stop the EU flow.
4. Turn the lever off to connect the line again.
