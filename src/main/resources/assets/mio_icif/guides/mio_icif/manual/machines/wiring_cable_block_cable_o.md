# Medium-Voltage Cable

<Row>
  <BlockImage id="mio_icif:wiring/cable/block_cable_o" scale="3" />
</Row>

## Function

The Medium-Voltage Cable carries EU at the MV voltage tier.
The bare cable shocks living entities that touch the cable while EU flows.
A packet above the cable limit burns the cable.

## Power data

| Item | Value |
|---|---|
| Rated voltage tier | MV (128 EU) |

The game measured these values from the block entity of this version.

## Procedure

1. Place the cable in a line from the generator to the machine.
2. Right-click the cable with Rubber to add an insulation layer.
3. Right-click a cable arm with a wrench to disconnect that side.
4. Right-click the cable center with a wrench to connect the side again.

## Notes

- You can lay the cable through an iron scaffold and foam the scaffold. The cable conducts inside the reinforced stone.
