# Insulated High-Voltage Cable

<Row>
  <BlockImage id="mio_icif:wiring/cable/block_gold_cable_1" scale="3" />
</Row>

## Function

The Insulated High-Voltage Cable is an HV cable with one insulation layer.
The insulation stops shocks only below the full HV voltage.
A packet above the cable limit burns the cable.

## Power data

| Item | Value |
|---|---|
| Rated voltage tier | HV (512 EU) |

The game measured these values from the block entity of this version.

## Procedure

1. Connect the generator to the machine with the Insulated High-Voltage Cable.
2. Right-click the cable with Rubber to add an insulation layer.
3. Shift-right-click the cable with a Cable Cutter to remove one insulation layer.
4. Right-click the cable with a dye to give the cable a colour.

## Notes


> **WARNING:** The cable can shock players at the full HV voltage. Add insulation layers with Rubber.

- Cables with different colours do not connect. A black cable connects to all colours.
- You can lay the cable through an iron scaffold and foam the scaffold. The cable conducts inside the reinforced stone.
