# Insulated Extra-High-Voltage Cable

<Row>
  <BlockImage id="mio_icif:wiring/cable/block_iron_cable_1" scale="3" />
</Row>

## Function

The Insulated Extra-High-Voltage Cable is an EV cable with one insulation layer.
The insulation stops shocks only below the full EV voltage.
A packet above the cable limit burns the cable.

## Power data

| Item | Value |
|---|---|
| Rated voltage tier | EV (2,048 EU) |

The game measured these values from the block entity of this version.

## Procedure

1. Place an iron scaffold line from the EV source to the EV machine.
2. Place the Insulated Extra-High-Voltage Cable into each iron scaffold.
3. Spray CF foam on the scaffold line with the CF Sprayer.
4. Right-click the wet foam with sand, or wait until the foam hardens.

## Notes


> **WARNING:** The cable can shock players at the full EV voltage. Add insulation layers with Rubber.

- Cables with different colours do not connect. A black cable connects to all colours.
- You can lay the cable through an iron scaffold and foam the scaffold. The cable conducts inside the reinforced stone.
