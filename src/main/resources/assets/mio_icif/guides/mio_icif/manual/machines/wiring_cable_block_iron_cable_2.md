# Double-Insulated Extra-High-Voltage Cable

<Row>
  <BlockImage id="mio_icif:wiring/cable/block_iron_cable_2" scale="3" />
</Row>

## Function

The Double-Insulated Extra-High-Voltage Cable is an EV cable with two insulation layers.
The insulation stops shocks only below the full EV voltage.
A packet above the cable limit burns the cable.

## Power data

| Item | Value |
|---|---|
| Rated voltage tier | EV (2,048 EU) |

The game measured these values from the block entity of this version.

## Procedure

1. Connect the generator to the machine with the Double-Insulated Extra-High-Voltage Cable.
2. Right-click the cable with Rubber to add an insulation layer.
3. Right-click the cable with a Cable Cutter to remove one insulation layer (the rubber comes back).
4. Right-click the cable with a dye to give the cable a colour.

## Notes


> **WARNING:** The cable can shock players at the full EV voltage. Add insulation layers with Rubber.

- Cables with different colours do not connect. A black cable connects to all colours.
- You can lay the cable through an iron scaffold and foam the scaffold. The cable conducts inside the reinforced stone.
