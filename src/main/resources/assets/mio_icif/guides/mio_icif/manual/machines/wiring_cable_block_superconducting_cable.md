# block_superconducting_cable

<Row>
  <BlockImage id="mio_icif:wiring/cable/block_superconducting_cable" scale="3" />
</Row>

## Function

The Superconducting Cable carries EU with no voltage or packet limit.
The cable has no transport loss and does not burn.
The insulation does not break down. The cable does not shock living entities.

## Power data

| Item | Value |
|---|---|
| Rated voltage tier | No limit |

The game measured these values from the block entity of this version.

## Procedure

1. Place an iron scaffold line from the generator to the machines.
2. Place the Superconducting Cable into each iron scaffold.
3. Spray CF foam on the scaffold line with the CF Sprayer.
4. Right-click the wet foam with sand, or wait until the foam hardens.
5. Put a transformer before each machine with a lower voltage tier.

## Notes


> **WARNING:** The cable does not limit the packet. A machine with a lower voltage tier explodes on overvoltage.

- The cable conducts inside the reinforced stone.
