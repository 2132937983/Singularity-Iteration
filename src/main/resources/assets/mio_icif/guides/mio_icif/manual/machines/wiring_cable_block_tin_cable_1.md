# Insulated Low-Voltage Cable

<Row>
  <BlockImage id="mio_icif:wiring/cable/block_tin_cable_1" scale="3" />
</Row>

## Function

The Insulated Low-Voltage Cable is an LV cable with one insulation layer.
The insulation stops shocks at the full LV voltage.
A packet above the cable limit burns the cable.

## Power data

| Item | Value |
|---|---|
| Rated voltage tier | LV (32 EU) |

The game measured these values from the block entity of this version.

## Procedure

1. Connect the generator to the machine with the Insulated Low-Voltage Cable.
2. Shift-right-click the cable with a Cable Cutter to remove one insulation layer.
3. Right-click the cable with a dye to give the cable a colour.

## Notes

- Cables with different colours do not connect. A black cable connects to all colours.
- You can lay the cable through an iron scaffold and foam the scaffold. The cable conducts inside the reinforced stone.
