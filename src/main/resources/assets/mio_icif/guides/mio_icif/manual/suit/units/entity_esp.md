# Biometric Scanner (ESP)

<ItemImage id="mio_icif:module/item_module_entity_esp" scale="3" />

## Function

The unit tags every creature within 32 blocks.
Each tag shows corner brackets, the name, the distance and a health bar.
The visor draws a see-through outline around each tagged creature.

## Power data

| Item | Value |
|---|---|
| Fits | Helmet |
| Power | 12 EU/t while on |
| Display | Needs a quantum helmet visor |

## Procedure

1. Install the unit into the quantum helmet.
2. Enter a cave or a dark area.
3. Count the red outlines before you advance.

## Notes

- Colors: red is hostile, yellow is neutral, green is passive, cyan is a player.
