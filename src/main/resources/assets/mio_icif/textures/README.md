# METS 富集作物纹理说明

## 需要创建的作物方块纹理

请在 `textures/block/mets_crop/` 目录下创建以下纹理文件：

### 富铁作物 (iron_rich)
- `iron_rich_1.png` - 第1阶段 (幼苗)
- `iron_rich_2.png` - 第2阶段
- `iron_rich_3.png` - 第3阶段
- `iron_rich_4.png` - 第4阶段
- `iron_rich_5.png` - 第5阶段
- `iron_rich_6.png` - 第6阶段
- `iron_rich_7.png` - 第7阶段
- `iron_rich_8.png` - 第8阶段 (成熟可收获)

### 富铜作物 (copper_rich)
- `copper_rich_1.png` ~ `copper_rich_8.png`

### 富锡作物 (tin_rich)
- `tin_rich_1.png` ~ `tin_rich_8.png`

### 富钛作物 (titanium_rich)
- `titanium_rich_1.png` ~ `titanium_rich_8.png`

### 富铅作物 (lead_rich)
- `lead_rich_1.png` ~ `lead_rich_8.png`

### 富铀作物 (uranium_rich)
- `uranium_rich_1.png` ~ `uranium_rich_8.png`

## 需要创建的种子物品纹理

请在 `textures/item/crop/` 目录下创建以下纹理文件：

- `iron_rich_seed.png` - 富铁种子
- `copper_rich_seed.png` - 富铜种子
- `tin_rich_seed.png` - 富锡种子
- `titanium_rich_seed.png` - 富钛种子
- `lead_rich_seed.png` - 富铅种子
- `uranium_rich_seed.png` - 富铀种子

## 纹理规格

- **尺寸**: 16x16 像素 (推荐) 或 32x32 像素
- **格式**: PNG (支持透明)
- **作物方块**: 交叉形状 (cross)，类似原版小麦作物
- **种子物品**: 平面图标
