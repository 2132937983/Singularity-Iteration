# METS 富集作物纹理需求清单

## 概述

METS 富集作物系统已完全移植，支持两种种植方式：
1. **原版耕地** → 放置 METS 作物方块 (8个生长阶段)
2. **IC2 作物架** → 使用 IC2 植物系统 (4个生长阶段)

## 纹理规格

- **尺寸**: 16x16 像素 (推荐) 或 32x32 像素

- **作物方块**: 交叉形状 (cross)，类似原版小麦作物
- **种子物品**: 平面图标

## 种子种植方式说明

每种 METS 富集种子都可以在两种地方种植：

### 1. 原版耕地
- 右键点击耕地 → 放置 METS 作物方块
- 作物方块有 8 个生长阶段
- 成熟后破坏方块获得产物和种子
- 可以使用骨粉催熟 (铀作物除外)

### 2. IC2 作物架
- 右键点击作物架 → 种植为 IC2 作物
- 使用 IC2 植物系统 (4 个生长阶段)
- 可以用作物分析仪分析
- 可以杂交育种
